```

  □ 隔离 CPU (isolcpus)
  □ 中断合并禁用

□ 网络配置
  □ RSS 配置
  □ Flow Control
  □ VLAN 配置
  □ Bonding/Teaming

□ 应用配置
  □ Master lcore 分配
  □ Worker lcore 分配
  □ 内存池大小
  □ 队列配置

## 7. 故障排查

### 7.1 常见问题

```
故障排查指南：

┌─────────────────────────────────────────────────────────────┐
│                    常见问题                                 │
│                                                              │
│  1. 设备绑定失败                                            │
│     - 检查 IOMMU: dmesg | grep -e DMAR -e IOMMU          │
│     - 检查驱动: lsmod | grep igb_uio                     │
│     - 尝试 force: dpdk-devbind --force                   │
│                                                              │
│  2. 内存不足                                                │
│     - 增加 hugepage: echo 4096 > nr_hugepages             │
│     - 检查: cat /proc/meminfo | grep Huge                │
│     - 查看其他进程: ipcs -m                               │
│                                                              │
│  3. 性能差                                                  │
│     - CPU 绑定: taskset -c 1-3 ./app                     │
│     - 检查 NUMA: numactl --hardware                       │
│     - 验证 RSS: ethtool -l eth0                          │
│                                                              │
│  4. 丢包                                                    │
│     - 增加 descriptor: --rxd 4096 --txd 4096             │
│     - 检查 offload: ethtool -k eth0                      │
│     - 监控: rte_eth_stats_get                             │
└─────────────────────────────────────────────────────────────┘
