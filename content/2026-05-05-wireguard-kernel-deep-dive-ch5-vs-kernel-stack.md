## 2. 内核网络栈架构

### 2.1 快速路径 vs 慢速路径

```
内核网络栈快速路径：

┌──────────────────────────────────────────────────────────────────────┐
│                        快速路径（Fast Path）                         │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   网卡驱动                                                           │
│      │                                                              │
│      ▼                                                              │
│   NAPI 轮询 (softirq)                                              │
│      │                                                              │
│      ├── 批量接收 (batch)                                          │
│      ├── GRO 合并 (Generic Receive Offload)                         │
│      └── 分配 skb                                                  │
│      │                                                              │
│      ▼                                                              │
│   netif_receive_skb()                                              │
│      │                                                              │
│      ├── tc Classifier (可选)                                       │
│      ├── Netfilter (PREROUTING)                                     │
│      └── 路由查找                                                   │
│          │                                                          │
│          ├── 转发 → ip_forward() → ip_output() → 发送               │
│          │                                                          │
│          └── 本地 → ip_local_deliver() → UDP/TCP                    │
│                        │                                           │
│                        └── socket receive queue                      │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────┐
│                        慢速路径（Slow Path）                         │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   · TCP 拥塞控制                                                    │
│   · 连接跟踪 (conntrack)                                            │
│   · Netfilter (多个 HOOK)                                          │
│   · 路由缓存                                                        │
│   · Socket 选项处理                                                 │
│   · QoS/TC                                                         │
│   · IPsec 加密                                                     │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## 3. WireGuard 开销分解

### 3.1 单包开销

```
WireGuard 单包开销（64B payload）：

┌──────────────────────────────────────────────────────────────────────┐
│                        WireGuard 开销                                │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   原始数据包：                                                      │
│   ┌──────────────────────────────────────────────────────────────┐ │
│   │  IP Header (20B) + TCP/UDP Header (8B) + Payload (64B)      │ │
│   │  = 92B                                                     │ │
│   └──────────────────────────────────────────────────────────────┘ │
│                                                                      │
│   WireGuard 封装后：                                                │
│   ┌──────────────────────────────────────────────────────────────┐ │
│   │  Outer IP Header (20B) + UDP Header (8B)                   │ │
│   │  + WireGuard Header (32B) + Encrypted Payload (80B)         │ │
│   │  + Poly1305 Tag (16B)                                      │ │
│   │  = 156B                                                    │ │
│   └──────────────────────────────────────────────────────────────┘ │
│                                                                      │
│   开销：156 - 92 = 64B（70% overhead）                              │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘

WireGuard 开销明细：

  ┌─────────────────────────────────────────┬───────────┬──────────┐
  │  字段                                  │  大小     │  说明    │
  ├─────────────────────────────────────────┼───────────┼──────────┤
  │  Outer IP Header                       │  20B     │  UDP 外部│
  │  UDP Header                           │  8B      │  WG 端口 │
  │  WireGuard Header (receiver_index)     │  4B      │  Peer ID │
  │  WireGuard Header (counter)          │  8B      │  防重放  │
  │  Encrypted Payload                    │  ~80B    │  16B 对齐│
  │  Poly1305 Tag                        │  16B     │  认证    │
  ├─────────────────────────────────────────┼───────────┼──────────┤
  │  Total                                │  ~156B   │          │
  └─────────────────────────────────────────┴───────────┴──────────┘

大包开销比例：

  Payload     │  WG Overhead │  Total      │  Overhead %
  ────────────┼───────────────┼─────────────┼────────────
  64B        │  64B         │  156B      │  70%
  256B       │  64B         │  348B      │  25%
  512B       │  64B         │  604B      │  12%
  1024B      │  64B         │  1116B     │  6%
  1500B      │  64B         │  1592B     │  4%
```

```bash
#!/bin/bash
# wireguard_tuning.sh — WireGuard 性能调优

echo "=== WireGuard 调优 ==="

# 1. 网卡队列
ethtool -L eth0 combined $(nproc)

# 2. 中断亲和
for i in $(seq 0 $(( $(nproc) - 1 ))); do
    IRQ=$(cat /proc/interrupts | grep "eth0-$i" | awk -F: '{print $1}')
    [ -n "$IRQ" ] && echo $((1 << i)) > /proc/irq/$IRQ/smp_affinity_list
done

# 3. Ring buffer
ethtool -G eth0 rx 4096 tx 4096

# 4. 巨型帧
ip link set eth0 mtu 9000
ip link set wg0 mtu 1420

# 5. 禁用不需要的功能
ethtool -K eth0 gro off gso off tso off 2>/dev/null || true

# 6. CPU 频率
for cpu in /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor; do
    echo performance > $cpu
done

# 7. Socket buffer
echo 16777216 > /proc/sys/net/core/rmem_max
echo 16777216 > /proc/sys/net/core/wmem_max
```

## 9. 小结

```
WireGuard vs 内核网络栈总结：

性能对比：
  · 延迟：WireGuard (6-12us) vs Raw UDP (1-2us)
  · 吞吐：WireGuard 50Gbps vs UDP 95Gbps（1500B）
  · CPU：WireGuard 2 cores vs UDP 0.5 cores（64B @ 1Mpps）

开销分解：
  · ChaCha20-Poly1305：~70% 开销
  · UDP 封装：~10% 开销
  · 内核协议栈：~10% 开销
  · 其他：~10% 开销

WireGuard 优势：
  · ChaCha20 比 AES 快（无硬件时）
  · 代码量小，易审计
  · NAT 友好
  · 快速漫游切换
  · 现代加密（抗量子）

WireGuard 劣势：
  · 比 Raw UDP 慢 5-6x
  · 小包 overhead 高
  · 不支持多播
  · 不支持隧道分片

适用场景：
  · 游戏/实时应用
  · 云计算互联
  · 移动漫游
  · IoT 嵌入式
  · 高性能敏感

调优要点：
  · 巨型帧（MTU 1420）
  · CPU 频率 performance
  · 网卡中断亲和
  · Ring buffer 调大
  · RPS 启用
```
