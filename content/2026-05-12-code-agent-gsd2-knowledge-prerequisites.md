# 构建 Code Agent 知识体系：从 Claude Code 插件到独立 Agent

## 1. 概述

```
本文目标：

分析构建一个类 Claude Code 的 AI Code Agent (gsd2) 需要提前学习的知识体系。

gsd2 演进路径：
  1. Claude Code 插件 (初始形态)
  2. 基于 Pi.ai 框架的独立 Code Agent (当前形态)

核心问题：
  · 构建一个 Code Agent 需要哪些知识？
  · 每个知识领域要学到什么深度？
  · 学习路径是什么？

技术栈假设：
  · LLM: GPT-4o / Claude 3.5 / 类似的强代码能力模型
  · 框架: Pi.ai Agent Framework
  · 代码执行: Sandboxing + Tool Use
  · 协议: MCP (Model Context Protocol)
```

推荐资源：
  · "Attention Is All You Need" — Google Brain 2017
  · "The Illustrated Transformer" — Jay Alammar blog
  · "GPT-3 Paper" — Brown et al.

  · 理解 Self-Attention 计算过程

### 5.2 MCP (Model Context Protocol)

```
MCP 协议：

┌──────────────────────────────────────────────────────────────────────┐
│                        MCP 架构                                      │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   Host (Claude Code / Agent)                                        │
│        │                                                            │
│        │  JSON-RPC 2.0                                             │
│        ▼                                                            │
│   ┌─────────────────────────────────────────────────────────────┐   │
│   │                    MCP Server                               │   │
│   │  ┌───────────┐  ┌───────────┐  ┌───────────┐               │   │
│   │  │  Tools    │  │ Resources │  │ Prompts   │               │   │
│   │  └───────────┘  └───────────┘  └───────────┘               │   │
│   └─────────────────────────────────────────────────────────────┘   │
│        │                                                            │
│        ▼                                                            │
│   External System (File System, Git, DB, etc.)                       │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘

MCP 核心概念：

  1. Tools: LLM 可调用的外部能力
     · list: 列出可用工具
     · call: 调用工具
     · schema: 工具定义

  2. Resources: 可读取的外部数据
     · 文件内容
     · 配置信息
     · 数据库查询结果

  3. Prompts: 预定义的 prompt 模板
     · 常用任务模板
     · 角色设定

MCP for Code Agent:
  · 代码搜索 (grep, ast)
  · 代码执行 (sandbox)
  · 构建系统 (make, cargo)
  · 测试运行 (pytest)
  · Git 操作
  · 文档检索
```

## 12. 总结

```
构建 Code Agent 知识体系：

核心知识领域:
  1. LLM 基础 — 理解 Transformer/Attention 机制
  2. Prompt Engineering — ReAct/CoT/Few-shot
  3. Agent 架构 — Tool Use/Memory/Planning
  4. 代码能力 — AST/构建/测试/执行
  5. 安全沙箱 — 资源限制/进程隔离
  6. 评估体系 — SWE-bench/自我验证
  7. MCP 协议 — 标准化工具扩展

从 Claude Code 插件到独立 Agent:
  · 插件: 依赖 Claude Code 主程序
  · 独立 Agent: 自己实现 LLM 调用 + Tool 系统 + 代码执行
  · Pi Framework: 提供 Agent 基础设施 (记忆、对话、部署)

关键成功因素:
  · 强大的代码执行环境 (安全沙箱)
  · 可靠的 Tool Use 系统 (MCP)
  · 优秀的任务分解能力 (ReAct/Planning)
  · 完善的评估体系 (SWE-bench)
  · 持续的自我改进 (RLHF/Feedback)
```
