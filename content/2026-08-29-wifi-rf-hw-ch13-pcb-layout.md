这一章回答一个问题：**为什么硬件工程师看一眼 PCB 布局，就知道这板子的 WiFi 会不会出事**。前十二章里所有「信号变差」的嫌疑人——失配（[[2026-08-29-wifi-rf-hw-ch09-impedance-matching|第九章]]）、频偏（第十一章）、电源毛刺（第十二章）——最终都要落在一块具体的板子上作案；板子怎么分层、器件怎么摆、地怎么铺，决定了他们有没有作案机会。

核心类比一组打天下：**PCB = 主板/背板，走线 = 总线/传输线，参考地平面 = 回流路径（回家路），布局 = 机房摆位与走线规划**——射频区是机房里的敏感区，晶振是精密仪器，电源是强电间，分区分明是两边共享的常识。

先立 non-goal：**本章不教 layout 实操**。画板子（阻抗计算、叠层设计、仿真调优）是射频工程师的手艺，超出系列射程；本章教的是「看懂」——把《ESP32-S3 硬件设计指南》PCB 版图布局章的每条规则翻译成物理。以后你翻任何模组 datasheet 的 layout 章，每条都能对上「为什么」。

本章路线图：13.1 先学会 PCB 的「分层语言」——多层板/叠层/过孔，软件工程师第一次看懂 PCB 的分层，以及为什么 WiFi 板常用四层；13.2 是全章的物理主轴——传输线与回流；13.3 把设计指南射频章的规则逐条翻译成「为什么」；13.4 讲天线净空 15 mm 的物理意义；13.5 收口第八、十一、十二章的布局侧；13.6 划清模组时代的分工线。

## 13.1 PCB 是什么：一块压扁的机房

软件工程师看 PCB 的第一误读是「一层绿色薄板，印了些电线」。正确的第一眼：一块由**多层铜箔与绝缘材料压合成的三明治**，表面插着器件，层间藏着「电梯井」。逐个术语配机房与背板的对照：

| PCB 术语        | 是什么                             | 机房与背板类比            |
| --------------- | ---------------------------------- | ------------------------- |
| 层（layer）     | 一层铜箔，常用板为 2/4/6 层        | 大楼的一层楼              |
| 叠层（stackup） | 各铜层的排列顺序与层间绝缘厚度     | 楼层规划图：哪层住谁      |
| 走线（trace）   | 铜箔上蚀刻出来的导线               | 总线/线缆                 |
| 过孔（via）     | 打穿绝缘层、连通两层铜的金属化小孔 | 楼梯/电梯井：换层唯一通道 |
| 铺铜（pour）    | 大面积连成片的铜（多数作为地）     | 机房公共接地铜排          |
| 焊盘（pad）     | 器件引脚焊接用的铜点               | 插槽/接线端子             |
| 阻焊（绿油）    | 覆盖铜层防短路的绝缘漆             | 线槽盖板                  |

「过孔」值得单独多说一句：它是唯一能换层的通道，但**每一次换层都是一次几何突变**——孔比线窄、孔壁有寄生电感。对数字信号这常常可以忍，对 RF 走线是明确禁区（13.3 的铁律之一）。

### 1. 四层板叠层：官方建议的楼层规划

《ESP32-S3 硬件设计指南》PCB 版图布局·电源章给出的四层板设计，每层职责（引文逐字摘自原文）：

```text
第一层 顶层    芯片、元件、信号走线、RF 50Ω 走线     「主要用于走信号线和摆件」
                  │
                  │ via（过孔）：层间电梯井，贯穿全部楼层
                  ▼
第二层 地层    ══════════ 完整地平面 GND ══════════  「不走信号线，保证一个完整的地平面」
第三层 电源层  ════ 电源走线，剩余面积铺地 ═════════  「铺地平面，使射频及晶振部分可以得到更好的屏蔽」
第四层 底层    ────────── 可适度走信号线 ──────────   「不建议摆件」
```

读出三层意思：

1. **第二层是全楼的承重墙**：整层只做地，不走任何信号——13.2 会讲为什么这一层如此金贵；
2. **第三层是兼职楼**：主力走电源，空余面积铺地——多一层地等于给射频与晶振多一层屏蔽（原文口径）；
3. **过孔是电梯井不是走廊**：它是连接手段，不是布线空间——信号「住」在哪层，比怎么连更重要。

### 2. 原理图与 layout：接口定义与部署拓扑

软件工程师常止步于原理图（schematic）：哪颗芯片接哪颗电容，像读 API 定义。但 WiFi 的很多问题只存在于 layout 层——同一张原理图，摆位不同、走线不同、地平面不同，射频性能能差出一个档次。类比：**原理图 = 接口定义与调用关系，layout = 部署拓扑**。微服务的依赖图画得再对，把两个互相干扰的服务调度到同一台宿主机上，照样互相拖累——「逻辑正确、部署错误」的系统故障，PCB 版的名字就叫 layout 错误。

这也是为什么模组与芯片厂商都随附 layout 指导文档而不只给原理图：供应商知道，成品板是「部署」出来的，不是「定义」出来的。

### 3. 为什么 WiFi 板常用四层

先官方口径，再物理翻译：

- ESP-FAQ：「为保证良好的 RF 性能，我们建议使用 4 层板设计。」
- ESP-FAQ（提高 EMC 条目）：「采用四层板设计的 EMC 性能优于两层板的硬件设计。」

物理翻译一句话：**两层板保不住完整地平面**。两层板上顶层要走信号、底层也要走信号，每根走线都会在地铜上开一道缝；13.2 会讲到，地平面上每道缝都是回流路的断头路。四层板多花的钱，买的是**一整层谁也不许走线的地**——相当于机房里专门划出一条公共回流干线，任何信号不得占用。模组自己更是如此：WROOM-1 的 PCB 按[[2026-08-29-wifi-rf-hw-ch07-wifi-soc-anatomy|第七章]]的解剖就是块小型多层板；你的底板越规整，模组搬进来越不受罪。

## 13.2 传输线与回流：信号去多远，电流就得回多远

### 1. 走线是总线，回流是它的另一半

[[2026-08-29-wifi-rf-hw-ch09-impedance-matching|第九章]]已确立：2.4G 下 PCB 走线不是「零电阻导线」，而是有特性阻抗的**传输线**——「表层铜皮 + 下方完整地平面」构成微带线，把线宽调到特性阻抗恰为 50Ω 就是「50Ω 走线」；线宽由板材介电常数、介质厚度、铜厚共同决定（一句话说完，细节与反射账都在第九章）。这里补上常被漏掉的另一半：**信号电流走多远，回流电流就得回多远**。

任何信号都是一对电流：从驱动端经走线到接收端，再**从接收端返回驱动端**，构成一个闭合环路。低频下回流「抄电气上的近道」随意走；高频下回流走阻抗最小路径，而高频的阻抗最小 = 电感最小 = **紧贴信号线正下方的地平面**（高速 PCB 设计的教科书结论）。于是健康状态长这样：

```text
完整地平面（健康的回流）：

  顶层   A ═══════════ 信号电流 →════════════════ B
  地层   ◄══════════ 回流电流：贴着走线正下方原路返回 ════
         环路面积 ≈ 走线长度 × 层间距（零点几毫米量级）→ 又窄又扁，安静
```

### 2. 割地平面 = 挖断回家的路

地平面上一道缝（被另一根走线、一个过孔群、一个挖空区切断），回流的「回家路」就被挖断了：

```text
地平面被割缝（回流被迫绕远）：

  顶层   A ═══════════ 信号电流 →════════════════ B
                ┆ 割缝 ┆
  地层   ◄═绕行═══════┆       ┆═══════绕行═►
         回流只能从缝的一端兜大圈回来

  环路面积不再是「走线 × 层间距」，而是绕行圈围出的面积——大几个数量级
```

软件类比：**信号与回流是配对的请求和响应**。每个 RPC 请求都默认有一条响应通道；在板上，这条「响应通道」就是正下方的地平面。所谓「地随便割」，等于把响应通道从公共干线上拆了——请求照发，回程被迫绕远，而绕出来的大环路就是一根**不情愿的天线**：对外，它把信号的边沿谐波辐射出去（EMI，认证测试在这栽跟头）；对内，别人的干扰场在这个大环里感应出电压（被干扰，第十四章的素材）。干扰别人与被人干扰，同源于「环路面积」。

这也是第九章埋的伏笔的正式回收——「为什么射频区下方必须完整地平面」：RF 走线的地平面身兼两职，既是微带线的**参考平面**（50Ω 特性阻抗的下极板，割了它阻抗就变，[[2026-08-29-wifi-rf-hw-ch09-impedance-matching|第九章]]的反射立刻上门），又是 RF 电流的**回流路径**（割了它环路暴涨）。两层职责一个结论：**RF 走线正下方的地，一个缝都不许有**。指南原文：「射频走线须保证相邻层完整地平面，射频走线下方尽可能不要有任何走线。」

顺手解一个常见困惑：「地不是都连在一起吗，割一刀怎么了？」——直流视角下确实都连着，万用表量还是 0Ω；高频视角下，地平面是**有形状的导体**，缝改变了回流的路径形状，也就改变了电路行为。同一块铜，直流看拓扑，高频看几何——与「表结构一样、索引不同则性能天差地别」同类：**连接正确不等于行为正确**。

### 3. 回流视角的三个工程推论

把「回流走正下方」当成检查器，三条通行结论（高速 PCB 设计通识，非乐鑫文档原文）自然掉出来：

1. **信号换层，回流也要跟着换层**：走线从顶层打过孔到内层，参考平面变了，回流得靠信号过孔旁就近的地过孔「换乘」。只给信号打孔、不给回流打孔，等于人换了楼层却拆了楼梯——回流又被逼着绕路。
2. **跨分割走线是最差走位**：走线越过地平面的缝（13.2.2 图里的情形）不只是绕远，缝两侧地平面的电位还可能不一致，信号质量双重劣化。检查 RF 与时钟线是否跨分割，是硬件评审的例行动作。
3. **「走线不串区」是零成本的隔离**：分区摆好（RF 区、晶振区、数字区、电源区各就各位）之后，绝大多数干扰问题在走第一根线之前就已经避免——先分间、再摆家具，是机房管理员和 PCB 工程师共享的工作流（13.5.4 展开成完整流程）。

## 13.3 RF 区铁律清单：官方原文与物理翻译

机房类比里，RF 区是**敏感区**：进去的每根线、每个孔都有讲究。下表把《ESP32-S3 硬件设计指南》PCB 版图布局·射频章的规则逐条列出，「官方原文」列逐字摘引，右列是它背后的物理：

| 铁律                     | 官方原文（摘引）                                                        | 背后的物理                                                    |
| ------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------- |
| 50Ω 阻抗控制             | 「射频走线需做 50 Ω 阻抗控制，参考平面为芯片邻层」                      | 接口协议（第九章）；参考平面是微带线的下极板                  |
| 线宽一致、无分支、尽量短 | 「射频走线线宽请注意保持一致，不可有分支走线。射频走线长度须尽量短」    | 几何突变即阻抗突变即反射点；分支是一根意外的短截线            |
| 不拐直角                 | 「尽量使用 135° 角走线或是圆弧走线」                                    | 直角处线宽局部变宽、寄生电容增大，局部阻抗跌落——一个失配台阶  |
| 不打过孔、不跨层         | 「走线不可有过孔，即不能跨层走线」                                      | 过孔自带寄生电感，换层又是一次几何突变                        |
| 下方完整地平面           | 「射频走线须保证相邻层完整地平面，射频走线下方尽可能不要有任何走线」    | 参考平面 + 回流路径，13.2 的全部内容                          |
| 远离高频数字线           | 「射频走线附近不能有高频信号线」                                        | 数字沿的谐波正好落进 2.4G 频段（第十四章预告），双向干扰      |
| USB/UART 远离天线        | 「USB 端口、USB 转串口信号的芯片、UART 信号线……都必须尽可能地远离天线」 | 串口芯片与 USB 口是板上的辐射源，天线是最好的接收器           |
| 密集地孔屏蔽             | 「注意周围密集地孔屏蔽」                                                | 地孔阵是把「屏蔽罩的地基」打进板里，圈住泄漏的场              |
| IPEX 焊盘下方全层净空    | 「IPEX 天线连接器下方建议全部层净空」                                   | 焊盘是刻意设计的 50Ω 端口，下方各层的铜改变其寄生电容导致失配 |
| 匹配元件贴脚、Z 字摆放   | 「请使用 0201 器件，把匹配器件靠近管脚放置，并呈 Z 字型摆放」           | 封装越大引线越长，寄生电感越大，匹配精度被吃掉（第九章）      |

三个值得展开的「为什么」：

1. **直角到底错在哪**：不是「尖角刮人」，而是拐角处铜皮变宽，对地电容变大，那一小段的特性阻抗局部跌落——信号每过一次拐角就过一次阻抗台阶，反射一点、失配一点（第九章的账）。量级上也能对齐：2.4G 波长 12.5cm，λ/10 才 12.5mm（第九章的传输线判据），拐角这种毫米级几何细节**全在电路参数尺度内**，不是美学问题。
2. **IPEX 焊盘挖空的口径**：指南原文用词是「建议」（非「严禁」），但方向明确——焊盘和它的匹配元件是按 50Ω 设计的端口，任何一层多出来的铜都在改它的寄生参数。翻官方评估板的 layout 工程文件，IPEX 座正下方四层皆空，就是这条规则的现场。
3. **「远离数字线」是双向条款**：数字线骚扰 RF（谐波落入频段），RF 也骚扰数字线（发射瞬期的功率摆动）。所以分区不是保护弱者，是隔离两个互相影响的机房租户。

## 13.4 天线净空：15 mm 不是留白，是天线的身体

### 1. 两条官方口径，一个数字

- ESP-FAQ（「使用板载天线的模组，对 PCB 和外壳设计有哪些要求？」条目）：「请确保模块不被任何金属的外壳包裹，模块 PCB 天线区域及外扩 15 mm 区域需净空（严禁铺铜、走线、摆放元件）。」
- 《ESP32-S3 硬件设计指南》PCB 版图布局·基于模组的版图设计通用要点：「建议将模组天线区域伸出板边」、馈点靠近底板板边放置；整机外壳内的净空「该净空区域建议至少 15 mm（所有方向上都是）」。
- 同章另一条常被读拧的话：「请注意在天线附近的底板上铺上充分的地和密集的地孔。」——它与净空不矛盾：**天线正区净空、周边铺地**。净空区是舞台，紧邻区外的大片良好地平面是舞台的地基。

### 2. 物理翻译：近场里的一切都是天线的一部分

**天线不是那块铜，是那块铜加上它周围的场。**紧贴天线的空间（术语：反应近场，reactive near field）里，电磁场在与天线交换能量而不是离开它——教科书口径，电小天线的反应近场大致延伸到 λ/2π；2.4G 的 λ=12.5cm（[[2026-08-29-wifi-rf-hw-ch03-decibel-family|第三章]]口径），λ/2π ≈ 2cm。15 mm 与它同量级；换个算法，15 mm ≈ λ/8。**净空要求是波长尺度上的要求，不是排版偏好**（两个换算都是对照量级，乐鑫文档未给出推导）。

塞进这个空间的任何东西——铺铜、走线、电池、排线、螺丝、外壳、手掌——都会被近场抓住，成为天线的一部分：介电物（塑料、手、电池）拉偏谐振频率（第九章的失谐 detuning，VSWR 恶化），导体（铜、金属壳）抢走场能、扭曲方向图（[[2026-08-29-wifi-rf-hw-ch06-antenna-basics|第六章]]）。第九章的观察实验「手掌盖住天线，RSSI 立掉数 dB」，就是往净空区里塞了一只手的现场版。

机房类比：**净空区不是闲置面积，是精密仪器的防振净空、乐器的共鸣腔**——往钢琴里塞毛巾，琴还是琴，但已经不是那架琴了。

把「净空区里出现它会发生什么」整理成速查表（失谐与反射的账在第九章，方向图在第六章）：

| 塞进净空区的东西   | 物理身份       | 后果                                  |
| ------------------ | -------------- | ------------------------------------- |
| 铺铜、走线         | 导体           | 抢走场能、拉失谐，反射上升            |
| 电池、螺丝、金属件 | 导体           | 失谐 + 方向图扭曲                     |
| 排线、馈线         | 导体且载有信号 | 失谐之外还充当「寄生天线」辐射与拾取  |
| 塑料外壳、标签     | 介电物         | 介电常数拉偏谐振频率（程度较导体轻）  |
| 手掌、人体         | 介电物且有损耗 | 失谐 + 吸收，RSSI 立掉数 dB（第九章） |

### 3. 金属外壳：法拉第笼与开窗

金属外壳对电路是优秀屏蔽（第十章的 FEM 板要靠屏蔽罩伺候），对天线却是灾难：指南与 FAQ 的口径一致——不被金属外壳包裹。工程解法三条（第九章对策的回收）：外壳在天线区**开窗**（局部挖掉金属或改非金属）；天线区整体改用塑料、玻璃等非金属；或用 IPEX 把天线**请出壳外**。第三条最彻底，但代价是延长线的线损与失配账——第九章 9.6 的遭遇战与第十八章的决策链管这笔账。

## 13.5 晶振、电源、去耦：三章的布局侧收口

第八、十一、十二章分别在元件、时钟、电源视角讲过它们；这里只做**布局侧**收口——它们在板上住哪儿。

### 1. 去耦电容：就近不是洁癖，是电感账（第八章）

[[2026-08-29-wifi-rf-hw-ch08-passives-in-rf|第八章]]算过：去耦电容是「缓冲池」，它到芯片电源脚每多一毫米，走线电感就多一分，高频缓冲效果就打折扣——原理图上的「电容贴脚放」，落到 PCB 上就是「焊盘贴脚焊」。软件同款：本地缓存必须贴着计算节点放；内存再大，放在跨机房那就不是缓存了。

### 2. 晶振：精密仪器的独立隔间（第十一章）

指南晶振章的规则（逐字摘引）合起来就是一份「精密仪器安置说明」：

- 「晶振下方都不能走高频数字信号，最好是晶振下方不走任何信号线。」
- 「晶振为敏感器件，晶振周围不能放置磁感应器件，比如大电感等，保证晶振周围有干净的大面积地平面。」
- 「同时晶振走线须用地包起来，周围用密集的地孔屏蔽隔离。」
- 「晶振需离芯片时钟管脚稍远一些放置，防止晶振干扰到芯片。间距应至少为 2.0 mm。」

第二条是「晶振远离开关电源」的官方依据：DCDC 的功率电感是板上最典型的「大电感」；ESP-FAQ 版图常见问题还有反向口径——「晶振旁边有感性器件或辐射器件，比如大电感、天线等也会导致芯片的射频性能不好」。天线与晶振互为对方的干扰源：射频章要求天线「远离所有传输高频信号的器件，比如晶振、DDR SDRAM、高频时钟等」，晶振章要求晶振远离大电感——**两个敏感区分开住，中间隔地**。频偏的故障模式（看着好好的设备连不上）是[[2026-08-29-wifi-rf-hw-ch11-crystal-clock|第十一章]]的主场。

### 3. 电源与地：强电间的规矩（第十二章）

布局侧只有两条，都出自指南电源章：

- 「芯片下方的地焊盘需要至少打九个地孔连接到地平面。」——芯片的地要用**多个**过孔就近下地，而不是一根细走线绕远；发射瞬间数百 mA 的电流毛刺（第十二章的主场，[[2026-08-29-wifi-rf-hw-ch10-rf-front-end-fem|第十章]]引过 11b 满功率约 355 mA 的模组口径）要从这儿痛快泄掉。
- 「芯片及其外围电路的器件地焊盘，建议和地铺铜充分接触，不要用走线连接。」——地连接要「面接触」不要「线接触」，电阻与电感都更小。

机房租约最后一条：强电间（DCDC、大电感）与敏感区（RF、晶振）分居板子两端，中间用地平面和距离隔开——不分区的板子，等于把 UPS 和频谱仪插在同一个插线板上。

### 4. 布局顺序：先分间，再摆家具

三章收口之后，布局的通行工作流（机房管理员视角，通行做法而非乐鑫文档条文）也顺理成章：

```text
1. 分区：RF 区、晶振区、电源区、数字区先划地盘（强电与敏感区分居两端）
2. 摆关键件：天线与馈点靠板边、去耦电容贴脚、晶振进独立隔间
3. 走线：RF 先走（短、直、不跨层），时钟次之，数字与电源让路
4. 铺地与地孔：地平面保完整，敏感区周围密集地孔
```

顺序本身就是规则：先分间（分区）决定干扰的物理隔离，再摆家具（布局）决定回路的长短，最后才是装修（铺铜）。软件同款：先划服务边界，再定部署拓扑，最后调参——顺序错了，后面每一步都在还债。

## 13.6 模组时代的分工线：WROOM 已替你踩过的坑

[[2026-08-29-wifi-rf-hw-ch07-wifi-soc-anatomy|第七章]]的结论复述：**裸片 = 散件 CPU，模组 = 品牌整机**。整机买回来还要摆进机房——模组解决了「整机内部」的 RF 布局，解决不了「机房」（你的底板与外壳）的环境。

### 1. 模组已经替你解决的

| 模组内已做好                        | 对应章节与口径                                                   |
| ----------------------------------- | ---------------------------------------------------------------- |
| 芯片 RF 脚到天线口的 50Ω 走线与匹配 | 本章 13.3 的铁律由模组厂在自己的小板里执行（第九章的匹配网络）   |
| 板载天线设计与模组板内净空          | 第六章：乐鑫要求 PCB 天线「务必同时通过仿真与实际测试验证」      |
| 屏蔽罩                              | ESP-FAQ：「屏蔽盖应该采用导电材料，并接地处理，以确保其有效性」  |
| 出厂认证                            | 第七章：认证与天线绑定，换高增益天线理论上要重认（第十七章展开） |

### 2. 还留给你的三笔账

1. **摆位**：模组往底板上一放，天线区是否伸出板边、馈点是否靠板边、净空是否被你的走线/铺铜/元件占掉——指南模组章明确「建议将模组天线区域伸出板边」，也明确不推荐把模组放板子中间「四周挖空来提供净空区」。模组再好，摆错位置全白搭。
2. **外壳与净空**：金属外壳开窗、15 mm 净空、天线边别堆电池排线——13.4 的全部内容，模组的手伸不到壳外。
3. **延长线与外置天线**：第九章 9.6 的遭遇战全套——75Ω 视频线、虚标地摊线、自焊 IPEX 座、自制转接板（转接板上的走线就是微带线，线宽不对特性阻抗就不对）。这笔线损账在第十八章的决策链里细算。

一句话分工线：**模组负责「出厂时是好的」，你负责「装进你的产品后还是好的」。**

### 3. 观察点：不花一分钱，把本章看一遍

1. **读原文**：打开《ESP32-S3 硬件设计指南》的 PCB 版图布局章（docs.espressif.com，esp-hardware-design-guidelines 项目 esp32-s3 分册），对照 13.3 的表逐条找官方配图——第一次以「物理翻译」的眼光读设计指南。
2. **翻实物**：拿一块 ESP32 开发板，看模组天线区是否伸出板边、天线周围是不是一圈「什么都没有」、天线外侧的底板上是不是大片铺铜加密集过孔——13.4 的三条规则在量产板上的样子。
3. **塞盒子**：用 WiFi 分析仪 App 盯住设备的 RSSI，把设备分别放进塑料盒与金属盒（饼干罐即可）对比读数（待真机验证）——法拉第笼的现场教学，第十五章再用 ESP32 系统复测。

## 13.7 常见误区表

先说观察：下面每条误区几乎都来自两个母题——「把低频直觉带进高频世界」或「把模组当成全保险」。对号入座：

| 误区说法                                     | 实情与出处                                                   | 软件类比                           |
| -------------------------------------------- | ------------------------------------------------------------ | ---------------------------------- |
| 「地都连着，割一刀没事」                     | 高频看几何不看拓扑；割缝 = 回流绕行 = 环路暴涨（13.2）       | 表结构一样、索引不同，行为天差地别 |
| 「RF 走线拐直角只是难看」                    | 指南要求 135° 或圆弧；直角 = 局部阻抗台阶 = 反射点（第九章） | 管道口径突变处必有反射与湍流       |
| 「打个过孔把 RF 线换层继续走」               | 指南：射频走线「不可有过孔，即不能跨层走线」                 | 总线中间随手插转发器，完整性没人管 |
| 「天线区下面走根数字线没关系，反正没碰天线」 | ESP-FAQ：天线区及外扩 15 mm「严禁铺铜、走线、摆放元件」      | 往精密仪器防振台上压了一台风扇     |
| 「两层板便宜，WiFi 板也一样用」              | ESP-FAQ：「为保证良好的 RF 性能，我们建议使用 4 层板设计」   | 全走公网不建内网，能用但别指望性能 |
| 「去耦电容随便放，电气上连着就行」           | 每多一毫米走线电感多一分（第八章）                           | 缓存放跨机房，就不是缓存了         |
| 「晶振那么小，放哪都行」                     | 指南：远离大电感、下方不走高频数字信号、周围要干净大地平面   | 把频谱仪插在强电间的插线板上       |
| 「金属外壳结实，天线装里面正好」             | ESP-FAQ：「请确保模块不被任何金属的外壳包裹」                | 把无线路由器锁进保险箱             |

## 13.8 小结

- **一组类比到底**：PCB = 主板/背板；层 = 楼层；过孔 = 电梯井；走线 = 总线/传输线；地平面 = 回流路径（回家路）；布局 = 机房摆位——RF 区是敏感区、晶振是精密仪器、电源是强电间、净空区是共鸣腔与防振净空。
- **一个物理主轴**：信号电流走多远就得回多远，回流走正下方；割地平面 = 挖断回家的路，环路面积暴涨，EMI 与被干扰同源。地平面身兼「参考平面」与「回流路径」两职，这就是 RF 走线下方一个缝都不许有的全部原因。
- **官方事实锚点**（出处：《ESP32-S3 硬件设计指南》PCB 版图布局章与 ESP-FAQ hardware-design.rst，原文逐字核对）：RF 走线 50Ω 阻抗控制、线宽一致无分支、135° 或圆弧、不可过孔、下方完整地平面、附近不能有高频信号线；IPEX 焊盘下方「建议全部层净空」；板载天线模组的天线区及外扩 15 mm 净空（严禁铺铜、走线、摆放元件）、不被金属外壳包裹；四层板叠层（顶层信号/第二层完整地/第三层电源铺地/底层少摆件）与「建议 4 层板」；晶振远离大电感与高频器件、下方不走高频数字信号；芯片地焊盘至少九个地孔、器件地与铺铜充分接触。
- **模组分工线**：模组负责出厂时是好的（匹配、天线、屏蔽、认证），你负责装进产品后还是好的（摆位、净空、外壳、延长线）。
- **伏笔与去向**：数字谐波与共存机制 → 第十四章；延长线的线损账 → 第十八章；频偏故障模式 → 第十一章；失配与反射账 → 第九章；RSSI 复测实验 → 第十五章。

一句话版本：**PCB 是压扁的机房——走线是总线，地平面是回家的路，净空区是共鸣腔；割地等于挖路，占净空等于往钢琴里塞毛巾。**

下一章把「不打架」讲完：2.4G 频谱里的邻居——微波炉、USB 3.x、蓝牙——谁在干扰谁，共存机制怎么调度，以及用共存视角重看 BOX-3 的 BLE+WiFi 配置，见[[2026-08-29-wifi-rf-hw-ch14-interference-coexistence|第十四章：干扰与被干扰]]。
