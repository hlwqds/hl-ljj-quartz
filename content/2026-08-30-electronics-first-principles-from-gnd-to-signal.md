## Part I：水与电的骨架

### 第 1 讲：GND 是什么——回水管与海平面

把电路想成水管系统：**水泵=电源，水管=导线，水车=芯片**（被水流冲着转就干了活）。
电不会凭空消失，必须走一圈回到出发点——出去的线（3.3V）和回来的线（GND）缺一根
水车就不转。所以板上那么多 GND 引脚，作用就一个：**当回水管**。

GND 同时是**海平面**：说"这个脚 3.3V"必须有起算零点，GND 就是全系统公认的那条
零线。万用表黑表笔接 GND、红表笔量信号脚，读的是"比 GND 高多少"。

**共地规矩**：两块板之间传信号，必须先把 GND 连起来——否则两家的"3.3V"不是同一
个 3.3V（两个海平面没法比海拔），轻则读数乱跳，重则电流找错回路烧器件。
**先接 GND，再接信号线；拆线反向，最后拆 GND。**

### 第 2 讲：回路——电的世界没有单行道

```text
        去程：电源说"给"
        ┌──────────────────────┐
        │                      ▼
     ┌──┴───┐   信号/电源线    ┌──┴───┐
     │ 电源 │ ══════════════► │ 器件 │
     │      │                 │      │
     │      │ ◄══════════════ │      │
     └──▲───┘      GND        └──────┘
        └────── 回程，同一股电 ──────┘
```

任一瞬间，信号线流出多少电流，GND 上就流回多少——不是两股水，是**同一股电的来回**。
由此立下一条硬规矩：**靠导体吃饭的器件至少两个端子**（一进一出）。电阻/LED 是两脚
最简形态；传感器模块 VCC/GND/数据是三脚标准形态。

两个著名变体：汽车的"搭铁"（回程走车身，整辆车就是地线）；19 世纪电报的地回路
（一根线+大地当回程）。以及一个零线特例：**RFID/NFC 卡一个外接端子都没有**——靠
内置线圈从电磁场"收麦子"获能，环路藏在自己体内。

### 第 3 讲：接线心法——按脚的职责接，不按名字接

每个脚按职责分四类，接哪根线由职责决定：

| 脚的名字                | 想干什么                     | 接去哪       |
| ----------------------- | ---------------------------- | ------------ |
| GND / VSS               | 回水+当基准                  | 对面的 GND   |
| VCC/3V3（传感器模块上） | 真喝水（供电）               | 对面的 3.3V  |
| VREF（调试器上）        | 量水压（电平参考，只看不喝） | 对面的 3.3V  |
| TXD/RXD/SDA/…           | 传话（电压抖动）             | 对面的信号脚 |

三条总结律：**GND 越连越大**（全世界共地成一片）；**电源各回各家**（两板的 3.3V
永不要并联——两台水泵打架）；**方言要对齐**（见下讲）。

## Part II：压力与方言

### 第 4 讲：为什么是 3.3V——一个有户口的标准

3.3V 登记在 **JEDEC JESD8 系标准**里（JESD8-B：3.3V LVTTL/LVCMOS）；5V 的地位
来自 1964 年 TI 7400 系列 TTL 的历史事实。从 5V 搬到 3.3V 是物理逼的：

- **功耗 ∝ 电压²**：5→3.3V 动态功耗只剩 44%；
- **晶体管越小越经不起高压**：栅氧化层薄到几个原子，5V 直接击穿。

这条沟今天还在往下走：5V→3.3V→1.8V→~1V（你的 CPU 内核就住在沟底）。3.3V 停站
的原因：①门限故意照抄 5V TTL（VIH=2.0V/VIL=0.8V，过渡期无痛）；②锂电 3.7V 一步
降到 3.3V；③传感器/树莓派/ESP32/STM32 生态滚雪球。**电（USB 5V）和数据（引脚
3.3V 方言）是两回事**——5V 进板被稳压器降成 3.3V 再喂给 I/O。

### 第 5 讲：电平对齐与 VREF——让双方说同一种方言

判读门限（3.3V 家族典型）：高于约 2.0V 判 1，低于约 0.8V 判 0，中间是禁区。
**两板能对话 = 发方的高电平够得着收方的判 1 线**——靠的是同家族，不靠连电源。

野火 DAP 的 VREF 脚就是"方言校准线"：**输入脚，不是供电**——接上目标板 3.3V 后
DAP 知道按 3.3V 的音量收发。板侧"VREF 脚"与排针"3V3"是**同一根 3.3V 轨的两个
引出口**（丝印按用途 vs 按本体命名，电气上同一片铜）。同板 GND 随便挑就近接，
3V3 同理；**跨板只共地、不并电源**。

### 第 6 讲：供电树——5V 引脚为什么存在

挑战者底板的供电（原理图 V2.0 实核）：

```text
Mini-USB 5V ──[自锁开关/保险丝]──────────┐
                                         ├──► 5V 总管 ──► 5V 排针
DC 座 6~12V ──[保险丝/TVS]──[DC-DC降压]──┘       │
                                          [LDO 小减压阀]──► 3.3V ──► 3V3 排针+全板芯片
```

- **5V 排针**=减压阀之前的总管开口，伺候大饭量外设（舵机/继电器/灯带）；舵机就是
  "喝 5V 的水、听 3.3V 的话"的典型（电源脚与信号脚各接各的）。
- **3V3 排针**=减压阀之后的细水，额度通常几百 mA——带大件别指望它。
- **硬规矩：USB 与 DC 一次只插一个**（防灌电流损坏电脑 USB 口）。日常 USB 足够
  （全板 ~百 mA），插大件后莫名复位 = 预算被拉穿，该换 DC。

## Part III：危险与防御

### 第 7 讲：超压烧毁的机理——挨打的是耐压低的一方

烧的从来不是施暴方：**380V 接进 220V 电器，烧的是电器，电网无恙**。每个 3.3V 芯片
引脚内部有保护结构（上下钳位二极管+栅氧化层），5V 一来：上钳位二极管被迫持续导通
（它只为纳秒级静电泄放设计，**热死**），或栅氧化层被强场**击穿**（几个原子厚，
额定 ~3.6V）——都不可逆。

判据去手册查两处：**Absolute Maximum Ratings**（如 VDD+0.3V，超过=开始物理破坏）；
**引脚表的 FT 标记**（Five-volt Tolerant：无上钳位、耐 5V 输入——STM32 一部分脚是
FT，树莓派 BCM2711 一个 FT 都没有）。

### 第 8 讲：防烧三件套——方向盘从来不在 GND 手里

| 想控制什么         | 专职零件         | 工作方式                             |
| ------------------ | ---------------- | ------------------------------------ |
| 方向（只许单向流） | 二极管（单向阀） | 反向截止——电源防反接就是它           |
| 大小（限流）       | 电阻/保险丝      | 电阻压流量；保险丝超流自爆断路       |
| 能量（超压泄放）   | TVS/钳位二极管   | 电压超标开阀，把多余能量**泄进 GND** |

GND 在 TVS 方案里是泄放目的地，但发号施令的是那颗阀。DC 输入的防线（实测核过）：
**TVS 烧穿自己 → 拉爆保险丝 → 保住后面全家**。超 12V 三档结局：略超=吃余量；
15~18V=赌博区；19V/24V=防线逐级触发，看设计赌运气。

### 第 9 讲：电流不足的四步侦探法（含实测黑匣子）

1. **看发作时刻**：故障总跟着大电流动作（插外设/转电机/亮屏）→ 高度怀疑供电；
2. **量电压 + MIN/MAX 锁存**：万用表搭供电脚，反复触发动作，看瞬间是否跌破 ~3.0V；
3. **减载对照**：拔掉别的外设 / 大件独立供电（共地）→ 好了=实锤板端带不动；
4. **读复位黑匣子**（实测）：`mdw 0x40023874`（RCC->CSR）——位号 25=BOR/26=PIN/
   27=POR/28=SFT/29=IWDG。**只有 BOR 没有 POR = 运行中欠压实锤**；清空重记
   `mww 0x40023874 0x01000000`，一次 NRST 后应只剩 PIN 单旗（当晚实测 0x0E000000→
   清空→0x04000000，完整复述了"拓展坞断电史"）。读前必须 `reset run`。

供电不足的机理：内阻+线阻吃掉电压（V = V源 − I×R），表象永远是**电压跌落**——
所以诊断主战场是量电压不是量电流（并联一搭 vs 断线串入）。

## Part IV：流动的细节

### 第 10 讲：回流与环路——为什么 20 脚座有 9 根地

对比两种布线（俯视环路大小）：

```text
独木桥（一根地）：                    交替接地（每信号一根地）：
┌──────────────────────────┐        ┌────────┐┌────────┐┌────────┐
│ SIG1 ──────────────┐     │        │ SIG1 ► ││ SIG2 ► ││ SIG3 ► │
│ SIG2 ────────────┐ │     │        │ GND  ◄ ││ GND  ◄ ││ GND  ◄ │
│ SIG3 ──────────┐ │ │     │        └────────┘└────────┘└────────┘
│                 ▼ ▼ ▼     │          环路极小=安静
│           ◄─ 独木桥 ─     │
└──────────────────────────┘
  环路巨大=天线；独木桥电流=总和→"0"在晃（地弹）
```

经典 20 脚 JTAG 座偶数排（4~20）全是 GND=9 根，是"信号夹地"的标准做法：①每股
回流就近走贴身地（环路最小）；②地是信号间的隔音墙（防串扰）；③空位宁接地不留
悬空（地是最廉价且永不犯错的填充物）。这是 PCB 地平面（WiFi RF 系列第十三章）在
连接器上的平替。进阶一句：**回流偏爱贴着来路走**（场抵消最干净、电感最小）。

### 第 11 讲：蜂鸣档的原理——表自带小水泵

万用表通断档：**表内电池主动发几毫安**从红表笔出、经被测物、黑表笔回，量出回路
电阻，小于门限（几十欧）就响。它自己带水，不需要被测电路有电——所以**量通断必须
断电**（外部电压会搅乱判读，极端反灌伤表）。同一片铜会响（电阻≈0），断路沉默，
虚焊触点几百欧不响——这就是它能查出"虚焊"的原理。电压档反之：被动读压差，
要带电测。

## Part V：看不见的层面

### 第 12 讲：能量不在铜里跑

能量以电磁场的形式**在导线周围的空间**里流动，铜线只是河道。回路必须闭合的本质：
**能量河道两头接通才能建立流动**，断一处场就停摆。日常佐证：合闸瞬间灯亮——不是
电子跑到（导线里电子比蜗牛慢），是**场以近光速沿回路瞬间建立**。

连隔空传能都长着环：变压器/无线充电的接收端是线圈——场穿过线圈感应电流。
**"环"是能量交换的通用形状，金属回路只是其一。**

### 第 13 讲：信号=约定的变化，码本给变化以意义

信号的本质：**让电压/电流按约定变化**。变化的维度有四族——电平（GPIO/UART 数据位：
频率没变，信息在高低）、频率（蜂鸣器音高/PWM/FM）、时序（115200 的 86.8µs 时间片/
摩斯码）、幅度与相位（WiFi 的 QAM）。

但光有变化不构成信号——**必须双方持同一本码本**：同一串 0↔3.3V 跳动，约定成
115200 8N1 是字符，约定成 SPI 是时钟数据，没约定就是噪声。乱码的本质=码本错位
（那晚 8E1 vs 8N1 的校验位事故：变化相同，解读差一位，意义全毁）。

### 第 14 讲：四句话合起来的第一性原理

> **GND 是基准和回程 → 回路是能量的河道（能量在场里走）→ 变化+码本构成信号 →
> 防烧靠插进回路的阀（方向/限流/泄放）。**

所有你将遇到的东西——UART/SPI/I2C/SWD/以太网/WiFi——都是这四句话上的码本排列组合。
