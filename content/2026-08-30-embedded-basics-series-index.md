# 嵌入式硬件基础系列索引

> [!tip] 系列说明
> 本系列面向**系统/网络背景的工程师**——RTOS 与网络栈已经读到源码级，缺的是"从比特到引脚"的硬件手艺。讲法大量借用你已有的心智模型：逻辑分析仪是 tcpdump（抓时间线）、NVIC 是可编程的中断分发器、万用表是看稳态的 `ip addr`。
>
> 平台铁律：**STM32F407VET6（Cortex-M4F）+ GD32VF103（RISC-V RV32IMAC）双架构主线**——GD32VF103 是 STM32F103 的寄存器级近似双胞胎，同任务双板重做，差异本身就是架构知识（向量表 vs mtvec、NVIC vs ECLIC、PendSV vs machine timer）。ESP32 一律不进教学主线，唯一出场位是综合项目章的"WiFi 协处理器"选型讨论。
>
> **无板先行机制**：板卡未到位。先行章（理论/协议/工具链/QEMU 代码）已在本机用 `arm-none-eabi-gcc` + `qemu-system-arm`（`-M mps2-an385`，该机型带 UART/SysTick/定时器模型，ch03/04/07/08 的实验构成全系列技术底座）真实跑通，证据可复现；核心价值在接线与电气实操的章节先发理论骨架 + 接线图 + 预期现象（标注"真机待验证"），板到后按文末回填路线补实测。类型标记：**✅ 已发布·先行**（无板即可完整学习）、**🔒 真机占位**（理论骨架就绪，实测待板）、`✅ + 🔒`（主体先行发布，内含真机占位小节）。

## 建议阅读顺序

- **急着上手的**（先跑起来再说）：第一章 → 第四章直接拿到"能编译能运行"的模板工程与第一行 QEMU 输出 → 第三章补齐启动背后到底发生了什么 → 第七章中断 → 其余按需跳读。
- **系统消化的**（推荐）：严格按 1→12 顺序推进。Part I 立好工具与路线，Part II 打通裸机内功，Part III 是外设交互主战场，Part IV 换架构视角加深理解，Part V 收官。
- **只补某块的**：启动/链接 → 第三、四章；中断 → 第七章；定时/PWM → 第八章；串口协议设计 → 第六章；总线选型 → 第十章；RTOS port 层 → 第九、十二章。

## 板卡到位后的回填路线

占位章按依赖顺序激活，每步都复用上一步的成果：

1. **F407 到位** → 第五章真机点灯 + 第八章 PWM 呼吸灯（同一套 RCC→GPIO 链路最先闭环）；
2. → 第六章双板 UART（需两块板或 USB-TTL，跑成帧协议与六行破坏性实验表）；
3. → 第十一章 SWD/openocd（调试器到位即激活，反过来支撑后续外设排障）；
4. → 第十章 I2C/SPI 接 BME280 首读（datasheet 指南落地为实测）；
5. **GD32VF103 到位** → 装好 RISC-V 工具链，用第九章对照表重做点灯/UART，差异即架构知识；
6. 最终进入综合项目（主控 + ESP32 WiFi 协处理器选型），与 FreeRTOS/lwIP 系列会师。
