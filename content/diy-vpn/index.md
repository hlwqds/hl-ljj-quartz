# 手写 VPN 系列

> [!tip] 系列说明
> 本系列与 [[vpn-deep-dive|VPN 与隧道技术系列]]是姊妹篇：那个系列**拆别人的轮子**（IPSec/WireGuard/Shadowsocks 的协议分析，50 章），本系列**亲手造一个轮子**——从最简单的明文 UDP 隧道起步，逐步加上加密、完整性、防重放、密钥交换、虚拟网卡、路由，最后装配成一个能跑的 mini-VPN，并逐项回答"它和 WireGuard 还差在哪"。
>
> 一句话路线：**隧道（把包塞进包）→ 加密（ChaCha20）→ 完整性（HMAC/防重放）→ 密钥交换（DH）→ TUN 虚拟网卡 → 路由 → 对照真实协议 → 生产化**。每个零件都是可编译运行的 C 工程（`practice/vpn-labs/`），由浅入深，每章解决上一章留下的"但是"。
>
> 配套阅读：[[p2p-deep-dive|P2P 网络深度解析系列]]（NAT 穿透、mesh 组网——WireGuard/Tailscale 的另一半血统）。
