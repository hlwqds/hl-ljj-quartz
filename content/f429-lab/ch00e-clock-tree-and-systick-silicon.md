## 1. 名字破译：H 和 S 在说什么

| 名字        | 全称                | 是什么                                                | 助记                   |
| ----------- | ------------------- | ----------------------------------------------------- | ---------------------- |
| **HSI**     | High-Speed Internal | 内置 RC 振荡器，16MHz，白送但 ±1% 不准                | 自备小发电机           |
| **HSE**     | High-Speed External | 外接晶振，本板 25MHz，±50ppm 级准                     | 市电                   |
| LSI/LSE     | Low-Speed ×2        | 32kHz 慢钟，喂 RTC/独立看门狗                         | 应急灯电路             |
| **PLL**     | Phase-Locked Loop   | 倍频器（环）                                          | 升压变压器             |
| **SYSCLK**  | System Clock        | 三选一（HSI/HSE/PLL）后的系统主时钟                   | 总闸后主干线           |
| **HCLK**    | AHB Clock           | SYSCLK÷AHB 分频 = **CPU 内核时钟** = SysTick 的节拍源 | 主干电网（H=AHB 的 H） |
| **PCLK1/2** | APB1/2 Clock        | HCLK 再分压给外设区                                   | 区域变电所             |

**"时钟"= 一根送方波的线**。信号即约定变化（[[2026-08-30-electronics-first-principles-from-gnd-to-signal|第一性原理第 15 讲]]）——时钟就是全芯片共用的节拍变化，每个上升沿所有触发器同步更新。**时钟树 = 从一个源头经倍频/分频/开关，把节拍配送到全芯片的电网**。

## 2. 我们板上的真实时钟树（每个数字都实测过）

```text
HSI 16MHz ──── 不用（但上电默认它撑着——PLL 翻车夜系统就是靠它活着）
                  └─ 上电复位 ⇒ SYSCLK 先跑 HSI 16MHz，固件再逐步切换

HSE 25MHz(晶振) ──► PLL 倍频器：
                       ÷M(25)   → 1MHz     进环前先降频（VCO 输入必须 1~2MHz）
                       ×N(360)  → 360MHz   VCO 输出（必须 192~432MHz）
                       ÷P(2)    → 180MHz ──┐
                       ÷Q(7)    → 51.4MHz  │ Q 路给 USB（≠48，想用 USB 得换 168MHz 方案）
                                         │
              SYSCLK ◄── 多路开关选 PLL ──┘
                 │
                 ├─ AHB ÷1 ─► HCLK = 180MHz ─► CPU 内核、SysTick、GPIO、DMA、Flash
                 ├─ APB1 ÷4 ─► PCLK1 = 45MHz ─► I2C1、USART2、TIM4（定时器×2=90MHz！）
                 └─ APB2 ÷2 ─► PCLK2 = 90MHz ─► USART1（BRR=781 按它算）、SPI1、ADC
```

**你所有实验数字都长在这棵树上**：

| 实验数字                 | 长在哪根枝上                                          |
| ------------------------ | ----------------------------------------------------- |
| SysTick LOAD=179999      | HCLK 180MHz                                           |
| UART BRR=0x30D（115200） | PCLK2 90MHz                                           |
| ch03 蜂鸣器 PSC=90-1     | TIM4=APB1 定时器×2=90MHz（**分频>1 时自动翻倍**规则） |
| 晶振漂移 +40.9ppm        | HSE 的质量报告                                        |

## 3. 六步配置配方（clock_init 的逐行翻译）

```text
① 电压先行    PWR 时钟 + VOS=Scale1          频率升压要先到（调试链路失效第一课：先提速后加压=欠压失控）
② 过载模式    ODEN→等ODRDY→ODSWEN→等ODSWRDY  180MHz 的硬性前提
③ Flash 等待  5WS+预取+缓存                  Flash 比 CPU 慢，切高频前先给它缓冲（XIP 课）
④ 开 HSE      HSEON→死等 HSERDY              晶振起振要毫秒级物理时间
⑤ 配 PLL      写 M/N/P/Q→PLLON→死等 PLLRDY   M 按晶振频率选（25M→M=25，调试链路失效第二课）
⑥ 分频+切换   AHB/APB 分频→SW 切 PLL→死等 SWS 硬件回执确认切换完成
```

**顺序不能乱**：①②保电压 → ③保取指 → ④⑤备好新钟 → ⑥才敢切。每个"死等 READY"
都在等一个物理过程（起振/锁相/稳压），不是软件仪式。

## 4. 换频率的算法：自己选 M/N/P

```text
想从 25MHz 晶振得到 X MHz：
  M = 25               （让 VCO 输入=1MHz，落在 1~2MHz 窗口）
  N = X × P            （VCO=1MHz×N，须落在 192~433MHz）
  P ∈ {2,4,6,8}        （VCO÷P = X）
  Q：要 USB 48MHz 时 VCO 必须整除出 48 ⇒ N=336/P=2/SYSCLK=168 的整套妥协方案
```

硬约束表（违反=调试链路失效那晚的下场）：

| 量          | 上限/区间           | 违反后果                     |
| ----------- | ------------------- | ---------------------------- |
| VCO 输入    | 1–2MHz              | PLL 拒锁，卡死 PLLRDY 等待环 |
| VCO 输出    | 192–432MHz          | 同上                         |
| SYSCLK      | 180MHz（Scale1+OD） | 欠压失控、调试口陪葬         |
| APB1 / APB2 | 45 / 90MHz          | 外设时序错乱                 |
| Flash WS    | 按频率-电压对照表   | 取指读飞                     |

## 6. SysTick 硅片解剖：一段刻在硅里的硬件循环

### 6.1 三个硬件积木（软件人的最小硬件课）

| 积木         | 是什么                                            | 软件对应物             |
| ------------ | ------------------------------------------------- | ---------------------- |
| **触发器**   | 存 1 比特的原子元件：时钟沿瞬间存入并保持到下一沿 | 1 位变量（但物理存在） |
| **时钟沿**   | 180MHz 节拍——每个上升沿全芯片触发器**同时**更新   | 全局锁存时刻           |
| **组合逻辑** | 无记忆运算电路：输入变输出立刻变（减法器/比较器） | 纯函数表达式           |

**一个 32 位寄存器 = 32 个并排触发器**——你 mdw 读的每个寄存器物理上就是这种阵列。

### 6.2 硬件循环：软硬对照

```c
/* 软件版（你的心智模型） */        /* 硬件版（伪 RTL，硅片真实形状） */
while(1) {                          always @(posedge clk) begin      // 每个时钟沿
  if (!enable) ;                      if (!enable) value <= value;    // 停表
  else if (value == 0) {              else if (value == 0) begin
    value = LOAD;                       value <= reload;              // 重装
    flag = 1;                           flag   <= 1'b1;               // COUNTFLAG
    if (tickint) 举手;                  if (tickint) irq = 1;         // 中断线
  }                                   end
  else value--;                        else value <= value - 1'b1;    // 减一
}                                   end
```

右边的"程序"**不消耗 CPU 任何周期**——电路每个时钟沿自己执行一轮，与流水线并
行运转。"并行"在软件里是调度出来的，在这里是物理事实。

### 6.3 方框图与四个机制的电路真相

```text
            ┌────────────── CPU 核内部（PPB 私有外设区）──────────────┐
            │                                                       │
HCLK ───────┼──► ┌─────┐   ┌──────────────┐                        │
(180MHz)    │    │ ÷8  │   │  24 个触发器  │ ◄── LOAD 寄存器       │
            │    └──┬──┘   │  (VAL 计数器) │     (24 个触发器)      │
STCLK ──────┼──► MUX─┘     └──┬────────┬──┘                        │
（CLKSOURCE 选）    │          │        │                           │
            │      │    ┌─────┘        │                           │
            │      │    ▼              ▼                           │
            │    减法器(组合)       ==0 比较器                      │
            │    "下一拍数几"          │                            │
            │                         ├─► flag 触发器 ─► CTRL.bit16│
            │                         │       ▲                    │
            │                         │  读 CTRL 地址⇒清零脉冲     │
            │                         │                            │
            │                         └─► AND(TICKINT) ──► NVIC    │
            └───────────────────────────────────────────────────────┘
```

| 机制           | 电路真相                                                      | 你的实测对应                          |
| -------------- | ------------------------------------------------------------- | ------------------------------------- |
| 倒数+重装      | 24 触发器+减法器回环；过零比较器触发重装                      | VAL 两读 0x7E→0x2A7；周期=LOAD+1 拍   |
| 24 位天花板    | 就 24 个触发器——物理上限 0xFFFFFF                             | 93ms（@180MHz）上限，矩阵实验正待测   |
| COUNTFLAG 读清 | 独立触发器：过零置位；**地址译码器发现读 CTRL 就发清零脉冲**  | c1=0x00010007 / c2=0x00000007 铁证    |
| 中断=一根线    | 过零 AND TICKINT → 金属线到 NVIC；NVIC 查 SHPR3、压栈、跳向量 | SHPR3=0xF0F00000 实测                 |
| CALIB          | 制造时金属层配置的**只读常数**，不是电路算出来的              | 0x4000493E（18750 对不上分频→SKEW=1） |

### 6.4 为什么住在核内：PPB 的意义

|          | SysTick                            | TIM4（ch03 在用）           |
| -------- | ---------------------------------- | --------------------------- |
| 设计者   | ARM（核的一部分）                  | ST（芯片厂外设）            |
| 住址     | CPU 硅片内，PPB 总线（0xE000E010） | APB1 总线矩阵（0x40000800） |
| 时钟     | 就是 HCLK，零延迟                  | 经总线时钟树                |
| 可移植性 | **全宇宙每个 Cortex-M 一模一样**   | ST 专有                     |

这是整个 RTOS 生态的基石：**FreeRTOS 敢拿 SysTick 当默认心跳，正因 ARM 把它焊进
架构定义**——ST/NXP/GD 任何厂的 M4，那四个寄存器分毫不差。而 TIM4 是同一设计原子
（计数器+比较器+重装）的富亲戚：预装载、四路输出比较（PWM 之源）、输入捕获、DMA。
**看懂 SysTick 的硅片解剖，就看懂了所有定时器的骨架。**

## 7. HSI：永远在场的朋友

上电复位 ⇒ 系统永远先跑 HSI 16MHz；HSE/PLL 出任何事（晶振坏、配置卡死）也退回
HSI 继续活着。调试链路失效那晚卡在 PLLRDY 死等时，CPU 就是在 HSI 的 16MHz 上空转——
**时钟树的容错设计，从上电第一拍就在保你**。
