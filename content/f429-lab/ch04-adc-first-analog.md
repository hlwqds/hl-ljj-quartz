## 目标（先说结论）

- 数字世界的第一个模拟输入：旋动板载电位器，串口实时打印 0–4095——**12 位 = 4096 个档位**，
  两端对应 GND（Ground，地线，0V 基准）与 VREF+。

> 📖 **术语卡：ADC（Analog-to-Digital Converter，模数转换器）**
> **是什么**：把引脚上的连续电压「量化」成整数的外设；12 位 ADC 的输出是 0–4095，把量程切成 2¹²=4096 格。分辨率就是「切成多少格」——格越多越细。
> **为什么存在**：CPU 的世界只有 0 和 1，物理世界的温度、光线、旋钮全是连续量，中间需要专职翻译官。
> **类比**：尺子上的最小刻度——毫米尺（12 位）比厘米尺（8 位，256 格）量得细。
> ⚠️ 类比边界：尺子是均匀刻度且无代价；ADC 的位数越多转换越慢（本章 12 位=固定 12 拍），且存在固有量化误差（±半格）。

> 📖 **术语卡：参考电压（VREF+，Voltage Reference）**
> **是什么**：ADC 的「满量程」基准——读数 = Vin/VREF+ × 4095；输入达到 VREF+ 时读满 4095，接地为 0。
> **为什么存在**：「多大算大」必须有个标准；同一输入电压，VREF+ 变了读数就变（换算公式里它是分母）。
> **类比**：地图比例尺——同样 1 厘米纸面距离，比例尺不同代表的实际距离不同。
> ⚠️ 类比边界：比例尺可任意选；VREF+ 受硬件约束（F429 上 ≤ VDDA，常用 3.3V，且越高可分辨的绝对电压差越细——每格=VREF+/4096）。

- 原理三件事：**SAR 二分搜索**（12 次比较定档位）、**采样保持电容**（高阻源要长采样）、
  **规则序列器**（转换批处理的调度表）。
- 时钟算例先记结论：**ADCPRE（ADC 时钟预分频器）编码不是递增序**（00=/2、01=/4、10=/8、**11=/6**），
  本工程 PCLK2（APB2 总线时钟——挂 ADC 等高速外设的内部总线，90MHz）只能选 /4 以下——/2 的 45MHz 超过 F42x 的 36MHz 上限。

## 原理下钻

### SAR：12 问二分搜索，一页讲完

> 📖 **术语卡：SAR（Successive Approximation Register，逐次逼近寄存器）**
> **是什么**：ADC 的主流架构：从最高位开始，每步用一个内部 DAC（Digita-to-Analog Converter，数模转换器，把数字变成真实电压）生成「中点猜测」，一个比较器（比较两电压谁大、输出 1 位的电路）回答「高了还是低了」，据此定下当前位。
> **为什么存在**：12 位结果只需固定 12 步、每步 1 个时钟——又快又省电路，是通用 ADC 的性价比之王。
> **类比**：猜价格游戏——每次猜可行区间的正中间，主持人答「高了/低了」，12 轮锁定价位。
> ⚠️ 类比边界：游戏可以乱猜；SAR 必须从最高位到最低位严格二分，且答案由硬件比较器一拍给出，没有「想一想」的延迟。

把 0–4095 想成一根电压数轴。SAR 从最高位问起：

```text
第 1 问：Vin ≥ VREF/2   ？  是→bit11=1，搜索区间上半段
第 2 问：Vin ≥ 当前区间中点？ 是→bit10=1 …
…（内部 DAC 生成「中点猜测」电压，比较器给出 1-bit 答案）
第 12 问：bit0 定。4096 格中锁定 1 格。
```

与软件二分唯一的区别：**答案由比较器在硬件里出**，12 问固定 12 个 ADC 时钟周期走完——
这就是「12 位转换占 12 个 ADCCLK」的来历，也是转换时间公式的后半项。

### 采样保持：为什么高阻源要长采样

> 📖 **术语卡：采样保持电路（S/H，Sample and Hold）**
> **是什么**：ADC 内部的一只小电容（pF 级——皮法=10⁻¹² 法拉，记住「非常小的电容」即可）加一个开关：开关闭合时电容跟随引脚电压充电（采样期），开关断开时电容把电压「定格」住（保持期），SAR 对这个冻结值做二分搜索。
> **为什么存在**：二分搜索的 12 拍里输入电压若还在变，每问一问答案针对的电压都不同，结果就是一团糊；先冻结再转换，等价于把「测量」和「读数」分开。
> **类比**：相机快门——曝光期跟随光线，成像期定格画面。
> ⚠️ 类比边界：快门定格的是光子积分，S/H 定格的是电压瞬时值；且 S/H 定格质量受「充电是否充到 12 位精度」限制（欠采样=曝光不足，读数偏低）。

转换开始前，内部小电容（pF 级）先通过引脚「充电」跟随输入电压（采样期，软件可选 3–480 周期），
随后开关断开、电容定格（保持期），SAR 对着这个冻结值工作。RC 电路（电阻+电容构成的充电回路）充到
12 位精度需要约 9 个时间常数（τ=RC；时间常数 τ：每过一个 τ 充到终值的约 63%，充「满」需好几个 τ，
要分得清 1/4096 的差别就得约 9 个）——**源阻抗（信号源的内阻 R，本例即电位器的等效电阻）越高，
τ=RC 越大，采样期就得越长**。datasheet 里有「源阻抗-采样时间」
对照表（RAIN max）：旋钮这类 10kΩ 级（本板实际阻值**待核对**）的高阻源，直接上最长的
480 周期最省心——反正单次转换对我们来说快得用不完。

相机类比完整版：曝光不足=欠采样（电容没充到位，读数偏低）；拍照时物体还在动=没有保持机制；
S/H 就是「先曝光、后成像」的硬件切分。

### 规则序列器：转换的批处理表

> 📖 **术语卡：规则序列器（Regular Sequence Register，SQR）**
> **是什么**：一张最多 16 行的「转换调度表」：触发一次，ADC 按表从第 1 行读到第 16 行，逐个把指定通道各转换一次。表长写在 SQR1 的 L 位段（存的是「表长−1」），表目 SQ1–SQ16 分散在 SQR3/SQR2/SQR1 三个寄存器里。
> **为什么存在**：要周期性采 8 路传感器时，不必软件挨个「设通道→触发→等→读」8 遍，一张表一次触发全部搞定（配 DMA 后结果自动流进内存）。
> **类比**：cron 表/批处理队列——一次提交一串作业，调度器按序执行——你的主场。
> ⚠️ 类比边界：序列器没有失败重试和条件分支，永远线性走表；ADC 另有一张「注入组」序列可打断规则组（高优先级插队），本章不用。

规则组一次转换最多 16 个通道，SQR1.L 写「表长−1」，SQ1–SQ16 写表目（SQR3 放前 4 个）。
本章单通道 = 表长 1、SQ1=13。它的价值在 DMA 场合：整张表自动跑完、结果流进内存
（ch11 的 ADC+DMA 双缓冲就是这张表的工业化）。另：数据对齐——复位默认右对齐，
DR 低 12 位即 0–4095 原码；左对齐是给「只要高 8 位精度」的场景省一次移位用的，本章不动它。

### ADC 时钟：ADCPRE 的编码坑与算例

ADCCLK（ADC 的工作时钟）来自 PCLK2（90MHz）经 ADCPRE 分频，**上限 36MHz**（F42x 手书指标）：

| ADCPRE（bits17:16） | 分频   | ADCCLK    | 合法？              |
| ------------------- | ------ | --------- | ------------------- |
| 00                  | /2     | 45 MHz    | ✗ 超上限            |
| 01                  | /4     | 22.5 MHz  | ✓ 本章采用          |
| 10                  | /8     | 11.25 MHz | ✓                   |
| 11                  | **/6** | 15 MHz    | ✓（注意不是 /16！） |

注意编码 10 是 /8、11 反而是 /6——非递增序，照「值越大分频越大」的直觉写会翻车。

（⚠️ 复核提示：上表与 RM0090 手册原文存在出入——手册中 ADC_CCR 寄存器 ADCPRE[1:0] 的定义是
00=/2、01=/4、10=**/6**、11=**/8**，恰好是递增序，「非递增」的说法按手册不成立。但无论按哪种
编码，本章选用的 ADCPRE=01（/4→22.5MHz）都合法、实验结论不变；上表原文按「只增不删」原则保留，
实测核销时以 RM0090 与真机读数为准。）

单次转换总时长算例：

```text
T = (采样周期 + 12) × ADCCLK 周期
  = (480 + 12) / 22.5MHz
  = 492 / 22.5e6 ≈ 21.9µs        → 单通道吞吐上限 ≈ 45.7 kS/s
```

（若有「引脚上没信号变化读数也稳定」的困惑，先想起 OVR（Overrun，溢出标志——上一次结果还没被
软件读走、新转换又完成时，硬件置 1 并作废数据）：单次模式下读 DR 不及时会置溢出、
数据作废——轮询版按序读不会踩到，DMA 版 ch11 会正面遇到。）

## 实验：读 PC3 电位器（先盖 J77！）

> 📖 **术语卡：电位器（Potentiometer，可调电阻/旋钮）**
> **是什么**：三端器件，本质是带滑动抽头的电阻分压器：旋钮改变抽头位置，中间脚输出 0–VREF 之间连续可调的电压。
> **为什么存在**：给 ADC 实验提供最简单的模拟信号源——拧一下电压就线性变化，无需任何外部仪器。
> **类比**：老式收音机的音量旋钮——拧到哪，输出比例就到哪。
> ⚠️ 类比边界：很多现代「旋钮」其实是数字编码器（输出脉冲序列不是电压）；电位器输出的是货真价实的连续电压。

引脚映射：**PC3 = ADC123_IN13**（意为 PC3 同时是 ADC1/ADC2/ADC3 三颗转换器的第 13 号输入通道——「通道」是 ADC 侧的输入编号，与引脚的对应关系由芯片出厂焊死，只能查表不能改；三颗 ADC 都能采的通道；通道映射见 STM32F429 datasheet 的
pin definition 表 PC3 行，实跑时核对）。J77 跳帽（插在两根排针上的小短路帽，等效一个手动开关——盖上=通路接通）盖上才有「旋钮→PC3」的物理通路。

```c
#define VREF_MV 3300u /* 待核对：板上 VREF+ 是 3.3V 还是独立基准（影响 mV 换算，不影响 raw 读数） */

static void adc_init(void)
{
    /* 1) 时钟：GPIOC + ADC1（挂 APB2，PCLK2=90MHz）+ 分频（CCR 属三 ADC 共用区，在 0x40012304） */
    RCC->AHB1ENR |= RCC_AHB1ENR_GPIOCEN;
    RCC->APB2ENR |= RCC_APB2ENR_ADC1EN;
    ADC->CCR = (ADC->CCR & ~(3u << 16)) | (1u << 16); /* ADCPRE=01：PCLK2/4=22.5MHz（编码坑见正文） */

    /* 2) PC3 设模拟模式：数字输入缓冲对模拟信号是噪声源，模拟模式把它断开 */
    GPIOC->MODER |= (3u << (3 * 2));       /* MODER=11：模拟 */
    GPIOC->PUPDR &= ~(3u << (3 * 2));      /* 无上下拉 */

    /* 3) 通道 13 的采样时间：SMPR1 的 ch13 位段[11:9]=111（480 周期，高阻源宁长勿短） */
    ADC1->SMPR1 = (7u << 9);

    /* 4) 规则序列：表长 1（SQR1.L=0），SQ1=13（SQR3 低 5 位） */
    ADC1->SQR1 = 0;
    ADC1->SQR3 = 13u;

    /* 5) 单次转换、软件触发、右对齐（复位默认）、无扫描；上电 ADON 后等稳定再首发 */
    ADC1->CR2 = ADC_CR2_ADON;
    for (volatile int i = 0; i < 1000; i++) { } /* tSTAB 量级的等待（datasheet ADC 特性表，待核对） */
}

static uint16_t adc_read_in13(void)
{
    ADC1->CR2 |= ADC_CR2_SWSTART;      /* 软件触发一次规则转换 */
    while (!(ADC1->SR & ADC_SR_EOC)) { } /* 等完成：约 21.9µs（见正文算例） */
    return (uint16_t)ADC1->DR;         /* 读 DR 自动清 EOC——顺序不可反，先读再等就是死循环 */
}

int main(void)
{
    clock_init();
    uart_init();
    adc_init();

    for (;;) {
        uint16_t raw = adc_read_in13();
        uart_puts("ADC13 raw=");
        uart_putdec(raw);
        uart_puts("  (");
        uart_putdec((uint32_t)raw * VREF_MV / 4095u); /* 线性换算：raw×VREF/4095 */
        uart_puts(" mV)\r\n");
        delay_ms(100); /* 10Hz 打印，g_ms 地基（ch01） */
    }
}
```

**代码走读**——逐条寄存器操作翻译成人话：

| 语句                                   | 拆解                                                                                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `RCC->AHB1ENR \|= RCC_AHB1ENR_GPIOCEN` | RCC（Reset and Clock Control，全芯片复位/时钟控制单元）的 AHB1 时钟使能寄存器：给 GPIOC 端口上电                   |
| `RCC->APB2ENR \|= RCC_APB2ENR_ADC1EN`  | APB2 总线的时钟使能寄存器：给 ADC1 上电（ADC1 挂 APB2）                                                            |
| `ADC->CCR = … (1u << 16)`              | CCR（Common Configuration Register，三颗 ADC **共用**的配置寄存器，故无 ADC1 前缀）；bit17:16=ADCPRE=01→/4         |
| `GPIOC->MODER \|= (3u << (3*2))`       | MODER 每脚 2 位；写 11=模拟模式——断开数字输入缓冲（施密特触发器），它对中间电平会反复翻转、是模拟噪声源            |
| `GPIOC->PUPDR &= ~(3u << (3*2))`       | PUPDR（Pull-up/Pull-down Register，上下拉寄存器）清零=不接内部上/下拉电阻，避免它干扰电位器分压                    |
| `ADC1->SMPR1 = (7u << 9)`              | SMPR（SaMPle time Register，采样时间寄存器）；ch13 占其中 3 位 [11:9]，写 111=480 周期（最长采样，高阻源宁长勿短） |
| `ADC1->SQR1 = 0`                       | 序列表长 L=0（存「表长−1」），即序列表只有 1 项                                                                    |
| `ADC1->SQR3 = 13u`                     | SQR3 低 5 位=SQ1=13：表第 1 项转换通道 13（PC3）                                                                   |
| `ADC1->CR2 = ADC_CR2_ADON`             | ADON=ADC 总开关；上电后内部电路要 tSTAB（稳定时间）才能首次转换                                                    |
| `for (volatile int i = 0; …)`          | 空转计数当延时；`volatile` 告诉编译器此变量随时会变、不许把这个「看似无用」的循环优化掉                            |
| `CR2 \|= ADC_CR2_SWSTART`              | SWSTART=软件触发位：手动踢一脚，按序列表开始一次转换（此位触发后硬件自动回零）                                     |
| `while (!(ADC1->SR & ADC_SR_EOC))`     | EOC（End Of Conversion，转换完成标志）：忙等它置 1，全程约 21.9µs（正文算例）                                      |
| `return (uint16_t)ADC1->DR;`           | DR（Data Register）低 12 位即结果原码；**读 DR 会顺带清 EOC**——顺序见下方工程细节 1                                |

main 循环里两句顺带说清：

- `(uint32_t)raw * VREF_MV / 4095u`：**先乘后除**是刻意的——若先除，raw<4095 的读数会被整数除法截成 0；先乘的积最大 4095×3300≈1352 万，远未溢出 32 位。
- `uart_putdec` / `uart_puts`：串口打印的十进制/字符串版（序章地基，不赘述）。

三个工程细节：

1. **EOC 与 DR 的顺序**是本代码唯一容易写反的地方——EOC 由读 DR 清除，先清再等就是
   永久卡死，和序章「等 PLLRDY 死循环」同款尸体。
2. ADC1 的中断（IRQ 18——IRQ=Interrupt ReQuest，中断请求号，内核给每个中断源编的号）本章不用：轮询 21.9µs 对 10Hz 的打印毫无压力。中断版留给
   DMA 章统一升级。
3. 三 ADC 共用区（CCR）和 ADC1 私有区（0x40012000 起的各寄存器）分居两处——地址表见下节。

## 预期输出（待实测核销）

串口侧（旋钮两端的判据就是做通标准）：

```text
ADC13 raw=0      (0 mV)      ← 旋到一端（GND 侧）
ADC13 raw=2048   (1651 mV)   ← 中位附近
ADC13 raw=4095   (3300 mV)   ← 旋到另一端（VREF+ 侧，若 VREF 实测 3.0V 则此行 3000 mV）
```

mV 列是换算值、跟着 VREF_MV 宏走；raw 列的 0/4095 两端值不受 VREF 影响——所以核对 VREF
的顺序是：先验两端 raw，再用万用表量 PC3 实际电压反推 VREF_MV 该填多少。

寄存器侧（活体 `mdw`）：

| 地址       | 寄存器     | 预期值     | 推导                            |
| ---------- | ---------- | ---------- | ------------------------------- |
| 0x4001200C | ADC1_SMPR1 | 0x00000E00 | ch13 位段[11:9]=111             |
| 0x40012034 | ADC1_SQR3  | 0x0000000D | SQ1=13                          |
| 0x4001202C | ADC1_SQR1  | 0x00000000 | 表长 1（L=0，复位值恰为 0）     |
| 0x40012008 | ADC1_CR2   | 0x00000001 | 仅 ADON；SWSTART 触发后自动回零 |
| 0x40012304 | ADC_CCR    | 0x00010000 | 仅 ADCPRE=01                    |

**命令拆解：** `mdw 0x4001200C`（在 OpenOCD 命令行/Telnet 会话里读寄存器）

| 部分         | 作用                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------- |
| `mdw`        | Memory Display Word——按 32 位「字」读出并打印物理内存（兄弟命令 `mdb`/`mdh` 按字节/16 位半字） |
| `0x4001200C` | ADC1 基址 0x40012000 + 偏移 0x0C，即 SMPR1；逐行换地址即可核对上表五行                         |

**你会看到**：`0x4001200c: 00000e00`——正是 SMPR1 预期值。
**失败了先查**：目标是否连上（`targets` 看状态）、地址是否抄错行（0x40012304 是三 ADC 共用区，抄成 0x40012xxx 的私有区就找错了楼）。

## 与 FreeRTOS / ESP32 对照

- **ESP32（IDF5 的 adc_oneshot 驱动）**：`adc_oneshot_new_channel` + `adc_oneshot_read`——
  本章 `adc_read_in13()` 的官方打包版。F4 这边「衰减挡位」的概念不存在：ESP32 靠
  attenuation 把量程从 ~1.1V 拉到 ~3.1V，STM32 则是固定 0–VREF+，要量程就换基准或分压电阻。
- **校准**：ESP32 出厂把校准系数烧进 eFuse（一次性可编程的硬件熔丝位，烧了就改不了），驱动自动套用；STM32F4 **没有出厂逐片校准**，
  精度场景要自己做两点校准（量两个已知电压建直线）。对照系统侧：出厂 microcode 校准
  vs 用户态手标——「平台替你做了多少」永远值得列成一张表再决定信什么。
- **FreeRTOS 下的形态**：10Hz 轮询可塞进任意任务；一旦上采样率（kS/s 级——千次采样每秒）就必须
  ADC+DMA+半满/全满中断的经典组合（ch11），届时本章的「序列表+EOC」升级为
  「序列表+DMA 流」，中断侧按 ch02 契约（优先级 ≥5<<4）接 FromISR。
- [[ch18-esp32-wifi-lwip-integration|lwIP（十八）]]里 ADC 与
  网络栈无关，但「采样流进环形缓冲再给消费者」的骨架与 pbuf 收包路径同构（环形缓冲、pbuf 都是你的
  主场）——阶段 5 会重逢。
