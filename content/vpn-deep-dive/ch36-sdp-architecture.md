## 1. 概述：SDP 简介

**SDP**（Software Defined Perimeter，软件定义边界）是由 CSA（云安全联盟）于 2013 年提出的零信任网络安全架构。SDP 的核心思想是「Darknet 暗网」——除非经过认证，否则服务器对未授权用户不可见。

```
SDP 核心特点：

┌─────────────────────────────────────────────────────────────────┐
│                      SDP 核心概念                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  设计原则：                                                      │
│  ├─ 零信任：永不信任，始终验证                                    │
│  ├─ 隐藏资产：服务器在网络中不可见（Darknet）                    │
│  ├─ 双向认证：客户端和服务端相互验证                              │
│  └─ 动态授权：基于设备、用户、上下文动态访问控制                  │
│                                                                 │
│  vs 传统 VPN：                                                   │
│  ├─ VPN：网络层访问控制，授权后可见整个网段                      │
│  └─ SDP：应用层微分段，逐服务精确授权                            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 2. SDP 架构详解

### 2.1 三角架构（SDP Triangle）

SDP 采用 Controller-Gateway-Client 三角架构：

```

┌─────────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────────┤

│                    ┌─────────────┐                              │
│                    │ Controller  │                              │
│                    │   控制平面   │                              │
│                    └──────┬──────┘                              │
│                           │                                     │
│              ┌────────────┼────────────┐                        │
│              │            │            │                        │
│              ▼            │            ▼                        │
│        ┌──────────┐       │     ┌──────────┐                   │
│        │ Client A │       │     │ Client B │                   │
│        │  客户端   │       │     │  客户端   │                   │
│        └──────────┘       │     └──────────┘                   │
│                            │                                     │
│                            ▼                                     │
│                    ┌─────────────┐                              │
│                    │  Gateway    │                              │
│                    │   网关       │                              │

## 3. SDP 协议（SPP）

### 3.1 SPP 协议概述

SPP（SDP Protocol）是 SDP 的通信协议，运行在 UDP 443 端口：

```
SPP 协议位置：

┌─────────────────────────────────────────────────────────────────┐
│                    SPP 协议栈                                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                      Application                                │
│                         │                                       │
│                    ┌────┴────┐                                  │
│                    │   SPP   │  ← SDP 控制/数据协议            │
│                    └────┬────┘                                  │
│                         │                                       │
│                    ┌────┴────┐                                  │
│                    │   DTLS  │  ← 加密（可选 TLS）              │
│                    └────┬────┘                                  │
│                         │                                       │
│                    ┌────┴────┐                                  │
│                    │   UDP   │  ← 通常 UDP 443                  │
│                    └─────────┘                                  │
│                                                                 │
│  特性：                                                         │
│  ├─ 基于 UDP，低延迟                                            │

```

## 4. Darknet 暗网原理

### 4.1 什么是 Darknet

Darknet（暗网）是 SDP 的核心概念——未授权用户无法发现或连接受保护的资源：

```
Darknet 暗网：

┌─────────────────────────────────────────────────────────────────┐
│                    Darknet vs Flat Network                       │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  传统网络（Flat）：                                              │
│                                                                 │
│    Internet                                                      │
│        │                                                         │
│    ┌───┴───┐                                                    │
│    │ Router │                                                    │
│    └───┬───┘                                                    │
│        │                                                         │
│    ┌───┴───┬───────────┐                                        │
│    │       │           │                                        │
│    ▼       ▼           ▼                                        │
│  Server A Server B   Server C                                  │
│   :80      :22         :443   ← 端口全部可见                     │
│                                                                 │
│  Darknet（SDP）：                                                │
│                                                                 │
│    Internet                                                      │
│        │                                                         │
│    ┌───┴───┐                                                    │
│    │ SDP   │                                                    │
│    │Gateway│                                                    │
│    └───┬───┘                                                    │
│        │ （未认证请求：无声拒绝）                                 │
│        ▼                                                         │
│       ???   ← 端口不可见，无响应                                 │
│                                                                 │
│  关键区别：                                                      │
│  ├─ 传统：端口开放，只认证不授权                                  │
│  └─ Darknet：端口隐藏，需要双向认证才能发现                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 端口隐藏技术

```
SDP 端口隐藏机制：

┌─────────────────────────────────────────────────────────────────┐
│                    端口隐藏技术                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 防火墙层面：                                                 │
│  ├─ SDP Gateway 只允许来自认证 Client 的流量                     │
│  ├─ 未认证流量：DROP（不响应）                                   │
│  └─ 效果：扫描不到端口                                          │
│                                                                 │
│  2. 协议层面：                                                   │
│  ├─ SPP 只响应 SIH 握手的 Client                                │
│  ├─ 无关流量：忽略                                               │
│  └─ 效果：端口看起来关闭                                         │
│                                                                 │
│  3. 网络层面：                                                   │
│  ├─ Gateway 可部署在 RFC1918 私有地址                           │
│  ├─ 公网只暴露 SDP 控制端口                                     │
│  └─ 服务完全在内网                                               │
│                                                                 │
│  对比：                                                          │
│  ┌──────────────────┬──────────────┬──────────────┐             │
│  │      方法        │   端口可见   │   响应特征    │             │
│  ├──────────────────┼──────────────┼──────────────┤             │
│  │ 传统防火墙       │     是       │   RST/ICMP   │             │
│  │ IDS/IPS         │     是       │   告警       │             │
│  │ SDP Darknet     │     否       │   无响应     │             │
│  └──────────────────┴──────────────┴──────────────┘             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 6. SDP vs VPN 对比

```
SDP 与 VPN 对比：

┌─────────────────────────────────────────────────────────────────┐
│                    SDP vs VPN                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌────────────────┬──────────────┬──────────────┐             │
│  │      维度       │     VPN      │     SDP      │             │
│  ├────────────────┼──────────────┼──────────────┤             │
│  │  可见性        │ 网络分段可见   │ 服务隐藏(Darknet)│         │
│  ├────────────────┼──────────────┼──────────────┤             │
│  │  信任模型      │ 网络边界信任   │ 永不信任      │             │
│  ├────────────────┼──────────────┼──────────────┤             │

│  ├────────────────┼──────────────┼──────────────┤             │
│  │  认证          │ 单向（用户）   │ 双向（用户+设备）│          │

## 9. 总结

SDP（软件定义边界）是零信任网络的核心架构之一，通过以下机制实现安全远程访问：

```
SDP 核心要点总结：

┌─────────────────────────────────────────────────────────────────┐
│                    SDP 关键要点                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  架构：                                                         │
│  ├─ Controller + Gateway + Client 三角架构                     │
│  ├─ SPP 协议（UDP 443）                                        │
│  └─ mTLS 双向认证                                               │
│                                                                 │
│  安全特性：                                                      │
│  ├─ Darknet：服务隐藏，不可扫描                                 │
│  ├─ SPA：单包授权，极小攻击面                                   │
│  ├─ 双向认证：用户+设备+服务                                    │
│  └─ 动态策略：基于属性实时授权                                   │
│                                                                 │
│  相比 VPN 的优势：                                              │
│  ├─ 应用层微分段                                                │
│  ├─ 消除横向移动风险                                            │
│  ├─ 设备状态评估                                                │
│  └─ 更好的可观测性                                              │
│                                                                 │
│  适用场景：                                                      │
│  ├─ 企业零信任转型                                              │
│  ├─ 合作伙伴安全接入                                            │
│  ├─ 敏感系统保护                                                │
│  └─ 远程办公安全化                                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
