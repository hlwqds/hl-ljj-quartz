## 1. 概述：WireGuard 的极致性能

WireGuard 设计目标是成为「安全隧道协议的极致性能标杆」。相比 IPSec（~2-3x 开销）和 OpenVPN（~10x 开销），WireGuard 在保持同等安全强度的同时，实现了接近线速的性能表现。

```
WireGuard 性能定位：

┌─────────────────────────────────────────────────────────────────┐
│                     VPN 协议性能对比                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  协议           │ 吞吐损失    │ CPU 开销    │ 延迟增加           │
│  ───────────────┼─────────────┼─────────────┼─────────           │
│  明文           │ 0%          │ 0%          │ ~0 μs              │
│  WireGuard     │ 2-5%        │ 1-2 核     │ 10-30 μs          │
│  IPSec (软)    │ 10-30%      │ 4-8 核     │ 30-80 μs          │
│  OpenVPN (TLS) │ 50-70%      │ 全 CPU     │ 100-200 μs        │
│                                                                 │
│  设计优势：                                                    │
│  ├─ 极简协议头（仅 4 个包完成握手）                              │

│  ├─ 内核级实现，零拷贝路径                                       │
```

## 3. 批处理与 IO 优化

### 3.1 内核批处理机制

WireGuard 使用内核批处理最大化吞度：

```c
// wireguard/device.c - 批处理发送

static void wg_packet_tx_worker(struct work_struct *work)
{
    struct wg_device *wg = container_of(work, struct wg_device, packet_tx_work);
    struct sk_buff *skb;
    int budget = wg->throughput_quota;  // 每批次处理上限

    while (budget > 0) {
        skb = ptr_ring_consume(&wg->tx_ring);
        if (!skb)
            break;

        // 批量加密（利用 SIMD）
        wg_encrypt_batched(skb, wg->peer);

        // 批量发送
        dev_queue_xmit(skb);
        budget--;
    }

    // 延迟中断合并
    napi_complete(&wg->napi);
}
```

## 6. 高性能配置

### 6.1 sysctl 参数优化

```bash
# /etc/sysctl.d/99-wireguard.conf

# 通用网络优化
net.core.rmem_max = 134217728
net.core.wmem_max = 134217728
net.core.rmem_default = 16777216
net.core.wmem_default = 16777216
net.core.netdev_max_backlog = 50000
net.core.somaxconn = 4096

# RPS (Receive Packet Steering)
net.core.rps_sock_flow_entries = 32768

# TCP 优化（如果 WireGuard 通过 TCP）
net.ipv4.tcp_rmem = 4096 87380 67108864
net.ipv4.tcp_wmem = 4096 65536 67108864
net.ipv4.tcp_congestion_control = bbr

# 内存缓冲区
net.ipv4.udp_rmem_min = 16384
net.ipv4.udp_wmem_min = 16384

# 禁用 bounce buffers
net.core.high_order_alloc_disable = 1
```

### 6.2 网卡优化

```bash
# 启用网卡特性
```

## 8. 总结

WireGuard 的极致性能源于精心设计：

- **密码学**：ChaCha20-Poly1305 无硬件依赖，AES-NI 加速时接近线速
- **协议简化**：4 包握手、单一密码套件、极简头部
- **内核集成**：零拷贝路径、批处理、NAPI 合并中断
- **实测性能**：98% 线速、<30 μs 延迟、仅 2-3 核 CPU
- **可优化空间**：sysctl 调优、RPS 分散、BBR 拥塞控制
