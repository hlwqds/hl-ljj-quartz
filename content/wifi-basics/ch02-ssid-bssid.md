# WiFi 小白（二）：你连的「名字」背后——SSID

> [!info] WiFi 小白系列 0. [[wifi-basics|系列索引]]
> 上一章：[[ch01-what-is-wifi|第一章：WiFi 到底是什么？]]
> **第二章：你连的「名字」背后——SSID**（当前章）

这一章回答三个问题：**你每天连的那个名字是什么**（SSID）、**为什么公司里一个名字背后有几十个信号源**（手机是怎么在它们之间无缝切换的）、以及两个名字相关的坑——「隐藏网络」和「免费 WiFi」到底可不可信。

## SSID：WiFi 网络的名字

先说结论：**SSID（Service Set Identifier，服务集标识）就是 WiFi 网络的名字**，你手机 WiFi 列表里看到的每一行，就是一个 SSID。技术上它是 1~32 字节的名字，区分大小写——`Home-WiFi` 和 `home-wifi` 是两个不同的网络。

类比上一章的小区：**SSID 就是小区名**。「翡翠湾」这个名字可以有无数个——上海有一个、杭州也有一个。名字本身不代表你是谁，只代表「你属于哪个群」。

## 同一个名字，为什么有几十个信号源

你一定注意过：在公司或商场，WiFi 列表里只有一个「Company-WiFi」，但走到哪层楼信号都满格。真相是——**这几十个信号源共用同一个名字**。

这在 WiFi 术语里叫 **ESS（扩展服务集）**：公司在每层楼部署一个 AP（第一章讲过，AP 就是发 WiFi 信号的角色），所有 AP 都广播同一个 SSID，背后接的都是同一个公司内网。

类比连锁店：**同一家公司（同一个内网）在每层楼开了门店（AP），挂同一块招牌（SSID）**。你走到哪层，就近的门店服务你——招牌不变，服务不断。

## BSSID：手机真正连的是哪一家「门店」

新的问题来了：几十个信号源同一个名字，手机怎么分清谁是谁？靠 **BSSID（基本服务集标识）**——通常就是那个 AP 无线网卡的 **MAC 地址**，全球唯一，相当于每家门店的营业执照号。

所以「连 WiFi」的完整真相是：

```text
你在列表里选的是：名字（SSID）
你的手机实际连的是：某一家门店（BSSID = 那台 AP 的 MAC 地址）
```

最神奇的部分：你拿着手机从 3 楼走到 8 楼，视频电话不断——因为信号变弱时，**手机自动切换到了 8 楼那台信号更好的 AP**。名字没变、IP 没变、你毫无察觉。这个过程就叫**漫游**。三个词的关系一张表收尾：

| 名词  | 全称                         | 是什么                          | 生活类比       |
| ----- | ---------------------------- | ------------------------------- | -------------- |
| SSID  | Service Set Identifier       | 网络名字                        | 连锁店招牌     |
| BSSID | Basic Service Set Identifier | 单个 AP 的标识（通常=MAC 地址） | 门店营业执照号 |
| ESS   | Extended Service Set         | 同名多 AP 组成的整张网络        | 整个连锁品牌   |

## 坑一：隐藏 SSID ≠ 更安全

路由器设置里有个「隐藏网络」选项：不对外广播名字，别人搜不到，连的时候要手动输入。

听起来很安全，但真相是**防不住懂行的人**：你的手机存过这个网络后，走到哪都会周期性地广播一句「有没有叫 XXX 的网络？」——名字是明文的；真正连接的那一瞬间，名字也会出现在发给路由器的关联请求里。一个抓包软件就能看到。

一句话总结：**加密才是门锁，隐藏名字只是把门牌摘了——贼照样摸得到你家门口。** 而摘门牌的代价是真实的：新设备连接更麻烦、部分设备漫游更慢。安全这事，等第五章讲 WPA2/WPA3 加密时再正经谈。

## 坑二：同名的「免费 WiFi」可能是陷阱

在商场看到两个一模一样的「Mall-Free-WiFi」？其中一个可能是别人用手机开的同名热点（行话叫 **evil twin**，恶意双胞胎）。你连上去，上网流量就可能经过他的设备中转——账号密码、验证码都暴露在他的视线里。更糟的是，手机对同名网络的自动重连会帮攻击者省掉「诱骗」这一步。

防坑三招：

1. **公共 WiFi 不做敏感操作**：网银、支付、输密码，用手机流量更稳妥；
2. **连之前核对名字**：注意大小写和形近字（`Mall-Free-Wifi` 和 `Mall-Free-WiFi` 不是一家）;
3. **不用就关掉 WiFi 开关**：不给自动重连任何机会。

## 自查三问

1. 公司里同名的 WiFi，你在 3 楼连的和同事在 8 楼连的，是同一台设备吗？
2. 隐藏 SSID 为什么防不住抓包的人？
3. 在咖啡馆连「免费 WiFi」，最大的风险是什么？

<details>
<summary>参考答案</summary>

1. **不是**。同一个 SSID（名字）下，每层楼是不同的 AP（不同的 BSSID）；你的手机会自动漫游到离你最近、信号最好的那台。
2. 手机保存过隐藏网络后会**主动广播探测请求**（明文带名字），连接时名字也会出现在关联帧里——抓包就能看到。
3. **同名伪装热点（evil twin）**：连上后流量可能被中间人截获，敏感账号密码可能泄露。
