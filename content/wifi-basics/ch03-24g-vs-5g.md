# WiFi 小白（三）：2.4G 和 5G 怎么选？

这一章回答那个经典选择题：路由器上的 **2.4G 和 5G 到底该连哪个**。先澄清一个几乎人人都误会过的事，再给一张对比表、四句口诀，顺带解释智能家居为什么只认 2.4G。

## 先澄清：WiFi 的 5G ≠ 手机套餐的 5G

这是全场最高频的误会：

- 手机右上角状态栏的「5G」：**第五代蜂窝移动通信**（4G 的后继），信号来自运营商基站；
- WiFi 名字里的「5G」：**5 GHz 无线电频段**，一个频率数字，就像 FM 97.4 里的「97.4」。

类比：**一个是「第五代汽车」，一个是「5 号车道」**——都带个 5，但根本不是一回事。同理，WiFi 的 2.4G 是 2.4 GHz 频段，和「2.4 代」没有任何关系。

顺带记住：GHz 是频率单位（吉赫兹），频率越高，单位时间里电磁波振荡得越快——这个「快慢」直接决定了下面两条车道的脾气。

## 两条车道的脾气

| 维度       | 2.4 GHz（老国道）                        | 5 GHz（新高速）                      |
| ---------- | ---------------------------------------- | ------------------------------------ |
| 穿墙/覆盖  | 好：波长 12.5 cm，绕过障碍物的能力强     | 差：波长约 6 cm，撞墙衰减快          |
| 速度       | 慢：频段总宽仅约 83.5 MHz，通道窄        | 快：可用带宽大，能跑 80/160 MHz 信道 |
| 拥挤程度   | 高：蓝牙、微波炉、无线鼠标、邻居全挤在这 | 低：干净得多                         |
| 老设备兼容 | 全部支持                                 | 老设备可能不支持                     |

一句话原理：**频率越高、波长越短，绕过障碍物的能力越弱，被墙体家具吸收得越多**。所以「5G 快」和「5G 穿墙差」是同一枚硬币的两面——不是路由器不行，是物理规律。

**为什么 5G 能快那么多**（细节第四章讲信道时再展开）：

1. **路更宽**：2.4 GHz 全频段只有约 83.5 MHz，挤一挤最多一条 20 MHz 的信道；5 GHz 有几百 MHz 可用，路由器能用 80 MHz 甚至 160 MHz——车道宽一倍，数据并行能力近似翻倍；
2. **车道多**：5 GHz 信道多且互不重叠，邻居之间不用挤同一条。

## 四句实用口诀

| 你在哪                            | 连哪个  | 理由                            |
| --------------------------------- | ------- | ------------------------------- |
| 同一房间、隔一堵墙                | 5 GHz   | 快、干净，体验差距明显          |
| 隔两堵墙以上、楼上楼下            | 2.4 GHz | 慢一点但连得上，5G 可能只剩一格 |
| 门口/阳台的摄像头、智能音箱、插座 | 2.4 GHz | 多数智能家居芯片只支持 2.4G     |
| 出门在外连公共 WiFi               | 无所谓  | 反正都不是你家的，先看安全      |

**智能家居为什么只认 2.4 GHz**：这类设备用的是廉价单频段 WiFi 芯片，成本低、功耗低——厂商省下的每一分钱都体现在售价上。所以配网失败时，第一件事就是确认路由器有没有一个独立的 2.4G 网络可连。

## 「双频合一」是什么，要不要关

现在路由器默认把两个频段合成一个名字（行业叫法 **band steering**，频段引导），手机自己选连哪个。方便，但有两个副作用：

- **设备可能「死守」2.4 GHz**：明明人在客厅（5G 覆盖很好），手机却连了慢的频段，因为它算账的算法未必和你一致；
- **智能家居配网找不到名字**：合名后设备只看到「一」个网络，有些设备就是配不上。

想要确定性？把两个频段**拆成两个名字**（比如 `Home-5G` 和 `Home-2.4G`），手动指定——多敲几个字，换来少折腾。

## 6 GHz 又是什么新东西

WiFi 6E 和 WiFi 7 引入了第三段：**6 GHz**——更宽、更快、更干净，但穿墙更差（频率更高，同一枚硬币的第三面）。**国内目前未向 WiFi 开放**（该频段被规划用于蜂窝通信），国行设备基本用不上，先知道有这回事即可。

## 自查三问

1. 手机状态栏的「5G」和 WiFi 列表里的「5G」，是一回事吗？
2. 为什么隔了两堵墙后，5G WiFi 反而不如 2.4G？
3. 新买的智能插座配网失败，第一反应应该怀疑什么？

<details>
<summary>参考答案</summary>

1. **不是**。前者是第五代蜂窝移动通信（运营商基站的信号），后者是 5 GHz 无线电频段。
2. 频率越高波长越短，绕射能力越弱、被墙体吸收越多——5G 信号衰减快，隔墙后弱到连不稳；2.4G 虽然慢，但还能维持连接。
3. **频段**。大量廉价智能家居芯片只支持 2.4 GHz；如果路由器开了双频合一、或只提供了 5G 网络，设备就会找不到/连不上——先确认有独立的 2.4G 网络。
