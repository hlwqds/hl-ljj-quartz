# WiFi 小白（七）：光猫、路由器、AP——你家弱电箱里那堆盒子各自是干嘛的

> [!info] WiFi 小白系列 0. [[wifi-basics|系列索引]]
> 上一章：[[ch06-full-bars-but-slow|第六章：信号满格却很慢——手机上的信号格数到底在数什么]]
> **第七章：光猫、路由器、AP**（当前章）
> 下一章：[[ch08-ip-mac-dhcp|第八章：IP 地址与 MAC 地址——设备在网络世界里的两重身份]]

这一章回答：家里那堆盒子**分别是什么、各干什么活**、怎么五分钟认清楚——外加一个配置坑（双 NAT）和两个摆放坑。

## 先按顺序认一遍

```text
光纤入户
   │
[光猫] —— 把光信号翻译成电信号
   │ 网线
[路由器] —— 拨号上网、分发地址、当大门
   │
   ├── [AP] 发 WiFi（很多路由器里就内置了）
   ├── [交换机] 扩展有线口
   └── 手机 / 电脑 / 电视
```

### 光猫：翻译官 + 运营商的边界

光纤里跑的是**光信号**，你家的设备只认电信号——**光猫（ONU/ONT）就是那个翻译官**：一头接光纤，一头出网线。

它通常由运营商提供并管理（后台密码不一定给你），是「运营商网络」和「你家网络」的分界线。

### 路由器：小区大门 + 门卫

第一章讲过它的三件事：**拨号上网**（用运营商给的宽带账号，协议叫 PPPoE）、**给设备发 IP 地址**（DHCP）、**让全家共用一个公网出口**（NAT）。

### AP：WiFi 广播站

真正发 WiFi 信号的部分叫 **AP（接入点）**。它可能是一台独立设备（吸顶 AP、Mesh 子节点），也可能就集成在路由器里——所以「路由器发出的 WiFi」严格说是「路由器里的 AP 模块发出的 WiFi」。

### 交换机：有线口的扩展坞

路由器背后的网口不够用时，加一台交换机就多出几个口。它只做一件事：**把网线分叉**。

## 你家的盒子是哪一种组合

| 组合                        | 特征                                | 常见于                 |
| --------------------------- | ----------------------------------- | ---------------------- |
| 光猫一体机（光猫+路由+AP）  | 一个盒子：光纤口 + 网口 + 自带 WiFi | 运营商默认装机、小户型 |
| 光猫桥接 + 路由器           | 光猫只翻译，路由器拨号 + 发 WiFi    | 对网络有点要求的家庭   |
| 光猫桥接 + 路由器 + 独立 AP | 路由器在弱电箱，AP 在天花板/各房间  | 大户型、别墅、Mesh     |

**怎么分辨谁在拨号**（很实用的一招）：登录路由器后台，看 **WAN 口 IP**：

- `192.168.x.x` / `10.x.x.x` / `172.16~31.x.x` 这类**私网地址** → 上层光猫在拨号，你的路由器只是「网中网」（这就是**双 NAT**）；
- `100.64.x.x ~ 100.127.x.x` 这类地址 → **运营商的大内网（CGNAT）**：一路都是内网，说明你家没拿到真正的公网 IP——端口映射、远程访问照样受限；
- 真正的**公网地址** → 路由器自己在拨号，结构干净。

## 双 NAT 为什么是个坑

光猫拨号、路由器又做一次 NAT，等于你家套了两层门卫：外面想进来（远程访问、游戏联机、端口映射）要多穿一道门，经常穿不过去；依赖 NAT 穿透的协议（远程接入类 VPN）也更容易握手失败——[[ch11-openvpn|VPN 深度解析（十一）：OpenVPN]] 里有一张跨 NAT 场景的对照表。排查问题时还容易晕：「到底是谁在发地址？」

两个解决方向：

1. 光猫改**桥接模式**，让路由器拨号（推荐，性能与可控性都更好）；
2. 或者干脆只用光猫一体机，别再串联第二台路由器做 NAT。

（运营商是否允许改桥接、怎么改，各地不同——打客服电话是最快的路。）

> [!note] 改桥接前先记配置
> 切换模式时，上游网段与 NAT 方式可能一起变化，旧的端口映射、静态地址会全部失效——动手前先把旧配置截图或抄下来。同类坑在 [[thread-debug-ch06-border-router|Thread 调试（六）：边界路由器]] 的故障表里有完整记录。

## 两个摆放小坑

- **弱电箱是金属的**：把路由器/AP 塞进弱电箱，等于给 WiFi 信号套了个铁笼子——电波出不来（第一章的「小区广播站」被关进了铁皮屋）。能挪就挪，或者弱电箱只放光猫，WiFi 交给外面的 AP。
- **光猫自带的 WiFi 要不要关**：如果已经有路由器在发 WiFi，建议把光猫的 WiFi 关掉——少一个信号源，少一份信道干扰（第四章）。

## 自查三问

1. 光猫和路由器各自的核心职责是什么？
2. 怎么快速判断是光猫在拨号还是路由器在拨号？
3. 为什么把路由器放进弱电箱，WiFi 信号会变差？

<details>
<summary>参考答案</summary>

1. 光猫负责「光信号 ↔ 电信号」的翻译，是运营商网络的边界；路由器负责拨号、发 IP（DHCP）、共享出口（NAT）——通常还内置 AP 发 WiFi。
2. 看路由器后台的 **WAN 口 IP**：私网地址说明光猫在上层拨号（双 NAT），公网地址说明路由器自己在拨号。
3. 弱电箱多为金属材质，相当于给信号加了屏蔽罩——无线电波被大幅衰减。

</details>
