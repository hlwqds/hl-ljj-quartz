这一章回答：为什么每个设备有两个「地址」、路由器后台那堆 IP 和 MAC 都是什么、以及「MAC 地址过滤」为什么不是安全措施——最后把第一轮八篇串成一张地图。

## 两个地址，两种身份

一句话分工：

**IP 地址 = 门牌号（会变）；MAC 地址 = 身份证号（跟一辈子）。**

寄快递最贴切：包裹上写的收货地址（IP）决定包裹怎么送到你所在的楼；收件人的身份证（MAC）决定这栋楼里具体交给谁。搬家换地址，身份证号不会变。

| 对比     | IP 地址                       | MAC 地址                         |
| -------- | ----------------------------- | -------------------------------- |
| 是什么   | 网络里的位置标识              | 网卡硬件的唯一编号               |
| 例子     | 192.168.1.8                   | A4:B1:C2:3D:4E:5F                |
| 谁分配   | DHCP 自动分配（也可手动固定） | 出厂烧录（软件层面可伪造）       |
| 会变吗   | 会：换网络、租约到期          | 真机不变（手机有随机化，见下文） |
| 长度     | IPv4 32 位 / IPv6 128 位      | 48 位（6 字节）                  |
| 作用范围 | 全互联网路由用                | 同一局域网内识别设备             |

## MAC：出厂就烧在网卡里的身份证

MAC 地址长这样：`A4:B1:C2:3D:4E:5F`——6 组十六进制，48 位，出厂烧进网卡，理论上全球唯一。

- 前 24 位是**厂商编号（OUI）**，所以查 MAC 能猜出设备品牌（路由器后台常直接标出厂商名）；
- **手机现在默认随机化 MAC**：连 WiFi 时用临时生成的 MAC，防止商场、咖啡店追踪你——这是隐私功能，也让「MAC 白名单」变得更不可靠。

## IP：会变的门牌号

IP 地址是设备**在当前网络里的位置**：

- 在家里可能是 `192.168.1.8`，到公司变成 `10.20.30.40`，咖啡馆又是另一个——换网络就换地址；
- 由路由器的 **DHCP** 自动分配，设备重启或租约到期后会变（通常还落在同一段）；
- **私网地址**（`192.168.x.x`、`10.x.x.x`、`172.16~31.x.x`）只在局域网内有效；出门上网要靠路由器做 **NAT** 翻译成公网地址（第七章）。

## 它俩怎么配合：ARP

同一局域网里，设备知道对方的 IP，但网卡真正发数据要填对方 MAC 地址——于是先喊一嗓子：**「谁是 192.168.1.8？请把 MAC 报给我」**。这就是 **ARP** 协议（IPv6 里对应的机制叫 NDP）。对方应答自己的 MAC，通信开始。

## 三个实用场景

1. **路由器后台的「已连接设备」**：显示的正是「名字 + IP + MAC」——认陌生设备、查蹭网就从这看。
2. **重启后 IP 变了**：正常现象（DHCP 重新发牌）；想让设备固定，就在后台做「IP 绑定」。
3. **MAC 白名单不是安全措施**：MAC 可被软件伪造，现在的手机还默认随机 MAC——白名单既不安全，又容易把自家新设备挡在门外（呼应第二章）。

## 自查三问

1. 手机连不同的 WiFi，「不变的那个地址」是什么？
2. 为什么「MAC 地址白名单」挡不住真正的攻击者？
3. ARP 在局域网里解决什么问题？

<details>
<summary>参考答案</summary>

1. **MAC 地址**（硬件身份证不变；IP 是当前网络的位置，换网络就变）。
2. MAC 可以由软件伪造，而且手机默认使用随机 MAC——白名单只会挡住自己人。
3. 已知对方 IP 时，找到对应的 MAC 地址，好把数据帧准确发过去。
