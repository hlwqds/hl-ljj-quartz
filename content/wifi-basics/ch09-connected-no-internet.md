# WiFi 小白（九）：WiFi 连上了却上不了网——五步自查

> **第九章：连上了却上不了网——五步自查**（当前章）
> 下一章（明日更新）：Mesh 是什么，和中继差在哪

第六章讲的是「满格却慢」，这一章讲更急的场景：**WiFi 图标明明正常，网页就是打不开**。五步按顺序走，每步都能把范围砍掉一半。

## 先分清两种「没网」

| 现象                       | 问题在哪                  | 去哪找答案                                                                 |
| -------------------------- | ------------------------- | -------------------------------------------------------------------------- |
| WiFi 列表里搜不到 / 连不上 | 无线段：信号、密码、认证  | 第三、五章；进阶见 [[wifi-hw-debug-ch04-cannot-associate\|硬件调试（四）]] |
| 连上了，但网页打不开       | 无线段 OK，问题在「后面」 | 本章                                                                       |

本章只管第二种：**WiFi 连上了，但出不去**。

## 五步自查

### 第一步：看 IP——有没有拿到地址

打开手机 WiFi 详情，看 IP 地址：

- `192.168.x.x` / `10.x.x.x` / `172.16~31.x.x` → 路由器发牌成功，**进第二步**；
- `169.254.x.x` → **DHCP 失败**：没从路由器拿到地址。先重连一次 WiFi；一直这样就把路由器重启一下（第八章讲过 DHCP 的活）；
- `100.64.x.x ~ 100.127.x.x` → 运营商大内网（能上网，但远程访问受限，第七章）。

### 第二步：ping 网关——WiFi 段通不通

网关就是路由器的地址（常见 `192.168.1.1`）。

> [!tip] 手机上怎么 ping？
> 手机系统通常没有命令行——用路由器后台自带的「网络诊断 / ping 工具」（多数家用路由器都有），或装一个 PingTools 类 App，也可以换台电脑在命令行敲。另外记住：**ping 不通不一定等于断网**——部分网络会屏蔽 ICMP，判断时用「网页能不能打开」交叉验证。

- **通** → 你和路由器之间没问题，进第三步；
- **不通** → 无线段通但 IP 层不通：路由器故障，或连错了 WiFi（比如连到了隔壁同名热点，第二章）。

### 第三步：ping 公网 IP——宽带通不通

`ping 223.5.5.5`（阿里公共 DNS 的 IP，记不住就搜「公共 DNS IP」）：

- **通** → 宽带是好的，问题在 **DNS**，进第四步；
- **不通** → 宽带 / 光猫 / 运营商侧问题，进第五步。但先排除误判：如果网页其实能打开、只是 ping 不通，那是 ICMP 被过滤，不是故障。

ping 的一去一回具体经过哪些环节，见 [[ch9-ip4-icmp|lwIP 深度解析（九）：IP 与 ICMP——ping 的完整往返]]。

### 第四步：DNS 专项

典型症状：ping `223.5.5.5` 通，但 ping `baidu.com` 不通；或者微信还能收消息（长连接没断），新打开网页却转圈。

处置：手机 WiFi 设置里把 DNS 手动改成 `223.5.5.5` 或 `119.29.29.29`；更彻底的是在路由器后台改（全家生效）。

（DNS 是「域名 → IP」的电话簿，下一轮单独讲。）

### 第五步：光猫与运营商

- 看光猫指示灯：**LOS 红灯 / PON 不亮** → 光纤断了或机房侧故障，自己修不了，直接报修；
- 指示灯正常但上不了网 → 重启顺序：**先关光猫、等一分钟、再开**，稳定后重启路由器；还不行打运营商客服，报「宽带无法上网」；
- 别忘了最朴素的可能：**欠费**（真的常见）。

## 懒人版顺序

不想记五步？按这个顺序试一遍：

重启光猫 → 重启路由器 → 手机重连 WiFi → 检查是否欠费 → 打客服。

## 自查三问

1. 手机 IP 显示 `169.254.x.x` 说明什么？
2. ping 公网 IP 通、ping 域名不通，问题出在哪？
3. 光猫 LOS 红灯亮了，该做什么？

<details>
<summary>参考答案</summary>

1. **DHCP 失败**：没从路由器拿到地址——重连 WiFi，或重启路由器。
2. **DNS**：域名翻不成 IP；换公共 DNS（`223.5.5.5` / `119.29.29.29`）。
3. 光纤链路断了或信号丢失（运营商侧问题）：重启光猫后仍红灯，直接报修。

</details>
