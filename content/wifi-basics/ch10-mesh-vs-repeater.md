家里总有房间没信号——于是你搜到了三个词：**中继器、Mesh、电力猫**。这一章讲清它们的差别，以及一个反直觉的安装原则。

## 先看四种「扩信号」方案

| 方案          | 原理                               | 优点                 | 代价                                   |
| ------------- | ---------------------------------- | -------------------- | -------------------------------------- |
| 无线中继器    | 收主路由的信号，再转发给你的设备   | 便宜、即插即用       | 同频转发吞吐减半、延迟升高、切换不智能 |
| Mesh          | 多个节点自组网，统一管理、自动漫游 | 统一名字、走动不断线 | 贵；无线回程仍然损耗                   |
| 电力猫（PLC） | 借家里的电线传数据                 | 不用拉网线、能穿墙   | 受电路质量影响大，跨电表可能不通       |
| 有线 AP       | 每个点用网线接主路由               | 最稳最快（完全体）   | 要能拉网线                             |

## 中继器：便宜，但有硬伤

中继器的工作方式是「听一句、复述一句」——它用**同一个无线频段**既听主路由、又对你的设备说话，同一时刻只能干一件事。所以：

- **吞吐通常掉一半**（空口时间被转发吃掉）；
- 延迟升高，打游戏能感觉到；
- 信号格数好看了，速度未必。

一句话：中继器 = 应急用的信号搬运工，不是升级方案。

## Mesh：不是「更强的中继」，是「会协作的一组节点」

Mesh 的节点之间自己商量怎么连（**有线优先，没线就无线**），对外只用一个 WiFi 名字。你从客厅走到卧室，手机在节点之间切换是**无感**的——背后靠 802.11k/v/r 这类漫游辅助协议（小白记住「快速切换」即可）。

但有个关键事实：**Mesh 的每个节点也要「回程」**——数据得从节点再传回主路由，无线回程时同样要占空口时间。所以：

- **三频 Mesh** 多一个独立频段专门做回程，末端速度损耗小；
- **双频 Mesh** 无线回程会和你的设备抢空口，末端节点速度要打折；
- **有线回程的 Mesh（或纯 AP 模式）才是完全体**。

## 一个反直觉的安装原则

节点**不要**放在没信号的房间——它自己都收不到主路由的信号，拿什么转发？

正确位置：**主路由和盲区之间，信号还剩「两格以上」的地方**（手机上大约 -60 dBm 以内）。它要有好信号可接，才能把信号接力到盲区。

## 怎么选：按情况对号入座

| 你的情况           | 推荐                                      |
| ------------------ | ----------------------------------------- |
| 能拉网线，追求稳定 | 路由器 + 有线 AP（或支持有线回程的 Mesh） |
| 不能拉线，房子大   | 三频 Mesh（无线回程也够用）               |
| 只差一个房间       | 双频 Mesh 两台；中继器只作应急            |
| 老房子、电路干净   | 电力猫可当备选（先买一对测试再决定）      |
| 预算非常有限       | 中继器凑合，但别指望满速                  |

## 自查三问

1. 为什么中继器「信号满格」却可能更慢？
2. Mesh 节点的最佳摆放位置是盲区正中间吗？
3. 双频 Mesh 和三频 Mesh 差在哪？

<details>
<summary>参考答案</summary>

1. 同频转发：同一时间只能听或说，吞吐通常减半，延迟升高。
2. 不是。放在主路由与盲区之间、信号还剩两格以上的地方——它先要接到好信号，才有东西可转发。
3. 三频多一个独立频段专门用于节点间回程，无线回程时损耗小；双频的无线回程会和终端争抢空口。
