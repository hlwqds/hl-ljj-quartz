# F429 × Korvo-1：WiFi 协处理器实战

> [!tip] 系列说明
> 一句话使命：**让一块没有 WiFi 的 F429 通过一根 SPI 线获得完整的联网能力**——WiFi 侧由 ESP32-S3-Korvo-1 承担（跑满栈 IDF + lwIP），F429 侧只需要 SPI 和一套我们亲手设计的轻量协议。由浅入深五层：物理链路（SPI 全双工 + 握手）→ 帧协议（COBS + CRC32）→ 控制通道（TLV 命令）→ 数据通道（socket 代理 RPC）→ 应用与性能。末章把我们手搓的轮子与官方 ESP-AT / ESP-Hosted 对照，说清各自站位。
>
> 硬件事实先行：**ESP32-S3 没有 SDIO slave 外设**（经典款才有），所以高速链路走 SPI 全双工；这是本系列一切设计的出发点。板卡：挑战者 F429-V2（宿主，延续 [[f429-lab|F429 裸机实验室]]的裸机路线）+ ESP32-S3-Korvo-1（协处理器）。
>
> 实验配套 `practice/wifi-coproc-labs/`：协议层四件（帧/控制/代理/spidev）在本机（zig cc）真实测试留档；板级骨架（SPI 两侧）以编译验证入库，待真机回填——本仓「先成文后实跑」惯例。
