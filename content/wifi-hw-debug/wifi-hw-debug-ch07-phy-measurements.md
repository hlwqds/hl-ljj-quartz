## 7.1 为什么需要物理层证据：协议层证据链的天花板

前六章你已经打通了一条完整的协议层取证链：抓包看空口（第三章）、逐帧读连接状态机（第四章）、deauth 原因码对时间线（第五章）、iperf3 + 抓包联动看吞吐三角（第六章）。这套链路能回答「空口上发生了什么」，但它有一个结构性天花板：**L2 只能看到「结果」，看不到「为什么解调失败」**。

| 层    | 你能看到                            | 你看不到                                    |
| ----- | ----------------------------------- | ------------------------------------------- |
| L1/L2 | 重传率高、速率掉档、RSSI 看起来正常 | 重传是因为星座图擦花（EVM 差）还是频偏漂出  |
| L3    | 驱动报「握手超时」「重试耗尽」      | 超时的物理成因在 PA、晶振还是电源           |
| L4    | —                                   | 病灶本身：功率、EVM、模板、频偏、VSWR、电源 |

一个典型的「证据链断裂现场」（教学复盘案例，取材自常见故障模式综述）：设备 RSSI 满格、关联正常，但只有个别路由器连得上，且高 MCS 下丢包雪崩。抓包看到的是大量重传和速率自适应降档——**症状**齐了，**根因**四选一：发射链路问题（PA/匹配）、晶振频偏、电源纹波、还是真干扰？协议层无法裁决，因为 MAC 层重传把物理层失败统一翻译成了「丢帧」。要裁决，就得下到物理层，用四大指标分别对应四个嫌疑方向。

这就是本章的定位：**给 L4 装上仪表**。概念不从头讲——dB 家族在 [[ch03-decibel-family|射频入门（三）]] 建立过，发射链路在 [[ch04-tx-chain|射频入门（四）]] 拆过，接收与灵敏度在 [[ch05-rx-chain-sensitivity|射频入门（五）]] 讲过；本章只回答两个问题：**怎么测、多少算好**。

```text
症状（L2） ——抓包/日志→ 「解调在失败」（四选一悬案）
                 │ 本章
                 ▼
发射功率 → PA 没开够/饱和？        7.2.1
EVM      → 星座擦花，匹配/电源/链路增益？  7.2.2
频谱模板 → 带外泄漏在污染谁？      7.2.3
频偏     → 晶振问题，个别环境才翻车？     7.2.4
```

## 7.2 四大指标逐个过

每个指标按同一套四联展开：**是什么 / 怎么测 / 多少算好 / 坏了会怎样**。

### 7.2.1 发射功率与 EIRP

| 维度       | 内容                                                                                                                                                                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| 是什么     | 发射功率是天线下（传导）射频口的输出功率；**EIRP = 传导功率 + 天线增益 − 馈线/开关损耗**，是法规真正管的东西（含天线看出去的最大等效辐射功率）                                                                                                  |
| 怎么测     | 传导：射频口经 U.FL→SMA 工装引出到频谱仪，读信道内功率（见 7.3）；粗估：频谱仪积分信道带宽内的功率。手机 App 测不了绝对功率                                                                                                                     |
| 多少算好   | 芯片侧：ESP32 2.4 GHz 发射功率约 +20 dBm（802.11b 档，乐鑫 datasheet 典型值，待核对具体档位）；软件上 `esp_wifi` 可配置目标功率（有上限）；整机侧法规限值（2.4 GHz ISM 频段 EIRP 上限）因 FCC/CE/SRRC 而异，见 [[ch17-certification-regulations | 射频入门（十七）]] 与本系列第十一章 |
| 坏了会怎样 | **偏低**：链路不对称，能收发不出，表现为「看得见邻居、邻居看不见你」，连不上/上行吞吐差；**偏高**：PA 压缩把 EVM 拖垮（功率和 EVM 常互为因果），且带外泄漏变宽撞频谱模板，预测试 fail                                                           |

实践口径：

| 检查点           | 怎么做                                                                                              | 证据强度         |
| ---------------- | --------------------------------------------------------------------------------------------------- | ---------------- |
| 软件侧目标功率   | ESP-IDF `esp_wifi_set_max_tx_power()`（单位 0.25 dBm），读回 `esp_wifi_get_max_tx_power()` 确认生效 | 官方 API 口径    |
| 功率档与速率联动 | 确认配置的功率在当前速率档（11b/g/n）是芯片支持的，乐鑫 datasheet 各档典型值不同                    | datasheet 口径   |
| 整机 EIRP        | 传导功率 + 天线增益（天线规格书标称）− 线损；正式值必须辐射测试（第十一章）                         | 换算口径，见 7.3 |

### 7.2.2 EVM：星座图擦花程度

| 维度       | 内容                                                                                                                                                                                                                                                                                                                             |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| 是什么     | 发出来的星座点相对理想位置的偏移量，用 dB 表达（越负越好）。概念上就是「信号被噪声+失真擦花了多少」——射频入门系列的信噪比概念在发射端的镜像                                                                                                                                                                                      |
| 怎么测     | 频谱仪/矢量信号分析仪的 EVM 测量模式：输入被测信号 → 按对应 WiFi 制式（OFDM 参数）解调 → 输出 per-symbol 星座误差。dBm 家族的读法见 [[ch03-decibel-family                                                                                                                                                                        | 射频入门（三）]] |
| 多少算好   | 802.11 标准对不同星座（即不同 MCS 档）规定了 EVM 上限：**速率越高，容限越紧**。量级：64-QAM 约 -25 dB、256-QAM 约 -32 dB、802.11ax 的 1024-QAM 约 -35 dB（Keysight 等仪器厂商 AN 常引口径；BPSK/QPSK 档具体 dB 数待核对，以 802.11 标准原文表格为准）。一个推论：**发射 EVM 不达标，标准自动禁止你用高 MCS**——即使 RSSI 看起来够 |
| 坏了会怎样 | 高 MCS 下丢包雪崩、速率自适应反复降档（第六章吞吐三角的物理根源之一）；轻度超标表现为「短包正常、长包吞吐抖」，因为长包在差 EVM 下 FER 概率显著上升                                                                                                                                                                              |

EVM 的嫌疑方向（坏了先怀疑谁）：

| EVM 恶化的形态           | 优先嫌疑                           | 交叉引用                      |
| ------------------------ | ---------------------------------- | ----------------------------- | ---------------- |
| 高功率档才差，降功率好转 | PA 压缩（增益饱和 + 非线性）       | [[ch04-tx-chain               | 射频入门（四）]] |
| 各功率档都差一个常数     | 链路增益异常、匹配劣化（插损变大） | [[ch09-impedance-matching     | 射频入门（九）]] |
| 随发射突发抖动           | 电源纹波串进 PA/PLL                | 第九章                        |
| 仅部分信道差             | 频响不平坦、匹配在某频点劣化       | 第八章、[[ch08-passives-in-rf | 射频入门（八）]] |

### 7.2.3 频谱模板：带外泄漏

| 维度       | 内容                                                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 是什么     | 信道内功率允许「溢出」到带外的包络曲线。802.11 对每种带宽/制式定义了频谱模板（spectral mask），带外泄漏就是**干扰别人**的物理来源，也是邻道干扰与认证 fail 的共同上游   |
| 怎么测     | 频谱仪：span 覆盖被测信道 ±带宽余量，对照标准模板曲线看逐点功率。占用带宽（OBW）、邻道功率（ACP）是它的两个标准衍生指标，预测试会逐项考（第十一章）                     |
| 多少算好   | 802.11 标准按带宽定义了模板（逐点 dBc 数以标准原文为准，此处不展开抄表）；判读口诀：**模板是 dBc 曲线，参考零点是信道内峰值功率**，所以「功率设太高」本身就会把模板顶破 |
| 坏了会怎样 | 混测环境里表现为「你的设备一发包，邻居信道就遭殃」，现场常被误诊为干扰问题（锅在别人设备上）；认证必考项——杂散与 OBW/ACP 是预测试 fail 的常客                           |

模板问题的高频根因：功率配超了法规/模板值、PA 压缩导致的频谱再生（与 EVM 高功率档恶化同根）、基带滤波配置异常。诊断顺序建议：先看功率是否在合理范围，再看 EVM 是否压缩，最后才怀疑模板本身的滤波配置——三者常是同一病灶的三个投影。

### 7.2.4 频偏：从 ppm 概念到实测表现

ppm 与晶振选型的概念已在 [[ch11-crystal-clock|射频入门（十一）]] 建立过，这里直接讲**实测层**：频偏怎么发现、多少算好、坏了长什么样。

| 维度       | 内容                                                                                                                                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 是什么     | 发射载波相对真实频率的偏移，单位 ppm。发射端和接收端各有自己的晶振，OFDM 用导频做残余频偏校正，但偏差太大就校不回来                                                                                                         |
| 怎么测     | 仪器侧：频谱仪测载波频率偏移（或 EVM 测量中一并输出的频偏读数）；协议侧粗筛：抓包看个别设备是否系统性解调差。**真正的 ppm 定值需要仪器，协议层只能看到它的下游症状**                                                        |
| 多少算好   | 802.11 标准对时钟精度有量级要求（±20 ppm 量级，具体条款数待核对标准原文）；晶振个体偏差：芯片方案常见 ±10 ppm 档（乐鑫等厂商参考晶振规格，datasheet 口径，待核对具体值）。注意：温度是频偏的最大变量，冷机/高温下偏差会放大 |
| 坏了会怎样 | 两个签名症状：**① 个别路由器连得上、个别连不上**（对端接收容限不同，频偏大的发射打不满对端解调余量）；**② 仅高 MCS 丢包**（高 MCS 子载波相位余量紧，频偏先在它上面翻车）                                                    |

```text
频偏故障的自查顺序（教学复盘案例，取材自常见故障模式综述）：
症状「只连得上某些 AP / 只有高 MCS 丢包」
  → 排除软件：固定 MCS 档测试（iw mcs-fixed），确认是物理层而非速率算法
  → 排除环境：换路由器/换房间，确认与具体对端相关而非位置相关
  → 疑点收敛：同一台设备对所有 5G 路由器都差 → 嫌疑指向自身频偏/匹配
  → 定案：送仪器测频偏 ppm（7.6），或换参考晶振做 A/B（改板前最后一步）
```

### 7.2.5 四大指标对照总表

| 指标          | 一句话定义           | 主要仪器             | 判据口径                              | 坏了的典型签名                |
| ------------- | -------------------- | -------------------- | ------------------------------------- | ----------------------------- |
| 发射功率/EIRP | 信道内功率（含天线） | 频谱仪（功率积分）   | 芯片 datasheet + 法规限值（第十一章） | 链路不对称/上行弱             |
| EVM           | 星座擦花程度         | 频谱仪 EVM 模式      | 802.11 标准按 MCS 分档                | 高 MCS 丢包、速率降档         |
| 频谱模板      | 带外泄漏包络         | 频谱仪（span + dBc） | 802.11 标准模板（dBc）                | 干扰邻居、认证 fail           |
| 频偏          | 载波 ppm 偏移        | 频谱仪/计频          | 802.11 ±20 ppm 量级（待核对条款）     | 个别 AP 连不上、高 MCS 先丢包 |

## 7.3 传导 vs 辐射测量

### 7.3.1 传导测什么：把射频口引出来

| 项       | 内容                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------- |
| 测的对象 | **不包含天线**的射频口性能：传导功率、发射 EVM、频谱模板、频偏——即芯片 + 板级匹配网络到射频口为止的全部                   |
| 怎么引出 | 模组（如 ESP32-WROOM）预留 U.FL/IPEX 座或射频走线测试点，用 U.FL→SMA 工装线接到频谱仪；做在裸板阶段最方便，整机阶段需开壳 |
| 优点     | 不需要屏蔽环境、可重复性好、成本最低（一间普通实验室+一台频谱仪即可）                                                     |
| 看不到   | 天线效率、天线方向图、结构件对天线的影响——这些是辐射侧的事（第八章）                                                      |

### 7.3.2 辐射测什么：整机 + 天线 + 环境

| 项       | 内容                                                                              |
| -------- | --------------------------------------------------------------------------------- |
| 测的对象 | 整机装上天线后的**真实辐射**：EIRP、辐射方向图、辐射杂散、TRP——认证考的全在这一侧 |
| 环境要求 | 半电波暗室或至少受控的低反射环境；普通办公室的多径反射会让读数毫无意义            |
| 优点     | 是「用户真实体验」与法规定义的对象；缺点：环境贵、可重复性靠夹具与流程保证        |

### 7.3.3 为什么预测试用传导，以及换算关系

预测试（第十一章）大量项目用传导，原因很工程化：**便宜、可重复、能归因**——传导 fail 一定是你板子的问题，辐射 fail 可能是环境问题。判据换算关系：

```text
EIRP ≈ 传导功率 + 天线增益 − 馈线/开关/工装损耗
（各量 dBm 与 dB，加减即可；工装线损需用已知信号源或功率计标定）

反向：辐射测试读数偏高/偏低时，先核对工装链路损耗与天线增益口径
（峰值增益 vs 平均增益，dBi 口径），再怀疑板子本身。
```

| 阶段     | 测量方式 | 回答的问题               | 环境       |
| -------- | -------- | ------------------------ | ---------- |
| 板级开发 | 传导     | 芯片/匹配/馈线链路健康吗 | 普通桌面   |
| 整机开发 | 辐射粗测 | 天线装上后行为对不对     | 受控环境   |
| 预测试   | 传导为主 | 离法规限值还有多少余量   | 普通实验室 |
| 正式认证 | 辐射     | 法规意义上的 EIRP/杂散   | 认证实验室 |

## 7.4 仪器地图

### 7.4.1 三类仪器别搞混

| 仪器             | 看什么                                       | 能测四大指标中的           | 关键区别                                                                       |
| ---------------- | -------------------------------------------- | -------------------------- | ------------------------------------------------------------------------------ |
| 频谱仪（SA）     | 频域：功率-频率分布                          | 功率、频谱模板、频偏（粗） | 扫频式，看的是「平均」，抓瞬态弱                                               |
| 实时频谱（RTSA） | 频域 + 时间：突发信号（WiFi 本来就是突发的） | 上述全部 + 抓发射瞬态/毛刺 | 能看到「某一瞬间的频谱」，PW 是发射瞬态取证的主力                              |
| 矢网（VNA）      | S 参数：网络对频率的响应（回损/插损/匹配）   | 四大指标都不直接测         | **VNA 测的不是频谱**——它不发信号进空气，测电路两端口特性，第八章天线排查的主角 |

### 7.4.2 三个旋钮的直觉

频谱仪上手只需要先建立三个旋钮的手感（操作细节随厂商而异，此处讲物理含义）：

| 旋钮              | 物理含义               | 设错的后果                                                 |
| ----------------- | ---------------------- | ---------------------------------------------------------- |
| RBW（分辨率带宽） | 频率轴上的「像素大小」 | 太大：噪声底抬高、窄信号糊掉；太小：扫描慢，突发信号看不全 |
| Span              | 频率轴上看多宽         | 太窄：看不到带外泄漏；太宽：信道内细节分辨率不足           |
| 参考电平          | 屏幕顶端的 dBm 刻度    | 太低：强信号削顶（读数失真）；太高：小信号挤在底噪里看不清 |

WiFi 是**突发**信号：扫频 SA 上看到的是多帧平均的包络，读功率时要注意「峰值 vs 平均」口径（占空比换算），这也是 RTSA 在 WiFi 测试里更有优势的原因之一。

### 7.4.3 行情概念

| 档位                     | 大致定位                              | 口径                         |
| ------------------------ | ------------------------------------- | ---------------------------- |
| 入门手持 SA / SDR + 软件 | 粗看频谱占用、教学                    | 几百到几千元级               |
| 二手中低端台式 SA        | 传导功率/模板/EVM（需选件支持解调）   | 万元级上下，以行情为准       |
| RTSA（中高端）           | 突发/瞬态取证、认证级预测试           | 十万元级，以行情为准         |
| VNA                      | 天线/匹配排查（第八章）               | 二手入门数千元级，以行情为准 |
| 替代路径                 | 租借、共享实验室平台、委托外测（7.6） | 按地区行情为准               |

## 7.5 没有仪器时的降级估计

没有频谱仪不代表无事可做。三种方法按取证成本排序，各自给出**能回答什么、误差在哪、边界在哪**。

### 方法一：灵敏度对照法（定距吞吐阶梯 vs 期望曲线）

| 维度     | 内容                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 做法     | 固定信道/带宽/路由器，按距离阶梯（如 1 m/5 m/10 m/隔一堵墙）各跑一轮 iperf3 + 记录 `iw` 的 RSSI/速率，画出「距离-吞吐-速率」阶梯，与第六章建立的期望曲线对照 |
| 能回答   | 链路随距离衰减的行为是否符合物理直觉；高 MCS 是否过早消失（指向 EVM/频偏嫌疑）                                                                               |
| 误差声明 | 环境多径、人体走动、邻居流量都会污染阶梯——**同一阶梯至少重复 2~3 次取稳定形态**，否则不要下结论                                                              |
| 边界     | 只能定性（好/异常），给不出绝对 dB 数；无法区分功率问题与灵敏度问题                                                                                          |

### 方法二：互测法（两台设备对打看 RSSI 对称性）

| 维度     | 内容                                                                                                                          |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 做法     | 设备 A 当 STA 连参考路由器，另一台参考机（Linux 笔记本/第二块网卡）做对照站，同一位置分别读 RSSI 与单向吞吐                   |
| 能回答   | **链路不对称性**：A 能看见 B 但 B 看不见 A（RSSI 差距显著），强烈指向发射侧（PA 功率/天线馈电）问题                           |
| 误差声明 | 消费级设备 RSSI 本身有厂商标定差异（不同芯片间可比性有限，误差可达数 dB——待核对具体芯片口径），**只比对称性趋势，不比绝对值** |
| 边界     | 需要参考设备的 RSSI 可信；天线方向图差异会伪装成不对称（两台设备天线朝向不同）                                                |

### 方法三：手机 App RSSI 半定量

| 维度     | 内容                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| 做法     | WiFi 分析仪 App 站在不同位置读 RSSI，建立「位置-强度」地图；对照多次改板/改结构前后的**同位置差值**                      |
| 能回答   | 天线/结构改动有没有改善（**相对比较有效**）；覆盖盲区在哪                                                                |
| 误差声明 | 手机天线效率与朝向、握持姿势都影响读数，绝对值误差可能很大（各手机标定不一，量级待核对）；只可用于同手机同姿势的相对比较 |
| 边界     | 测的是「手机收到的」，不是「设备发出的」；诊断设备发射问题时要互换视角或用互测法                                         |

| 方法       | 成本 | 最好用于                  | 绝对给不出           |
| ---------- | ---- | ------------------------- | -------------------- |
| 灵敏度对照 | ¥0   | 距离行为、高 MCS 提前消失 | EVM dB 数、频偏 ppm  |
| 互测法     | ¥0   | 发射/接收不对称归因       | EIRP 绝对值          |
| App 半定量 | ¥0   | 改动前后相对改善          | 任何认证意义上的数值 |

三条方法共同的纪律：**降级估计的结论只用于「排除法归因」和「改动方向判断」，永远不要写进需要绝对数值的场合**——那个场合是 7.6 的事。

## 7.6 什么时候送实验室

### 判据清单

| 判据                                                    | 为什么自测穷尽不了                     |
| ------------------------------------------------------- | -------------------------------------- |
| 降级估计法给出嫌疑方向，但归因需要在功率/EVM/频偏间裁决 | 缺绝对数值，四选一无法收敛             |
| 客户现场无法复现（温度/位置/特定 AP 才触发）            | 实验室可控温度、可扫全信道、可换参考机 |
| 认证前自检（功率余量、模板、杂散）                      | 预测试本身就是实验室项目（第十一章）   |
| 改板决策（换晶振/调匹配/换 PA）前要拿定量基线           | 改板昂贵，决策依据必须是定量证据       |

### 送测前准备

| 准备项                | 内容                                                                                                                                                                                      |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 测试模式固件/连续发射 | 常见厂商提供连续发射（continuous TX）工具/测试固件：ESP32 系列有 RF 测试工具与连续波/连续调制模式（乐鑫官方工具口径，待核对最新版本）；送测**必须**用它，否则正常固件的突发流量无法稳定测 |
| 样机                  | 至少 2 台（1 测 1 备）；引好 U.FL→SMA 工装线并在外壳留测试口；标注板号与固件版本                                                                                                          |
| 接口文档              | 一页纸：射频口形式（IPEX/SMA）、供电要求、测试模式进入方式（串口命令/按键）、信道与功率可配置范围                                                                                         |
| 问题清单              | 把 7.1 悬案写成具体问题：「测 TX EVM @MCS7 是否达 64-QAM 上限」「测频偏 ppm」——实验室按问题报价排期，问题写得越具体越省钱                                                                 |

## 7.7 收尾：物理层病灶 ↔ 指标对照大表

| 症状（L2 看到的）           | 先查哪个指标        | 可能根因              | 后续章节                                 |
| --------------------------- | ------------------- | --------------------- | ---------------------------------------- |
| 看得见邻居、邻居看不见我    | 发射功率/EIRP       | PA 未开满、配置功率低 | 第十一章（限值口径）                     |
| 高 MCS 丢包、速率反复降档   | EVM                 | PA 压缩、电源纹波     | 第九章                                   |
| 个别路由器连不上/换 AP 好转 | 频偏                | 晶振偏差或温度漂移    | [[ch11-crystal-clock\|射频入门（十一）]] |
| 你的设备发包时邻道遭殃      | 频谱模板            | 功率超配、PA 非线性   | 第十一章                                 |
| EVM 全档差一个常数          | EVM + S11（第八章） | 匹配劣化、插损变大    | 第八章                                   |
| 发射瞬间复位/掉线           | 功率（+示波器电流） | 电源毛刺拉垮电压      | 第九章                                   |
| 拆装外壳后性能变化          | EIRP（辐射侧）      | 天线净空/金属件影响   | 第八章                                   |
| 改动前后拿不准有没有改善    | 全部降级估计法      | —（先定性再定量）     | 本章 7.5                                 |

最后三句话总结本章：**协议层只给结果，物理层给原因**；四大指标分别对应 PA（功率/EVM）、晶振（频偏）、匹配与链路（EVM/模板）、电源（EVM 抖动 + 第九章）四个病灶方向；没有仪器就用降级估计收敛嫌疑，收敛不了就按 7.6 带着具体问题清单送实验室——证据链到 L4 为止，再往下的 soldering 层留给第八、九章。
