## 8.1 现场：三类「装上去就不行」

概念在 [[ch06-antenna-basics|射频入门（六）]] 已经建立：增益、极化、驻波、方向图各是什么。本章不重复教概念，只回答一件事——**天线这东西，单测好好的，装上去就出问题**。这是天线与结构排查的全部矛盾来源：天线不是一个独立元件，它是一个「辐射体 + 周围环境」的系统，而外壳、净空、馈线、邻近金属全是环境的一部分。

三类高频现场，先认脸：

| 现场             | 症状                                          | 典型触发                                  |
| ---------------- | --------------------------------------------- | ----------------------------------------- |
| 金属外壳吞信号   | 开板正常，装机后 RSSI 掉十几 dB、穿墙能力消失 | 外壳/支架改为金属、增加金属装饰件         |
| 换批次灵敏度漂移 | 同设计不同批次整机，同位置 RSSI 差几个 dB     | 换天线供应商、换外壳供应商、馈线批次      |
| 开壳正常装壳变差 | 工装上测试全过，整机测试偶发丢包              | 装壳挤压馈线、外壳涂层/电镀、天线被压变形 |

这三个现场的共同点：**故障在装配域，单板测试看不见**。第八章（本章）的任务就是给这套问题一套取证顺序：先分类（8.2）、再测驻波（8.3）、再查馈线（8.4）、再查净空与结构（8.5）、然后回头审选型（8.6）、最后整改验证（8.7）。

## 8.2 症状三分类法：先分类再动手

天线问题千变万化，但按「差的分布方式」只分三类。分类本身就是第一个取证动作——它直接决定你接下来往哪查：

| 分类           | 症状特征                                        | 首要嫌疑                                       | 取证入口                         |
| -------------- | ----------------------------------------------- | ---------------------------------------------- | -------------------------------- |
| **全频段差**   | 2.4G 和 5G 一起差，各方向都差，且装配前后差异大 | 驻波恶化、馈线/连接器接触、馈线损伤            | 8.3 测 S11 + 8.4 查 IPEX 接触    |
| **特定方向差** | 某个方向信号骤降，其他方向正常；转个朝向就好    | 方向图被环境改变、安装朝向错、极化失配         | 转动设备观测 RSSI 方向性（定性） |
| **装配后才差** | 单板/工装正常，装机或装壳后差                   | 净空被金属侵占、外壳介质加载、天线与屏蔽罩耦合 | 8.5 逐项还原装配变量             |

取证顺序的决策树——拿到一台「疑似天线问题」的设备，走这个分支：

```text
症状是间歇的（时好时坏/按压变化/温度相关）？
 ├─ 是 ──→ 8.4 IPEX 接触不良专题（按压/换线/固定复测）
 └─ 否 ──→ 开壳 vs 合壳对比同一测量
            ├─ 装机后才差 ──→ 8.5 净空与结构（逐项还原装配变量）
            ├─ 差异只在某些方向 ──→ 方向图/朝向/极化（旋转设备观测）
            └─ 开壳合壳都差、各方向都差 ──→ 8.3 测 S11 看凹陷 + 8.6 审选型
```

每类的取证入口都有一个共同原则：**先找到「好状态」和「坏状态」的同一个测量点**。全频段差比的是同一频段装配前后的 S11；方向差比的是同一方位装机前后的 RSSI；装配差比的是开壳与合壳两种状态下的同一组读数。找不到「好状态」作对照，一切判断都是猜。

> [!note] 三分类的边界情况
> 馈线接触不良（8.4）常伪装成「偶发/时好时坏」，不在三类的主特征里——它属于「全频段差」的高频子类，但症状是间歇的。凡是「敲一敲/按一按/温度变一变就变」的，先跳到 8.4，不要在分类里打转。

## 8.3 VSWR/回损实测入门

### 8.3.1 判据直觉

概念（VSWR 与回损的换算、反射的来源）见 [[ch06-antenna-basics|射频入门（六）]]，这里只给现场判据：

| 指标     | 判据                                                    | 口径                                       |
| -------- | ------------------------------------------------------- | ------------------------------------------ | ---------------- |
| VSWR     | 工作频段内 **< 2** 常用作「可用」的经验线               | **经验口径**（工程惯例，非标准强制）       |
| VSWR     | 工作频段内 **> 3** 基本可判「天线系统有问题」           | **经验口径**                               |
| 回损     | 与 VSWR 等价换算（VSWR 2 ≈ 回损 9.5 dB，VSWR 3 ≈ 6 dB） | 换算关系，见 dB 家族 [[ch03-decibel-family | 射频入门（三）]] |
| 凹陷位置 | 谐振点应落在工作频段内；凹陷偏移 = 天线失谐             | 定性判据                                   |

关键不是记住数字，而是**看形状**：一条正常的 S11 曲线在工作频段内有一个明显凹陷（谐振点）；装配问题常见的三种病态形状——凹陷整体偏移（失谐/介质加载）、凹陷变浅（辐射效率掉或匹配被破坏）、凹陷分裂成两个（邻近金属耦合改变谐振结构）。形状识别不需要精确数值，一台 NanoVNA 就够。

### 8.3.2 工具阶梯

| 档位      | 工具                           | 能看什么                            | 局限                                                     |
| --------- | ------------------------------ | ----------------------------------- | -------------------------------------------------------- |
| ¥0        | 发射频段凹陷观测法（见 8.3.4） | 频段内有无凹陷的粗判                | 定性，无绝对数值                                         |
| ~¥150-500 | 天线分析仪/NanoVNA 类          | S11、VSWR、Smith 图、凹陷位置与深度 | 精度有限；低频段可靠性下降；务必先用开路/短路/50Ω 件验证 |
| 二手矢网  | 真矢量网络分析仪               | 校准后精确回损/驻波，可看 S21       | 贵、重、端口怕功率；操作门槛最高                         |

**矢网最小操作流**（会这一套就能用，不需要成为仪器专家）：

1. 开机预热后，设置起止频率（WiFi 场景设 2.4-2.5 GHz 和 5.15-5.85 GHz 两段分别看）。
2. **Cal 校准**：用校准件在测试端口做 Open/Short/Load（OSL）单端口校准——不校准的 S11 读数包含线缆误差，凹陷位置可能整体漂移，判失谐会误判。
3. 接被测天线，看 S11 与 VSWR 轨迹，记凹陷位置/深度。
4. 换状态（装壳/开壳、压紧/松开馈线），对比曲线形状变化。

> [!warning] 矢网安全
> 矢网端口只输出小信号，**不能承受发射功率**。接任何「能发射的板子」之前必须断电；间接馈电（U.FL 工装引出）时同样先确认板子不工作。烧一个端口，仪器直接残废。

### 8.3.3 U.FL→SMA 工装与线损记账

实测板载天线必须把信号「引出来」，标准做法是 U.FL（IPEX）→SMA 转接：拔掉板上天线，接工装，工装 SMA 端接仪器。这一路引入两笔记账：

| 记账项   | 内容                         | 处理                                                          |
| -------- | ---------------------------- | ------------------------------------------------------------- |
| 转接线损 | U.FL→SMA 线缆 + 转接头的插损 | 矢网校准时把整根线纳入校准面；NanoVNA 至少做 SOL 校准到线末端 |
| 误差来源 | 工装本身接触质量             | 换一根线复测，两次结果一致才可信                              |

dB 记账语言（dBm、dB、dBi 各自的角色）见 [[ch03-decibel-family|射频入门（三）]]，不重复展开。只强调一条纪律：**每换一次线缆/工装，重新记一次账**。现场争论「差了 1 dB」的案例，一半最后发现是两次测量用了不同的线。

### 8.3.4 没钱时的降级观测法及其局限

「发射频段凹陷观测法」：让设备自己发射，用频谱仪（或另一台能看频谱形状的工具）观察发射频谱在频段内的包络形状——天线失谐时包络会呈现倾斜/凹陷等异常形状。它**只能定性**：

- 能发现：明显的失谐（凹陷位置大幅偏移）、严重的辐射异常。
- 不能发现：轻微失谐、效率下降（回损好看但辐射效率低的天线在发射频谱上几乎无感）。
- 陷阱：发射功率本身随信道/温度波动，包络形状对比必须**同一信道、相近温度、背靠背进行**，否则波动会污染形状判断。

结论：降级法用于「有没有大问题」的筛查，**不能用于「改了 2 dB 还是不改」级别的决策**。那种决策请回到 8.3.2 的工具阶梯。

## 8.4 IPEX/U.FL 接触不良专题

### 8.4.1 为什么它是最常见的「天线病」

U.FL/IPEX 连接器是板对馈线的标准接口，但它本质是为**产线一次性插接**设计的：插拔寿命有限（厂商 datasheet 标典型值约 30 次插拔，**以具体型号 datasheet 为准，待核对**），接触面积小，靠卡扣保持压力。三个失效模式：

| 失效模式      | 机理                           | 症状特征                                   |
| ------------- | ------------------------------ | ------------------------------------------ |
| 插拔损耗      | 反复插拔磨损失弹性             | 调试插拔多次后「无缘无故」变差             |
| 微动/振动失效 | 振动让接触面微位移，氧化膜累积 | 装机后震动场景（风扇、搬运、车载）间歇故障 |
| 产线插不紧    | 卡扣未完全扣合，看起来接上了   | 出厂抽检不良、温度循环后失效               |

故障特征识别的关键词是**间歇性**：时好时坏、拍一拍就好、温度变化后出现、特定姿态下丢包。这些特征指向机械接触，而不是天线本身。

### 8.4.2 排查手法

按取证成本从低到高：

| 手法         | 操作                                   | 判读                                        |
| ------------ | -------------------------------------- | ------------------------------------------- |
| 按压复测     | 手指按压连接器头部，同时观测 RSSI/丢包 | 按压时症状变化 → 接触问题实锤               |
| 换线对比     | 换一根已知良好的馈线，重复同一测量     | 换线后恢复 → 馈线/接头问题                  |
| 固定后复测   | 用胶带/热熔胶固定连接器后再复测        | 固定后症状消失 → 微动失效                   |
| S11 抖动观测 | 矢网/天分连着看 S11，轻拨线缆          | 曲线随拨动跳动 → 接触不良（正常曲线应稳定） |

> [!note] 纪律：换下的线不要混回良品盒
> 排查中判定「可疑」的馈线和工装，立即物理隔离（贴标签单独放）。混线是这类排查反复失败的第一原因——上一轮刚排掉的问题件，下一轮又混进了对照组。

## 8.5 净空与结构

### 8.5.1 净空区规则

净空（keep-out）是天线周围**不放金属、少放介质**的区域。原理层面（天线为什么怕邻近金属）见 [[ch06-antenna-basics|射频入门（六）]]，layout 层面的具体规则（净空区尺寸、铺铜禁入、馈线走线）见 [[ch13-pcb-layout|射频入门（十三）]]。排查视角只需要记一张表：

| 侵占方式           | 机理                   | 现场常见来源                               |
| ------------------ | ---------------------- | ------------------------------------------ |
| 金属进入净空       | 改变谐振、吸能         | 螺丝、屏蔽罩改位、金属支架、电池（金属壳） |
| 大面积铺铜贴近天线 | 镜像电流抵消辐射       | 改板时铺铜「顺手补满」                     |
| 介质加载           | 介电常数使谐振频率下偏 | 装壳后塑料厚度变化、贴标签、泡棉变胶垫     |
| 馈线穿越净空       | 耦合与干扰             | 改板走线调整后馈线路径变化                 |

### 8.5.2 外壳材料影响表

外壳是最大的「环境变量」。定性影响排序（幅度因具体结构差异很大，**只作方向性判断，不作数值依据**）：

| 外壳状态                        | 对辐射的影响方向                     | 排查提示                                             |
| ------------------------------- | ------------------------------------ | ---------------------------------------------------- |
| 普通塑料壳（ABS/PC）            | 影响小，轻微介质加载                 | 基准状态                                             |
| 塑料壳 + 喷漆/电镀层            | 电镀层≈金属屏蔽，影响大              | 拆膜/换非电镀件做 A/B                                |
| 金属壳                          | 严重屏蔽，必须外置天线或壳上天线开窗 | 确认是否有开窗及天线是否对准                         |
| 内部金属膜/导电泡棉（EMI 措施） | 常被忽略的「半个金属壳」             | 查 BOM 里的导电材料件                                |
| 拆膜/开孔验证                   | —                                    | 疑似外壳问题时第一动作：开壳对比（8.1 现场三的解法） |

### 8.5.3 人体与金属件邻近失谐

2.4 GHz 波长约 12.5 cm，人体（含水）和金属摆件都是显著的环境负载。排查要点：

- 人体贴近会吸能并失谐，**手握位置不同 RSSI 可以差很多**——「手一放就断」的案例先查天线位置是否在手握路径上。
- 桌面金属支架、显示器支臂、机柜金属板都是方向图改造者。「某个方向突然变差」先扫一眼天线朝向上有没有新增金属物。
- 测试基准纪律：RSSI 对比必须在**同一物理位置、同一姿态**进行；手持 vs 桌面、朝向变化都会引入超过问题本身的差异。

### 8.5.4 同板多天线隔离与摆放

双频或 MIMO 设备板上有多根天线。排查视角三条：

| 检查项   | 内容                                                            | 症状指向                          |
| -------- | --------------------------------------------------------------- | --------------------------------- |
| 天线间距 | 两根天线距离越远隔离越好（经验上希望 ≥ λ/4 量级，**经验口径**） | MIMO 吞吐不达标、空间流速率上不去 |
| 朝向正交 | 相邻天线极化方向尽量正交                                        | 同上                              |
| 摆放对称 | 天线尽量远离板边屏蔽罩、电池、摄像头排线                        | 单边信号差、特定姿态差            |

顺带一提「特定方向差」分类里一个容易漏的分支：**极化失配**。外置胶棒天线被拧弯、天线杆横放（发射垂直极化、接收水平极化）时，理论上极化失配可以带来明显的耦合损失——实测中因室内多径反射，通常表现为「某个朝向明显变差」而非彻底断链。排查动作：把外置天线杆转回竖直（或对准对面设备的天线姿态）再对比。这一条成本为零，却常在「换了天线还是差」的案例里充当最后被发现的真凶。

## 8.6 天线选型错配案例家族

以下案例均为**教学复盘案例，取材自常见故障模式综述**，非虚构实测记录；症状与机理按公开常见模式综述。

### 8.6.1 2.4G 天线用在了 5G 频段

症状：2.4 GHz 一切正常，5 GHz 信号弱、速率低、距离差。根因：单频天线（常见于 2.4 GHz 胶棒天线或早期陶瓷天线）在 5 GHz 频段增益/效率大幅下降。

**双频天线的确认方法**：查天线规格书的工作频段（应覆盖 2400-2500 与 5150-5850）；无规格书的实物，用 8.3 的 S11 观测——双频天线应在两个频段各有一个凹陷，单频天线 5 GHz 段无凹陷。这一条是「选型审查」而非「调试」：天线订错货，怎么调都没用。

### 8.6.2 陶瓷天线的方向图陷阱

片式陶瓷天线体积小、成本低，但方向图通常有明显的弱方向（常见为贴装面法向以外的方向衰减明显）。症状：设备某个朝向信号骤降，「立着放好用、躺着放不行」。确认方法：同一位置旋转设备朝向，观测 RSSI 随朝向的变化——变化剧烈（远超装配随机性）即方向图问题。对策是安装朝向对准主要使用方向，或换更全向的天线形态。

### 8.6.3 PCB 天线改板后性能漂移

PCB 天线（如模组上的板载走线天线）的谐振由走线形状、净空、铺铜、板厚、板材介电常数共同决定。改板时任何一项变动——净空区被挪用、铺铜距离变化、换板厂导致板材参数漂移——都会让谐振偏移。入门系列讲过板载天线的升级决策链（[[ch18-antenna-upgrade-capstone|射频入门（十八）]]），排查视角的结论是：**PCB 天线的改板必须复测 S11**，不能假设「layout 只动了一点」。复测基线是上一版的 S11 曲线，所以版本管理要包含射频基线记录。

### 8.6.4 FEM 带来的功率余量错觉

板上有 FEM（PA/LNA 前端，见 [[ch10-rf-front-end-fem|射频入门（十）]]）时，发射功率口径被 FEM 抬高，链路预算表上「余量充足」。但 FEM 放大的是发射方向，**天线端的失谐/效率损失它救不回来**；且失谐还会反射回 PA，极端时影响 PA 工作。症状：传导测试（8.3 工装引出）功率正常，辐射测试/实场信号差。排查结论：有 FEM 的板子，传导数据合格 ≠ 天线系统合格，**天线端要单独取证**。

## 8.7 整改优先级与 A/B 验证方法

### 8.7.1 整改优先级

从便宜到贵、从可逆到不可逆：

| 优先级 | 动作       | 成本 | 例子                                     |
| ------ | ---------- | ---- | ---------------------------------------- |
| 1      | 装配修正   | ¥0   | 重插压紧馈线、挪开邻近金属、换安装朝向   |
| 2      | 结构件调整 | 低   | 外壳开窗、去掉电镀层、净空区清空         |
| 3      | 天线更换   | 中   | 换确认覆盖双频的型号、换全向性更好的形态 |
| 4      | 改板       | 高   | 天线位置/净空重设计、换板载天线形态      |

原则与全系列一致：**改板子永远放最后**。第 4 级动手前，第 1-3 级的每一项都应有「已排除」的取证记录。

### 8.7.2 A/B 验证方法

天线整改最怕「感觉变好了」。三条纪律：

1. **变量清单化**：一次只改一个变量（外壳、天线、馈线、位置），改动前写下清单，改动后逐项确认「其余未动」。同时改外壳和天线，变好变坏都说不清原因。
2. **同一测试位对比**：固定的物理位置（标记桌面位置、设备朝向、天线高度），改前改后各测一组。位置不同引入的差异经常大于整改本身的收益。
3. **记录环境基线**：日期时间、邻频占用情况（手机 App 粗测）、温度。环境不同（邻居路由器开关、微波炉使用时段）会让 RSSI/丢包基线漂移，没有基线记录就没法判断「变好」是真变好。

指标选择：RSSI（`iw` 读，见第二章）适合快速对比；吞吐（iperf3，见第六章）适合最终确认；S11 曲线适合定位谐振级问题。三者口径不同，报告中必须注明用了哪个。

## 8.8 天线与结构排查 checklist

| #   | 检查项            | 方法                      | 通过判据/口径                              |
| --- | ----------------- | ------------------------- | ------------------------------------------ |
| 1   | 症状分类完成      | 按 8.2 三分类归类         | 已确定属「全频段/特定方向/装配后才差」之一 |

> [!summary] 本章小结
> 天线问题的本质是「辐射体 + 环境」系统的装配域问题。取证顺序：先按症状三分类（全频段差→驻波与馈线；特定方向差→方向图与朝向；装配后才差→净空与结构），再按工具阶梯测 S11 看凹陷，IPEX 接触不良用按压/换线/固定三手法，选型错配（单频天线、陶瓷方向图、PCB 天线改板、FEM 幻觉）靠规格书与 S11 审查而不是调出来。所有对比遵守 A/B 三纪律：变量清单化、同一测试位、环境基线。判据数值均为经验口径，决策级对比请用校准过的仪器。
