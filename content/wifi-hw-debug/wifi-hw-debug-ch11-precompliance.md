# WiFi 硬件调试实战（十一）：认证预测试——送测之前，先把 80% 的低级 fail 排掉

> [!info] WiFi 硬件调试实战系列 0. [[wifi-hw-debug|系列索引]]
> 上一章：[[wifi-hw-debug-ch10-power-consumption|第十章：功耗调试]]
> **第十一章：认证预测试**（当前章）
> 下一章：[[wifi-hw-debug-ch12-casebook-checklist|第十二章：案例手册与调试清单]]

法规的概念框架——FCC/CE/SRRC 是什么、限值背后的逻辑、模组认证为什么值钱——[[ch17-certification-regulations|射频入门（十七）]]已经建立过。那一章回答「为什么有这套规矩」；本章回答工程师真正睡不着的问题：「**我的板子送进去，会不会挂？挂了怎么办？送测前我能自己先查掉多少？**」预测试的定位从来不是替代正式实验室，而是把「低级 fail」在自家工位上排掉，让送测变成一次通过率尽量高的事件，而不是一次次交学费。

## 11.1 现场引入：一次 fail 的代价账

先算账，再看技术。某团队的新款智能面板，整机送 FCC 认证，辐射杂散项目 fail——3 次整改、3 轮复测之后才过。这不是虚构案例，而是消费电子行业的**常见故障模式综述**（教学复盘案例，取材自常见故障模式综述；具体时间与金额以下为量级示意，以实际行情为准）：

| 代价项             | 量级（示意）        | 说明                                           |
| ------------------ | ------------------- | ---------------------------------------------- |
| 单轮整机认证测试费 | 数万元级/标准       | FCC/CE 各一轮；某一项 fail 复测通常按次另计    |
| 一轮整改-复测周期  | 1~4 周              | 排队 + 测试 + 出报告；旺季实验室排期更长       |
| 模具/结构件返工    | 数万元起            | 若 fail 源于外壳屏蔽或天线净空，改模具是硬成本 |
| 上市窗口           | 错过消费旺季 = 半年 | 11 月的货挂在上游认证，基本告别当年旺季        |
| 团队士气与机会成本 | 不可量化            | 射频工程师被反复拉去实验室陪测，本可以做新项目 |

把这张表倒过来看：**预测试的本质是花钱买信息**。一台二手频谱仪或一次实验室的「预扫（pre-scan）」服务，费用远低于一轮 fail 复测；而多数 fail 其实不需要任何仪器就能在设计阶段预防——11.4 的 TOP 清单里，一半是「看原理图就能发现」的问题。

一张决策图放在最前面，全章围绕它展开：

```text
设计定稿 ──► 设计侧自查（11.5，¥0）
              │  能排掉：时钟谐波、DCDC 噪声上报线、EIRP 超标、接口滤波缺失
              ▼
        传导预测试（11.5，频谱仪/预扫服务）
              │  能排掉：发射功率、占用带宽、传导杂散、频谱模板
              ▼
        实验室预扫（花钱买保险，可选）
              │  能排掉：辐射杂散的大方向问题（暗室数据仍与正式测有差）
              ▼
        正式送测（11.6）──► 一次通过
```

## 11.2 认证地图速览与「模组复用」的边界

三个主流市场的认证体系各管一段。概念细节见[[ch17-certification-regulations|射频入门（十七）]]，这里只给速查表：

| 体系 | 主管/标准                            | 适用市场   | 管什么（WiFi 相关）                           | 典型 WiFi 相关标准                         |
| ---- | ------------------------------------ | ---------- | --------------------------------------------- | ------------------------------------------ |
| FCC  | 美国联邦通信委员会（47 CFR Part 15） | 美国       | 发射限值、杂散、DFS（5 GHz 雷达避让）         | Part 15.247/15.407；具体限值以法规文件为准 |
| CE   | 欧盟（RED 指令 2014/53/EU）          | 欧洲经济区 | 频谱、EMC、安全、（部分设备）无电线电指令要求 | ETSI EN 300 328（2.4G）/EN 301 893（5G）等 |
| SRRC | 中国工信部无线电管理局（型号核准）   | 中国大陆   | 发射功率/带宽/杂散/频率容限（按信道逐项核）   | 信部无〔2002〕353 号等，限值以现行文件为准 |

三家关注的物理量高度重叠（功率、带宽、杂散），但**测试方法、限值数字、判定细节不同**。所以「过了 CE 不等于过 FCC」——别拿一份报告到处复用。

### 模组认证复用 vs 整机测试

这是选型期就要做的决定，做错会直接变成 fail。核心逻辑：**模组的认证是连着「当时那根天线、那种屏蔽环境」做的**（[[ch18-antenna-upgrade-capstone|射频入门（十八）]]里的 WROOM-1U 例子：认证限定天线增益不超过 2.33 dBi）。

| 场景                                                   | 能否复用模组认证                | 理由与动作                                                                                     |
| ------------------------------------------------------ | ------------------------------- | ---------------------------------------------------------------------------------------------- |
| 用已认证模组 + 原装板载天线 + 塑料外壳 + 净空良好      | 通常可复用（ Modular Approval） | 省 2.4G/5G 射频项的整机测试；EMC/安全等项目仍需整机做                                          |
| 换了更高增益/不同类型的天线（PCB 天线 → FPC → 金属杆） | **不可直接复用**                | 认证与天线绑定；变更需重新评估甚至重测（本节口径：以模组厂商认证说明为准，常见为需要补充测试） |
| 外壳引入金属件、屏蔽结构大改、天线被金属包围           | **不可直接复用**                | 辐射特性已变，模组报告不代表整机行为；必须整测                                                 |
| 模组焊进自己的板子但布局/净空良好、天线未动            | 通常可复用                      | 保留模组厂商的认证副本与天线规格说明备查                                                       |
| 用裸片（chip-down）设计                                | 无模组认证可言                  | 整机做全套射频认证                                                                             |

一句话版本：**照抄参考设计、不动天线，模组认证替你省大钱；一旦动了天线或屏蔽，省钱逻辑失效，按整机送测来排期和预算。**

## 11.3 测什么：WiFi 产品常规测试项

预测试的前提是知道正式测什么。下表是 WiFi 产品射频项的常规清单（限值数字随频段/地区/标准变化，**本章一律不写具体 dB 值，以对应法规文件为准**）：

| 测试项                    | 测的是什么                                                  | 典型方法简述                                                           |
| ------------------------- | ----------------------------------------------------------- | ---------------------------------------------------------------------- |
| 发射功率限值              | 各信道最大 EIRP/传导功率是否超法规上限                      | 传导法：样机射频口引出至频谱仪逐信道测                                 |
| 功率谱密度（PSD）         | 单位带宽内的功率密度（高阶调制/大带宽设备的关注点）         | 频谱仪 RMS 检波测每 MHz 功率                                           |
| 占用带宽（OBW）           | 发射能量 99% 集中的带宽是否超授权范围                       | 频谱仪 OBW 功能直接读                                                  |
| 带外发射（OOB）与频谱模板 | 主瓣之外的滚降是否落进模板框内                              | 频谱模板比对，逐点超框即 fail                                          |
| 杂散发射（传导）          | 从射频口「有线漏出去」的带外谐波/寄生分量                   | 频谱仪宽扫（几十 MHz 到数十 GHz），比对限值线                          |
| 杂散发射（辐射）          | 从机壳/线缆「无线漏出去」的分量，3 m/10 m 法在暗室/开阔场测 | 暗室转台 + 测量天线，扫描找峰值                                        |
| 频率容限                  | 载波频率偏移是否在容差内（晶振问题的直接暴露点）            | 频谱仪测中心频率偏差                                                   |
| DFS（仅 5 GHz 部分信道）  | 检测雷达信号并主动让频的机制是否正常                        | 实验室注入模拟雷达脉冲，验证检测与退避（一句带过，细节超出预测试范围） |

**哪些项最常 fail？** 行业经验的排序（教学复盘综述口径，非统计报告）：辐射杂散 > 传导杂散（时钟谐波类）> 占用带宽/频谱模板 > 发射功率（EIRP 算错）> 频率容限。前两名几乎都和「射频链路之外」的电路有关——这正是预测试能提前抓的原因。

## 11.4 常见 fail TOP 清单与对策（本章核心）

每一项按「失败机理 → 低成本对策」展开。这份清单同时也是 11.5 自查清单的展开版。

### TOP 1：杂散超标——时钟谐波

| 环节       | 内容                                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 失败机理   | MCU/DCDC/晶振的谐波频率恰好落在测试频段内，经电源、地或邻近走线耦合进天线馈线，随天线辐射出去                                                 |
| 典型嫌疑   | 晶振基频及其谐波（如 40 MHz 的整数倍正好扫过带内/带外测试点）；高频时钟线紧贴天线馈线平行走线                                                 |
| 低成本对策 | ① 布局审查：时钟线远离天线馈线与 RF 走线，避免长距离平行走线；② 时钟线串小阻值电阻/加共模滤波；③ 屏蔽罩接地（导电且接地才生效，见[[wifi-rf-hw | 射频入门系列]]拆机章）；④ 晶振下方铺地、包地处理 |
| 验证手段   | 频谱仪宽扫传导杂散，看时钟谐波族是否可见（预测试阶段就应排查，而非等辐射测试暴露）                                                            |

### TOP 2：杂散超标——DCDC 开关噪声上报线

| 环节       | 内容                                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 失败机理   | DCDC 开关频率及其谐波（百 kHz~数 MHz 基频，谐波可延伸很高）通过电源轨和地弹耦合到 RF 链路或线缆上再辐射                                          |
| 典型嫌疑   | DCDC 布局在地共阻抗上与射频地纠缠；电感未屏蔽；输出纹波滤波不足；线缆（USB/电源线）成了辐射天线                                                  |
| 低成本对策 | ① 优先改布局：DCDC 远离天线/RF 区域，减小回路面积；② 输出加磁珠+电容的 π 型滤波；③ 线缆入口加共模扼流圈/磁环（结构允许时）；④ 确认屏蔽罩接地连续 |
| 验证手段   | 示波器看电源纹波（第[[wifi-hw-debug-ch09-power-integrity                                                                                         | 九章]]的方法）+ 频谱仪看传导路径；两步都不需要暗室 |

### TOP 3：占用带宽/频谱模板超限

| 环节       | 内容                                                                                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------- |
| 失败机理   | 信道内功率「胖」出了授权带宽：调制质量差（EVM 劣化导致频谱扩散）、功率推得太满导致频谱再生、带宽配置错误（40/80 MHz 用在了不该用的信道）                                                      |
| 低成本对策 | ① 核对固件信道带宽与地区设置（`iw` 查看当前信道带宽，第二章的方法）；② 适当回调发射功率——满功率常伴频谱再生；③ 查供电：发射瞬间电压跌落会直接劣化 EVM（第[[wifi-hw-debug-ch09-power-integrity | 九章]]的因果链）；④ 天线失配也会推高带外能量（第[[wifi-hw-debug-ch08-antenna-structure | 八章]]的 VSWR 检查） |
| 验证手段   | 频谱仪看频谱模板；没有仪器时先做 ③④ 这两项免费检查                                                                                                                                            |

### TOP 4：发射功率超限——EIRP 算进天线增益的经典错误

| 环节         | 内容                                                                                                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 失败机理     | 法规限的是 **EIRP = 传导功率 + 天线增益 − 线缆损耗**。团队按「芯片 datasheet 的最大功率」设置固件，忘了天线增益要加回去（或换了大增益天线没降功率），整机一测超限                                     |
| 典型数字陷阱 | 换天线：原 PCB 天线换成 3 dBi/5 dBi FPC/杆状天线后功率设置未调整；多天线产品误把「每根」限值当「整机」限值（口径随法规地区而异，**以对应法规文件为准**）                                              |
| 低成本对策   | ① 选型期就按 EIRP 预算倒推：固件最大功率 = 法规 EIRP 上限 − 天线增益 + 馈线损耗（负值代数运算，别心算）；② 换天线 = 认证变更（11.2 的表），重新算预算并记录；③ 预测试逐信道传导测功率，别只测中心信道 |
| 验证手段     | 传导法测各信道功率 + 对照天线增益规格书做 EIRP 预算表（11.8 checklist 的固定栏目）                                                                                                                    |

### TOP 5：辐射杂散——结构与线缆辐射

| 环节       | 内容                                                                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 失败机理   | 板内没有直接漏出去的，但 USB 线/电源线/网线/金属支架/外壳缝隙充当了「意外天线」，把板上的噪声辐射出去                                                |
| 典型嫌疑   | 线缆未滤波直接出壳；外壳金属件与 PCB 地只有单点接触形成谐振结构；天线净空区被金属件/贴纸/线缆侵入（[[ch18-antenna-upgrade-capstone                   | 射频入门（十八）]]的净空规则） |
| 低成本对策 | ① 接口出壳处加滤波（共模扼流圈/穿心电容/磁环）；② 线缆尽量短、贴地走；③ 外壳金属件多点接地而非单点搭接；④ 尊重天线净空：净空区内不得有任何金属与走线 |
| 验证手段   | 这个项目预测试**最难自查**（需要暗室）；设计侧对策是唯一经济手段——靠 11.5 的设计自查清单兜底                                                         |

### 汇总：一张「失败机理→对策」速查表

| Fail 项目     | 失败机理一句话               | 第一动作（免费）        | 第二动作（花小钱） |
| ------------- | ---------------------------- | ----------------------- | ------------------ |
| 时钟谐波杂散  | 时钟耦合进天线/线缆          | 布局审查 + 屏蔽罩接地   | 时钟滤波、二次改板 |
| DCDC 噪声杂散 | 开关噪声经电源/地上报        | DCDC 远离 RF + 回路面积 | π 滤波、磁环       |
| OBW/模板超限  | EVM 劣化/功率推满/带宽配置错 | 查固件带宽与功率设置    | 频谱仪实测模板     |
| EIRP 超限     | 忘了天线增益要加进功率预算   | 重算 EIRP 预算表        | 逐信道传导复测     |
| 辐射杂散      | 线缆/结构件当天线            | 接口滤波 + 净空检查     | 实验室预扫定位     |

## 11.5 低成本预测试路线

### 路线 A：传导预测试（有频谱仪或能借到工装）

第七章建立过传导 vs 辐射的区别：辐射测试要暗室，传导测试只要一根同轴线把样机的射频口引到频谱仪。**绝大多数射频项 fail 在传导域就能暴露**：

| 自查项         | 方法                                            | 判据口径                           |
| -------------- | ----------------------------------------------- | ---------------------------------- |
| 各信道发射功率 | 连续发射模式 + 频谱仪信道功率测量，逐信道过一遍 | 对照 EIRP 预算表（法规限值待核对） |
| 占用带宽       | 频谱仪 OBW 功能                                 | 授权带宽内                         |
| 频谱模板       | 频谱仪模板功能叠加比对                          | 模板框内（模板以法规为准）         |
| 传导杂散       | 宽扫（低到几十 MHz、高到谐波可及范围）          | 对比限值线（以法规文件为准）       |
| 时钟谐波族     | 在杂散扫描结果里找等间隔谱线族，间隔=时钟基频   | 可见即风险，先整改再送测           |
| 频率容限       | 频谱仪测中心频偏                                | ppm 量级容差（以标准为准）         |

没有自己的仪器？两条降级路线：① 找实验室买一次**预扫服务**（比正式测试便宜，出数据不出报告）；② 借用/合租仪器，按 11.1 的代价账，一次 fail 的复测费就够买回一整个预测试日。

### 路线 B：没有仪器时的设计侧自查（¥0）

照着参考设计做，是最便宜的「预测试」。逐项核对：

| 自查项           | 检查内容                                                                                | 出处/依据                                          |
| ---------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------- | ------ |
| 参考设计对照     | RF 匹配网络、晶振电路、去耦电容与厂商参考设计逐元件对照（值、位置、封装都不能自己发挥） | 模组/芯片硬件设计指南                              |
| 天线净空         | 净空区内无走线、无金属、无电池、无螺丝；外壳内侧对应区域无金属喷漆/金属贴               | ESP-FAQ + 第[[wifi-hw-debug-ch08-antenna-structure | 八章]] |
| 屏蔽罩           | RF 区域屏蔽罩存在、材料导电、接地连续（多个接地过孔）                                   | ESP-FAQ（屏蔽罩须接地）                            |
| 时钟与 DCDC 布局 | 时钟线不贴天线馈线；DCDC 远离 RF 区域；大电流回路面积小                                 | 11.4 TOP 1/2                                       |
| 接口滤波         | USB/电源/网线出板处有共模滤波位（哪怕先贴 0 Ω，位置留出来）                             | 11.4 TOP 5                                         |
| EIRP 预算表      | 天线增益、馈线损耗、固件最大功率三项代数和落在法规限内                                  | 11.4 TOP 4                                         |
| 地与结构         | 外壳金属件与 PCB 地多点搭接；无孤立金属件                                               | 11.4 TOP 5                                         |

### 预测试能排掉 vs 排不掉的问题

诚实划界，避免「我自查过了为什么还挂」的错觉：

| 能排掉（预测试覆盖）                     | 排不掉（必须实验室）                                       |
| ---------------------------------------- | ---------------------------------------------------------- |
| 发射功率/EIRP 超标（传导法直接测）       | 辐射杂散的**准确判定**（暗室环境不可复制，预扫只有方向性） |
| 占用带宽、频谱模板、频率容限             | 辐射限值余量（家庭/工装环境本底噪声淹没小信号）            |
| 传导杂散（时钟/DCDC 谐波族的「存在性」） | 5 GHz DFS 行为（需要专用雷达信号模拟器）                   |
| 设计侧低级错误（净空、接地、滤波缺失）   | 正式报告与证书本身                                         |

## 11.6 送测准备：把实验室时间花在刀刃上

实验室按小时计费、按排期走。样机或文档不齐，浪费的是自己的窗口。

| 准备项       | 要点                                                                                                                                                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 样机数量     | 通常 2~3 台起（不同认证/不同项目可能要求多台与不同状态样机），**以测试机构要求为准**                                                                                                                                            |
| 测试模式固件 | 提供「连续发射/连续接收/逐信道锁定」的工程测试固件或工具入口——各芯片厂商都有自己的 RF 测试工具（如乐鑫 ESP32 的 RF 测试工具、其他厂商的裸频测试模式），提法仅供对照，**不构成工具选型背书**；确认机构认可你们的测试模式入口方式 |
| 文档清单     | 规格书、方框图、原理图（机构通常需要）、天线规格与增益说明、用户手册、Label 位置说明、固件版本记录                                                                                                                              |
| 运行模式覆盖 | 明确告知哪些模式需要被测（TX 最大功率态、含无线+有线同时工作的态），漏报一个模式=回去补测                                                                                                                                       |
| 沟通要点     | 送测前一次电话/邮件对齐：适用标准版本、目标市场、DFS 信道是否使用、样机供电方式、预期排期                                                                                                                                       |

一条经验规则：**机构测的是你「说明书里承诺的产品」**。文档里写了的功能（哪怕固件暂时关掉）都可能被测；反过来文档没写的模式不会被测——文档与固件行为要一致，别用「文档装傻」赌运气。

## 11.7 费用与周期量级

数量级概念，**以行情为准，仅给数量级概念**（2026 年前后消费 WiFi 产品的大致印象，随地区、机构、产品复杂度浮动很大，不构成报价）：

| 项目                        | 数量级（示意）       | 备注                                  |
| --------------------------- | -------------------- | ------------------------------------- |
| 单市场整机认证（FCC 或 CE） | 数万元人民币级       | WiFi+BLE 双模、5 GHz 支持都会加项加价 |
| SRRC 型号核准               | 万元级到数万元级     | 以现行收费与代理行情为准              |
| 单项 fail 复测              | 千元到万元级/次      | fail 越晚发现，叠加的排期成本越贵     |
| 实验室预扫                  | 通常明显低于正式测试 | 买的是「方向性数据」，不是证书        |
| 整改一轮（含改板）          | 2~6 周               | 改 PCB 打样 + 验证 + 重新排队         |
| 改模具（若 fail 涉结构）    | 万元级起 + 模具周期  | 11.1 代价账里最重的一项               |

费用结构里最反直觉的一点：**fail 的钱主要花在排期上，不是测试费上**。所以预测试的价值以「周」计价，不以「元」计价。

| #   | 检查项                                                  | 状态口径                     | 对应小节 |

| 1   | 天线/屏蔽方案与模组认证范围一致（未换天线、未改屏蔽）   | 若不一致 → 按整机送测排预算  | 11.2     |

| 3   | EIRP 预算表完成：天线增益+馈线损耗+固件功率代数和       | 逐信道核对，留余量           | 11.4     |
| 4   | 固件信道带宽/地区码设置与目标市场一致                   | `iw` 或固件配置确认          | 11.4     |

| 7   | 所有出壳线缆（USB/电源/网线）有共模滤波措施             | 原理图+BOM 核对              | 11.4     |
| 8   | 天线净空区无金属/走线/贴纸，外壳内侧无金属涂层          | 结构对照净空图               | 11.4     |
| 9   | 屏蔽罩导电且接地连续（多接地过孔）                      | 目检+万用表通断              | 11.4     |
| 10  | 传导预测试完成：功率/OBW/模板/杂散/频偏逐项过           | 有数据记录；无仪器则预扫替代 | 11.5     |

| 12  | 测试模式固件（连续收发/锁信道）就绪且机构认可入口       | 与机构对齐                   | 11.6     |
| 13  | 文档包齐：规格书/框图/原理图/天线增益说明/手册/标签位置 | 按机构清单逐项勾             | 11.6     |
