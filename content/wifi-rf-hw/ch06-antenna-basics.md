## 6.1 天线是什么：物理世界的网络接口

### 换能器：电流与电磁波的编解码器

先给结论：**天线是一个换能器（transducer）——物理世界的网络接口**。发射方向上，它把馈线上「束缚」的高频电流翻译成空间中自由传播的电磁波；接收方向上反过来，把落在它身上的电磁波翻译回电流。这与网卡 PHY 把比特翻译成线路信号、再把线路信号翻译回比特，是同一个角色：**两个世界之间的编解码器**。

| 软件世界                     | 天线世界                        |
| ---------------------------- | ------------------------------- |
| 网卡：比特与线路信号的编解码 | 天线：电流与电磁波的换能        |
| RJ45 水晶头与网线            | IPEX 座与射频缆                 |
| 接口协议不匹配，握手失败重传 | 阻抗不匹配，能量反射（VSWR）    |
| 双网卡主备 bond 切换         | 双天线分集 esp_phy_set_ant 切换 |

这张对照表是本章的主线：6.4 讲第三行（反射），6.5 讲第四行（分集）。还有一个有用的性质：天线是**无源、双向**的——同一个结构既当发射也当接收，而且两个方向的特性一致（互易定理，天线教材通识）。所以「发射增益」和「接收增益」是同一个数。

「接口」视角还有个排障红利：接口坏了的现象你熟——速率掉底、时通时断、重启偶尔能救；天线环节出问题的现象一模一样（接触不良、失谐、遮挡），排查顺序也因此类似：**先查物理连接，再查配置**。ESP-FAQ 对「怎么提升接收距离」的回答顺序正是如此——先「调整模组方向让辐射较强方向对准接收设备」、确认「天线附近没有金属遮挡物、天线背面没有 PCB」，然后才轮到换外置天线（ESP-FAQ「RF 相关」页）。

### 增益的真相：能量守恒，压扁波瓣

datasheet 上天线增益的单位是 dBi。**天线是无源器件，不含任何电源，不可能凭空放大能量**——那 dBi 从哪来？

类比麦克风：全向麦克风对四面八方一样灵敏，定向麦克风（采访枪麦）拾音距离远得多，但代价是只对正前方灵敏。它并没有「放大」声音，只是**丢掉了不关心的方向，把灵敏度集中到一个方向**。天线增益完全是同一回事：**增益 = 方向性换来的**。理想点源向四面八方均匀辐射，定义为 0 dBi 基准；把辐射波瓣往某个方向「压扁」，那个方向场强变大，代价是别的方向变弱——总能量不变（能量守恒）。

| 天线形态         | 常见增益量级 | 波瓣形状               | 典型场景       |
| ---------------- | ------------ | ---------------------- | -------------- |
| 全向（棒状）     | 2~5 dBi      | 方位面近圆，俯仰面压扁 | 路由器外置天线 |
| 全向（PCB 倒 F） | 0~2 dBi      | 近似全向但不规则       | ESP32 模组板边 |
| 定向（平板）     | 6~12 dBi     | 主瓣朝前，背后凹坑     | 定向覆盖、桥接 |
| 定向（八木）     | 7~15 dBi     | 主瓣窄而长             | 点对点远距离   |

注：增益数值为行业常见量级，**待核对**（乐鑫官方文档对自家模组只给定性描述，见 6.5）；单位口径：dBi 以理想全向点源为 0 dB 基准，dBd 以半波振子为基准，0 dBd = 2.15 dBi（天线教材通识）。

两个直接推论：其一，「高增益天线」不是信号增强器，而是**把覆盖从球形换成扇形**——路由器高增益天线的代价是头顶和脚下更弱；其二，发射功率（dBm，第五章）与天线增益（dBi）相加得到 EIRP，这是法规限制的对象，第十七章（认证）会回来讲这个数。

## 6.2 波长与尺寸：为什么 PCB 天线长那个样

### 2.4 GHz 的尺子：波长 12.5 cm，四分之一 3.1 cm

天线尺寸不是拍脑袋画的，由波长决定：λ = c / f。把 2.4 GHz 频段代进去：

- 2400 MHz（信道 1 下沿）：λ = 3×10⁸ / 2.4×10⁹ = **12.5 cm**
- 2483.5 MHz（信道 14 上沿）：λ ≈ 12.08 cm
- 常用口径：2.4G 波长约 12 cm 上下，工程顺口说「12.5 cm」

最基本的谐振天线长度是半波（λ/2 振子）或四分之一波长（λ/4 单极子）。**λ/4 ≈ 3.1 cm**——记住这个数，你就看得懂 PCB 上那块铜箔了。

### 单极子、地板与倒 F：板上那块铜箔的形状解读

λ/4 单极子需要一块「地」来当镜子（镜像效应，教材通识）：振子立在接地板上，接地板提供镜像的「另一半」。手机和 ESP32 模组上常见的**倒 F 天线（IFA，Inverted-F Antenna）**就是把单极子折弯省空间的版本——把振子放倒、贴着板边走，再加一条接地支路做匹配，馈电点和接地点挨在一起，俯视图像字母 F（倒过来的 F）：

```text
      ┌────────────────────────────┐
      │       辐射臂（≈ λ/4）       │  ← 长边的横笔，2.4G 下 3 cm 级
      └───┬──────────────┬─────────┘
          │              │
       接地支路        馈电支路
      （短路到地）     （接 50 Ω 馈线）
```

三段结构各有分工：辐射臂决定谐振频率（长度≈λ/4），接地支路与辐射臂的间距参与阻抗匹配，馈电支路接 50 Ω 走线。有两点值得写进笔记：

- **板上的铜箔看着比 3.1 cm 短**，因为电磁波在 FR4 介质表面传播的等效波长比自由空间短（有效介电常数大于 1，天线教材通识）；具体谐振长度必须仿真加实测确定——乐鑫硬件设计指南原话是「PCB 天线务必同时通过仿真与实际测试验证」（ESP Hardware Design Guidelines，PCB Layout Design 章）。
- **铜箔形状不能改、周围不能铺铜**。同一份指南要求模组的 PCB 天线超出底板边沿悬挂（推荐布局）、外壳内净空「各个方向至少 15 mm」，并建议在天线就近放一组 CLC 匹配元件留出调谐余地。

尺寸证据可以从模组 datasheet 上直接量出来：ESP32-S3-WROOM-1（带 PCB 天线）长 **25.5 mm**，去掉天线的 WROOM-1U（带 IPEX 座）只有 **19.2 mm**（Datasheet v1.8 第 7 节尺寸图）——**那 6.3 mm 的差值就是天线区**：一块 3 cm 级的辐射结构被折成紧凑条带，占了模组四分之一的长边。BOX-3 用的正是 WROOM-1（非 U 变体，板载 PCB 天线，见[[ch1-quick-start|BOX-3（一）]]的五件套清单）。

### 「天线不是越长越好，是对波长匹配才好」

天线的工作本质是**谐振**：长度与波长匹配时，馈入的能量高效辐射出去；长度不对（剪短、加长、贴了金属改变了等效电长度），谐振点偏移，能量的一部分被反射回发射机（6.4 的 VSWR 就是量化它的表）。所以「剪一截应该没关系」和「越长越好」都是同一个错误的两面：**长度只对波长负责**。棒状全向天线看着长短不一，其实都在做 λ/4 或 5/8 λ 的整数倍文章，不是随意长度。

顺带把 5 GHz 也代入同一把尺子（本系列实验不做 5G，但选型会碰到）：5150~5850 MHz 对应波长约 5.8~5.1 cm，λ/4 只有 **1.3~1.5 cm**——这就是为什么 5G 天线可以做得很小、也是为什么它的 layout 公差更苛刻（同样 1 mm 的加工偏差，对 3 cm 结构和 1.4 cm 结构的谐振影响差一倍以上）。同一根天线想在 2.4G 和 5G 都谐振良好，需要专门的**双频天线**设计，通常由两段不同长度的辐射体组合，成本高于单频。

## 6.3 极化与方向图：天线在空间里的「形状」

### 极化：电场的振动方向

电磁波传播时，电场在一个确定的平面内振动，这个方向就是**极化**。WiFi 棒状天线和 PCB 倒 F 都是**线极化**：振子竖直放就是垂直极化，横放就是水平极化。极化的工程意义一句话：**收发两端的极化方向要对齐**。极化失配因子为 cos²θ（θ 为两极化夹角，天线教材通识）：θ=0° 无损失，θ=45° 损 3 dB，θ=90° 理论上完全收不到（损失无穷大）。

实际世界没有无穷大：真实天线的交叉极化抑制有限，室内墙面和多径反射也会「去极化」救回一部分，自由空间/视距场景下正交极化的典型损失在 **20 dB 量级**（数值为工程通识口径，具体天线具体分析，**待核对**）。20 dB 意味着信号只剩百分之一——比隔着两堵墙还惨。工程上的直接建议：**两台设备的天线姿态保持平行**（路由器天线竖直，就别把 ESP32 板躺着贴天花板）。

> [!tip] 随手观察：转手机看极化（待真机验证）
> 手机连上 WiFi 后打开 WiFi 分析仪 App 看 RSSI，把手机从竖屏慢慢转到横屏（手机内置天线极化随之改变），观察 RSSI 变化量。室内多径环境下变化通常不明显，到空旷环境（楼下空地，远离反射面）再试一次，差异会拉大。变化幅度取决于路由器与你之间信道的多径丰富程度。

### 方向图怎么看

**方向图（radiation pattern）**是把 6.1 的「波瓣」画出来：以天线为中心，标注每个方向上辐射强度的图，通常给两个切面——**方位面**（水平切一刀）和**俯仰面**（竖直切一刀）。理想单极天线的方向图是个「甜甜圈」：振子是甜甜圈的中轴线，方位面近似一个圆（全向的由来），俯仰面沿轴线有凹陷：

```text
     俯视（方位面）＝ 近似圆          侧视（俯仰面）＝ 横躺的 8 字
          ______                          ______
        /        \                       /        \
       |     ●    |                     |  ●       |→ 能量向两侧辐射
        \        /                       \ ______ /   （沿振子轴上下是凹陷）
          ‾‾‾‾‾‾                        （● = 天线/振子方向）
```

看图抓三个要点：**主瓣**指向哪、**旁瓣/背瓣**多大（定向天线规格里的「前后比」）、**凹陷（零点）**在哪。读图时留意纵轴刻度：方向图几乎都以 dB 为单位（对数刻度），一圈 10 dB 意味着相邻两圈的功率差 10 倍——肉眼看着温和的凹陷，实际是功率上的深坑。文档术语里还会见到 E 面/H 面（E 面含电场矢量与传播方向，H 面与之正交）；对竖直放置的振子，E 面就是俯仰面、H 面就是方位面——两个名字体系说的是同一组切面。

PCB 倒 F 的方向图比理想甜甜圈「歪」：板子的地平面、外壳、邻近元件都会把圆啃出缺口，这正是 ESP-FAQ 建议的做法——「调整模组方向，让天线辐射较强的方向对准接收设备」（ESP-FAQ「RF 相关」页）。想看官方实测方向图：ESP-FAQ 对天线方向图（antenna pattern）的官方口径是「请联系销售获取」，模组 datasheet 未随文附图；第三方实测图仅供参考，最可靠的是自己测——6.6 就干这件事。

## 6.4 VSWR 与回波损耗：反射的能量不算「发射」

### 接口不匹配，协议握手失败重传

馈线与天线约定在 50 Ω 上交接功率（为什么是 50 Ω，第九章专门讲）。若天线在谐振点的阻抗偏离 50 Ω，一部分功率**在接口处被反射回来**——软件类比：两个模块用不一致的接口协议对接，调用失败、数据被打回重传。反射系数的定义为 Γ = (Z_L − Z_0) / (Z_L + Z_0)，工程上惯用两个换算指标：

- **VSWR（驻波比）**：入射波与反射波在馈线上叠加形成驻波，电压最大值/最小值之比，VSWR = (1+|Γ|)/(1−|Γ|)。完美匹配 VSWR=1:1，越大越糟。
- **回波损耗 RL = −20·log₁₀|Γ|**：反射信号比入射信号低多少 dB。
- **失配损耗 ML = −10·log₁₀(1−|Γ|²)**：反射掉的功率折算成发射净损失。

| VSWR  | 反射功率占比 | 回波损耗 | 失配损耗 |
| ----- | ------------ | -------- | -------- |
| 1.5:1 | 4%           | 14 dB    | 0.18 dB  |
| 2:1   | 11%          | 9.5 dB   | 0.51 dB  |
| 3:1   | 25%          | 6 dB     | 1.25 dB  |
| 6:1   | 51%          | 2.9 dB   | 3.1 dB   |

（上表由定义式直接计算，非查表抄录。）常用的工程门槛 **VSWR 2:1 ≈ 损失 0.51 dB**：只有约 11% 功率被反射，尚可接受；天线 datasheet 给的谐振指标通常是「频带内 VSWR < 2」。

### 反射不只是「少发了一点」

被反射的功率回到发射机，还会**干扰功率放大器的工作点**。乐鑫硬件设计指南把它写成了标准故障模式：发射功率实测值明显低于目标值时，可能源于「RF 引脚与天线之间传输线阻抗失配引起的信号反射」，而且「阻抗失配会影响内部 PA 的工作状态，使 PA 提前进入饱和区」——解法是在馈线与天线之间加 π 型匹配网络，元件值按实际天线与板卡调整（出处同上，PCB Layout Design 章）。

VSWR 还是**频率的函数**：天线只在谐振频率附近匹配良好，离开谐振点 VSWR 迅速变差。所以天线 datasheet 的规格写法是「在 2400~2483.5 MHz 频带内 VSWR < 2」——这句话同时定义了**谐振带宽**。看懂它你就明白两个工程现象：天线「能用」和「好用」的差别就在带宽内的 VSWR 曲线平不平；以及把 2.4G 天线硬接到别的频段（比如 868/915 MHz 的 LoRa）上用，增益和匹配都无从谈起——谐振点根本不在那。

这也回答了一个看板子时的常见疑问：**天线附近那一小撮电阻电容电感（π/CLC 匹配网络）是干嘛的**——它们是接口适配层，负责把天线实际阻抗「翻译」回 50 Ω，让握手成功。原理与计算是第九章的主题，本章先认识它们存在的理由。

## 6.5 工程实践：选型、线损账与天线分集

### 三种常见方案的对照

《ESP32-C3 Wireless Adventure》5.2.5 节给了官方的定性选型表（PCB 板载：低成本、中等增益、集成在模组上；棒状外置：经 I-PEX 连接、高成本、高增益、受干扰小、全向性好；陶瓷：中成本、低增益、体积小，适合小尺寸设备）。合并成工程视角的对照：

| 方案          | 增益量级（待核对） | 体积占用       | 成本   | 位置灵活性     |
| ------------- | ------------------ | -------------- | ------ | -------------- |
| PCB 板载天线  | 0~2 dBi 级         | 模组板边条带   | 低     | 焊死，不可动   |
| IPEX 外置天线 | 2~5 dBi 级（棒状） | 座子加天线本体 | 中到高 | 可移可换       |
| 陶瓷天线      | 更低               | 贴片级，最小   | 中     | 可摆位，需净空 |

（增益列待核对：乐鑫官方文档只给「中等/高/低」定性描述；早期 ESP32-WROOM-32 datasheet 是否标注过 PCB 天线峰值增益，现行 v3.7 已无该数值，未核对。）名字澄清一个新手坑：IPEX 是 I-PEX 公司 MHF 系列连接器的俗称，与 Hirose U.FL、Amphenol AMC 互为兼容品——ESP32-S3-WROOM-1U datasheet 第 10.2 节原话就是「连接器需兼容 U.FL（Hirose）、MHF（I-PEX）、AMC（Amphenol）」。

### IPEX 延长线的线损账

外置天线不是免费午餐：信号要穿过「座子—细缆—座子」才到天线，每一环都吃功率，而细缆在 2.4 GHz 的损耗不可忽略：

| 环节              | 典型值（2.4 GHz）    | 口径                         |
| ----------------- | -------------------- | ---------------------------- |
| IPEX 座（每处）   | 0.1~0.3 dB           | 连接器厂商 datasheet，待核对 |
| 1.13 mm 细缆      | 约 1 dB/m            | 线缆厂商 datasheet，待核对   |
| 一根 10 cm 延长线 | 合计约 0.5 dB        | 由上两行推算                 |
| 收益门槛          | 外置增益须大于总损耗 | 链路预算常识                 |

结论：**换外置天线的净收益 = 天线增益 −（线损 + 失配损耗）**。一根 5 dBi 棒状天线接 10 cm 延长线，净赚约 4 dB 量级；但若为了「把天线引到金属外壳外」拉 1 m 细缆（线损约 1 dB，待核对），5 dBi 就只剩 3 dB 出头——增益必须大于代价才有意义。另外别忘了 IPEX 是**机械弱点**：座子与线的咬合力有限，反复拔插或长期振动后接触劣化，是「设备摔过一次之后 WiFi 变差」的头号嫌疑之一。另有认证约束：WROOM-1U datasheet 要求外置天线「最大增益不超过 2.33 dBi（认证所用天线的增益）」，并明说「使用不同类型或增益的天线，可能需要额外测试（如 EMC）」——这是模组认证口径，量产产品详见第十七章。

### 天线分集：esp32 的天线切换 API（源码核实）

ESP32 系列是**单射频口**：Wi-Fi 与蓝牙分时共享同一天线（ESP32-S3-WROOM-1 Datasheet 第 1 节：内置 Wi-Fi/蓝牙共存机制、共用天线）。那「双天线」板子（如 ESP32-WROOM-DA，两个 IPEX 座）是怎么回事？——**天线分集**：两根天线共用一个射频口，中间隔一个射频开关，按信号质量切换。软件类比：**双网卡主备 bond**——不是带宽翻倍，是给链路上一份保险。

切换的软件入口，官方 example 就在本地仓库 `examples/phy/antenna/`。注意一个版本坑：**v4/v5 时代的 API 叫 `esp_wifi_set_ant_gpio` / `esp_wifi_set_ant`，v6 起已从 esp_wifi 组件移除**，官方迁移指南明示改用 esp_phy 组件的等效函数（`docs/en/migration-guides/release-6.x/6.0/wifi.rst`）：

```c
#include "esp_phy.h"   // v6.0.2：多天线 API 居于 esp_phy 组件

// 第一步：声明天线选择线接在哪些 GPIO（外置射频开关的控制脚）
esp_phy_ant_gpio_config_t ant_gpio_config = {
    .gpio_cfg[0] = { .gpio_select = 1, .gpio_num = 21 }, // ESP32-WROOM-DA 默认天线脚
    .gpio_cfg[1] = { .gpio_select = 1, .gpio_num = 22 },
};
esp_phy_set_ant_gpio(&ant_gpio_config);

// 第二步：配置收/发各用哪路天线（芯片内部只有天线 0/天线 1 两个模块）
esp_phy_ant_config_t ant_config = {
    .rx_ant_mode = ESP_PHY_ANT_MODE_ANT0,
    .tx_ant_mode = ESP_PHY_ANT_MODE_ANT0,
};
esp_phy_set_ant(&ant_config);
```

从 v6.0.2 本地源码与文档核实到的机制清单（`components/esp_phy/include/esp_phy.h`、`docs/en/api-guides/phy.rst`、`examples/phy/antenna/main/antenna_switch_example_main.c`）：

- 链路结构：芯片内 PHY 天线模块输出 `antenna_select[3:0]` 四根选择线 → 经 GPIO 矩阵引到管脚 → 驱动外部射频开关选天线。
- 上限：理论上支持外接 **16 根天线，但同时启用的最多 2 根**（phy.rst 原话）。
- 自动模式 `ESP_PHY_ANT_MODE_AUTO` **官方不推荐**：信号不稳时会频繁切换，整体射频性能反而达不到预期；example 里的做法是关 modem sleep（`esp_wifi_set_ps(WIFI_PS_NONE)`）保住 PHY 常开，再自己做切换策略。
- WROOM-DA 板用的开关芯片是 RTC6603SP，只支持 2 天线（`0b01`/`0b10` 有效）；example 里另有一个基于 RSSI 阈值软切换的组件（`esp_wifi_set_ant_soft_switch`）可参考。

分集为什么有效？回到 6.3 的方向图：室内多径叠加后，空间里布满随位置变化的「零点」（同一地点信号差，挪半米可能就好）。两根相距一定距离的天线**几乎不会同时落进零点**——切换选优就能持续捡到较好的那份信号。这跟负载均衡里「两条出口链路很少同时抽风，所以做主备」是同一个统计直觉；WROOM-DA 把两个 IPEX 座分开布置在模组两端，就是为了拉开这份空间差异。

对入门者的建议：先把单天线用明白（位置、姿态、净空），分集是锦上添花——信号差到需要分集救的场合，先查天线环境再查切换算法。

## 6.6 动手实验：手绘你的第一张方向图（待真机验证）

> [!warning] 待真机验证
> 本节为完整实验方案，BOX-3 到货后实测回填数据。全程只需手机 + ESP32 + 卷尺，零仪器。

**目标**：实测你手里那块板（BOX-3 的 WROOM-1 PCB 天线）在水平面（方位面）的方向图，亲手画出「全向天线其实不圆」。

**准备**：

1. ESP32 刷 softAP 固件：`examples/wifi/getting_started/softAP` 例程（menuconfig 里设好 SSID/密码），`idf.py flash monitor` 起一个热点。进阶玩法：AP 侧用 `esp_wifi_ap_get_sta_list()` 还能直接读到手台的 RSSI（`wifi_sta_info_t.rssi` 字段，esp_wifi_types_generic.h 注释为「当前连接 STA 的平均 RSSI」）。
2. 手机装 WiFi 分析仪 App，连上这个热点（或仅看该 SSID 的 RSSI，不连也行）。
3. 空旷场地（楼下空地/大房间中央），ESP32 架在非金属支架上，高度约 1 m；地面用卷尺+粉笔画一个以板子为圆心、半径 2 m 的圆，每 45° 做一个标记（8 个测点）。板子姿态固定：模组板边（天线区）垂直朝上。

**步骤**（每个测点重复同一套动作）：

1. 站到标记点，手机持握高度与板子一致、屏幕朝向板子（每次相同，人体是 2.4G 的吸波体，站位本身就是变量）。
2. 等 10 秒让 RSSI 稳定，读数并记录 10 次取平均，填进下表。
3. 八个点测完，换一个变量再测一轮：把板子「立起来」（板面竖直）重复，观察方向图形状和整体电平的变化——这一轮同时演示了方向图与极化的双重影响。

| 方位角             | RSSI（10 次平均，dBm） | 现场备注           |
| ------------------ | ---------------------- | ------------------ |
| 0°（正对板边馈点） | 待填                   | 定为 0 dB 基准方向 |
| 45°                | 待填                   | 第一象限           |
| 90°                | 待填                   | 板侧长边           |
| 135°               | 待填                   | 斜对角，远离馈点   |
| 180°               | 待填                   | 背对馈点方向       |
| 225°               | 待填                   | 第三象限           |
| 270°               | 待填                   | 另一侧长边         |
| 315°               | 待填                   | 第四象限           |

**画图**：拿一张纸画同心圆代表 −30 到 −85 dBm（每圈 5 dB，外圈信号强），8 个测点按角度标点、平滑连线，就是你的第一张实测方向图（极坐标）。跟 6.3 的「理想圆」对比，缺口就是板子地平面与外壳啃掉的部分。

**记录纪律**：一轮实验只改一个变量（距离、板子姿态、遮挡任选其一），其余条件全部固定并在表里注明；每轮记录时间与周围环境（有人走动/开门都要写）——多径环境随时间漂移，两轮数据隔了一小时就没法对比。这份纪律和压测脚本「一次只改一个参数」是同一回事。

**预期与陷阱**（待真机验证）：方位面应大致是个圆但起伏若干 dB；板子立起后形状与整体电平都会变。三个常见坑：距离太近（<1 m 时读数饱和不随角度变化）、测点之间手机握姿不一致（引入假凹陷）、场地有金属栏杆/汽车（反射造成局部异常高或低）。变体实验：把板子塞进金属饼干盒再测一圈，亲眼看「金属壳内放 PCB 天线」的代价。

## 6.7 常见误区与小结

| 误区                      | 真相                           | 一句话纠正              |
| ------------------------- | ------------------------------ | ----------------------- |
| 增益大的天线凭空放大信号  | 无源器件不放大，只重新分配能量 | 增益是压扁波瓣换来的    |
| 天线剪短一点没关系        | 长度须对波长匹配（λ/4≈3.1 cm） | 动剪刀前先算波长        |
| 金属壳里放 PCB 天线没事   | 官方要求净空至少 15 mm         | 金属改变谐振与方向图    |
| 换 IPEX 外置一定更强      | 延长线自带 0.5 dB 级损耗       | 净增益要扣线损与失配    |
| 板子姿态随便摆            | 极化正交可损失 20 dB 级        | 收发极化方向保持一致    |
| 双天线等于功率翻倍或 MIMO | 单射频口，DA 板是分集切换      | 是主备切换，不是叠加    |
| 信号满格就万事大吉        | 满格只说明信标强，不代表吞吐好 | 看 SNR 与速率，见第五章 |

（表中「待核对」量级同前：0.5 dB 线损、20 dB 极化损失为工程口径。）

**小结**：

- **天线 = 换能器 = 物理世界的网络接口**：电流与电磁波的编解码器，无源双向，收发同参。它的三个经典问题——增益、匹配、方向图——分别对应软件世界的「定向麦克风 vs 全向麦克风」「接口协议握手」「链路质量的分布图」。
- **增益是方向性，不是放大**：dBi 的每一分都来自波瓣压扁，能量守恒；2.33 dBi 是 WROOM-1U datasheet 给出的认证天线增益锚点，换更高增益外置天线可能触发重新认证（EMC）。
- **尺寸由波长决定**：2.4G 波长 12.5 cm、λ/4≈3.1 cm，模组板边的倒 F 铜箔就是被折弯收纳的 λ/4 振子；WROOM-1 比 1U 长出的那 6.3 mm 就是它的地盘。
- **匹配决定能量交接**：VSWR 2:1 损失约 0.5 dB 且反射波会扰乱 PA 工作点；天线旁那撮元件是接口适配层，第九章拆解。
- **分集是主备不是叠加**：ESP32 单射频口，`esp_wifi_set_ant` 一族在 v6 已迁移为 `esp_phy_set_ant_gpio`/`esp_phy_set_ant`（esp_phy 组件），AUTO 模式官方不推荐。
- 下一章钻进芯片本体：MAC、基带、射频收发机在 ESP32 这颗 SoC 里如何分工，模组（WROOM）与裸片的区别——见[[ch07-wifi-soc-anatomy|第七章：WiFi SoC 解剖]]。
