## 8.1 三句话复习电路：从欧姆定律到「频率改变一切」

先给结论：**看不懂 RF 电路，九成不是因为缺欧姆定律，而是因为没换脑**——频率这个维度进来之后，每个元件的性格都变了。本节先用三句话把中学物理接回来，再做那次换脑。

### 1. 电压、电流、电阻：三句话与一个式子

| 量     | 单位    | 一句话定义                     | 软件工程师的锚点                                |
| ------ | ------- | ------------------------------ | ----------------------------------------------- |
| 电压 U | 伏（V） | 两点间的电位差，推动电荷的压力 | GPIO 高电平 3.3V、低电平 0V，就是两个档位的电压 |
| 电流 I | 安（A） | 单位时间流过的电荷量           | 吞吐量：单位时间过了多少字节                    |
| 电阻 R | 欧（Ω） | 对电流的阻碍程度               | 限流器：同样压差下，决定流量多大                |

```text
U = I × R      欧姆定律：电压 = 电流 × 电阻，全章唯一的公式
P = U × I      电功率：第三章 dBm/dB 家族的物理源头
```

欧姆定律的软件类比：一个纯函数合同——输入（电压）确定、参数（电阻）确定，输出（电流）就确定，永不抛异常。整个中学电路课的本质，就是拿着这一个式子反复代入。

### 2. 换脑：频率进来之后，元件全都变了性格

但 RF 世界里电流不是「一直往前流」的直流，而是每秒改变方向几十亿次的交流——2.4 GHz 的字面意思是每秒 24 亿次。在这个速度下，中学那张「电阻消耗、电容断路、电感短路」的静态照片全部作废：

| 元件   | 直流世界             | 高频交流世界（RF 语境）                 | 一句话点评                  |
| ------ | -------------------- | --------------------------------------- | --------------------------- |
| 电容   | 充满电后等于断路     | 频率越高越像导线：隔直通交              | 性格随频率翻转，RF 第一主角 |
| 电感   | 就是一段导线         | 频率越高越像堵墙：通直阻交              | 电容的镜像                  |
| 电阻   | 消耗能量，线性老实人 | 依然消耗，RF 用无感工艺压制寄生电感     | 全频段性格最稳定            |
| 二极管 | 单向阀门             | 单向导电仍成立，衍生 ESD 保护等 RF 专职 | 方向就是语义                |

再往深一层：频率上去之后，不光元件变了，**连线也变成了元件**——一段几毫米长的导线表现出可观的电感，两根相邻导线之间表现出电容。硬件工程师称之为「寄生参数」：图纸上不画，物理上存在。软件类比：同一个缓存组件，QPS 10 与 QPS 10 万下行为完全不同——低频时它是零延迟的字典，高频时锁竞争、缓存行争用全冒出来；元件与走线也一样，频率上去之后，寄生参数从「可忽略」变成「主角」。

> [!tip] 全系列复用率最高的两句口诀
> 电容「隔直流、通交流」，电感「通直流、阻交流」。频率越高，电容越像导线、电感越像断路——第八到第十四章关于去耦、滤波、匹配、干扰的全部讨论，都是从这两句推出来的。

换脑之后，看电路要换三个问题：

1. 直流问「多大电阻」，交流问「多大阻抗、在什么频率」——同一颗元件，频率不同答案不同。
2. 直流问「通不通」，交流问「通过去多少、反射回来多少」——第九章的反射从这里发芽。
3. 直流看「连线」，交流看「连线也是元件」——第十三章 PCB 传输线的伏笔。

最后补一个名词：把「电阻」推广到交流世界，就得到**阻抗**（impedance，Z）——它仍然是电压与电流的比值，但随频率变化。50 Ω 的系统约定、反射、VSWR 都是阻抗的故事，第九章主场；本章只需要记住上面的性格表。

## 8.2 四个元件的档案表

档案表先上，一表看四件；随后每个元件一段展开，再认「同一颗元件的三种接法」，最后是原理图符号速查与读图口诀。

### 1. 档案表：五个维度看四个元件

| 元件     | DC 视角            | RF 视角                      | 软件类比           | WiFi 板上哪能找到               |
| -------- | ------------------ | ---------------------------- | ------------------ | ------------------------------- |
| 电阻 R   | 限流、分压、上下拉 | 限流分压依旧，另做端接与衰减 | 下拉电阻你天天用   | 启动模式脚、LED 限流、复位上拉  |
| 电容 C   | 充满后断路         | 去耦、隔直、组成滤波与匹配   | 每级芯片旁的缓冲池 | 电源脚旁 0.1 µF、匹配网络 pF 级 |
| 电感 L   | 等于一段导线       | 抗电流突变，高频呈大阻抗     | 机械飞轮           | 电源 LC 滤波、磁珠、匹配 nH 级  |
| 二极管 D | 单向导电           | ESD 保护、防反接             | 单向阀             | 电源入口与天线的 ESD 管         |

**电阻**是四件里唯一「全频段性格稳定」的：直流下限流分压，2.4 GHz 下还是限流分压（RF 电路会用无感工艺型号，避免绕线的寄生电感）。你在软件里天天用它：esp-idf v6 的 `components/esp_driver_gpio/src/gpio.c` 里就有 `GPIO_PULLDOWN_ONLY` 这个枚举——配置「内部下拉」不是软件模拟，而是接通芯片内部一颗真实的电阻，把引脚电平「轻轻按」在 0 V，防止悬空读到随机值。启动模式的 strap 引脚上下拉，就是它在决定芯片上电后的行为模式。

**电容**在直流里「充完电就下班」，在 RF 里却是劳模：高频信号一来它近乎导线。于是它有三份工作：接在电源与地之间，吸收电源毛刺（去耦，8.3 节专题）；串在信号路径上，挡住直流、放过变化量（隔直耦合）；与电感搭档组成滤波器或匹配网络（8.4 节与第九章）。软件类比贯穿全系列：电容是**本地小缓存**，去耦电容是**每一级芯片旁边的缓冲池**。

**电感**的物理属性是磁场惯性：电流不能突变，就像机械飞轮的转速不能突变——你可以瞬间改变施加的力，但转速只能渐变。这份惯性在电源里是宝：挡住高频噪声、放过干净的直流。它出现在 WiFi 板的三个地方：电源轨的 LC 滤波（官方明确建议，见 8.3）、磁珠隔离（把某段电路的高频噪声「关在笼子里」）、RF 匹配网络里 nH 级的小电感。

**二极管** = 单向阀：正向偏置导通、反向截止。整流是它最著名的应用，但 WiFi 板上更常见的是两个亲戚：电源入口与天线口的 ESD 保护二极管（静电浪涌来了就地泄放到地——官方设计指南对这两处都有明确建议）、电源防反接。软件类比：单向队列——只允许一个方向流通，反向直接丢弃。

表里反复出现的「匹配」先预告一下：RF 系统约定所有端口 50 Ω，天线附近那一小撮 C/L 组成的 π 形（CLC）网络，负责在芯片输出与天线之间做「翻译」——类比两个不同协议服务之间的适配层。为什么是 50 Ω、翻译不好会怎样（反射），第九章展开；本章只需认脸，不要手痒。

选型参数顺带认三个（读 BOM 不再懵）：容量单位 pF、nF、µF 是千进位（1 µF = 1000 nF = 1000000 pF）；耐压要高于所在网络的电压（3V3 网络用 6.3 V 及以上耐压是常见做法——典型工程值）；封装尺寸 0201/0402/0603 是英寸系代码，数字越小体积越小——RF 匹配元件官方建议用 0201 小封装以降低寄生电感（《ESP32-S3 硬件设计指南》）。

### 2. 原理图符号速查：认脸与口诀

原理图符号是硬件世界的「图标字体」：全球基本统一，认一次终身受用。下表用文字描述它们长什么样，拿任何一张真实原理图对照十分钟即可记住：

| 元件   | 符号长什么样                   | 记忆口诀                     |
| ------ | ------------------------------ | ---------------------------- |
| 电阻   | 锯齿线（美标）；国标为空心矩形 | 电流搓过锯齿，搓掉一点能量   |
| 电容   | 两条正对的平行短线，中间断开   | 两块板不接触，所以隔直流     |
| 电感   | 连续几个半圆弧，像弹簧         | 弹簧储能，电流只能渐变       |
| 二极管 | 实心三角顶着一条横线           | 三角指向即导通方向，横线是闸 |
| 地 GND | 三条逐级变短的横线             | 全图同名地线即同电位         |
| 电源   | 圆圈加箭头，或网络名 3V3、5V   | 网络名就是电源的标签         |
| 不相连 | 交叉处无实心点，或画跳线拱     | 有点即相连，无点即跨过       |

两点补充：一是有极性电容（电解/钽电容）符号的一边会标「+」或画成空心——接反会出事故，这是符号自带语义的典型；二是原理图上不画长线，连接靠**网络标号**（net label）：同名的网络在电气上是同一根线，就像源码靠符号名引用、不画调用箭头。

举例：模组的 ANT 引脚上标着网络名「ANT」，图纸另一头的天线符号也标着「ANT」——中间可能隔着三页图纸，但电气上它们就是同一根线。在 PDF 里搜索网络名是读大图最快的导航方式，类比 IDE 里的「查找符号」。

元件在图上的编号叫**位号**（designator），前缀即元件类型，也是 BOM 的主键：

| 前缀 | 元件           | 板上常见例子                       |
| ---- | -------------- | ---------------------------------- |
| R    | 电阻           | 启动模式下拉、LED 限流             |
| C    | 电容           | 去耦电容、匹配电容                 |
| L    | 电感、磁珠     | 电源 LC、匹配电感（磁珠也常记 FB） |
| D    | 二极管         | ESD 保护管                         |
| Q    | 三极管、MOS 管 | 电源使能开关                       |
| U    | 芯片、模组     | ESP32-S3-WROOM-1 模组              |
| J    | 连接器         | IPEX 天线座、USB 座                |
| Y    | 晶振           | 40 MHz 主晶振（第十一章主角）      |

**读图四步口诀**：一找电源地，二找主芯片，三跟网络标号，四看位号前缀。展开：

1. **一找电源地**：先找 GND 符号与 3V3/5V 网络标号，它们是全图的坐标系。
2. **二找主芯片**：U 打头的方框（SoC/模组），引脚名是读懂图的索引。
3. **三跟网络标号**：顺着信号的网络名走，同名即相连。
4. **四看位号前缀**：C 贴着谁的脚就是谁的缓存；L 串在路径上；D 的三角指向就是允许的方向。

### 3. 同一颗电容，三种接法

认脸的最后一课：元件的角色不仅看它是什么，还要看它**怎么接**。以电容为例——

| 接法           | 角色         | 一句话原理                   |
| -------------- | ------------ | ---------------------------- |
| 并联在电源与地 | 去耦（低通） | 高频毛刺被短路入地，直流照常 |
| 串联在信号路径 | 隔直（高通） | 直流被挡住，变化量过得去     |
| 与电感成对组合 | 滤波或匹配   | 两种惯性互补，筛出想要的频段 |

所以读图时问两个问题：这是什么元件（位号前缀）、它怎么接（并联还是串联、在哪个网络）。两个答案一组合，角色就定了——这比背「什么电路用什么元件」可靠得多，也是 8.5 节读真图的直接工具。

## 8.3 去耦电容专题：每个电源脚旁边的缓冲池

先解释名字：**去耦**（decoupling）就是把两件事「解耦」。芯片的取电是突发的，电源网络（稳压器加走线）的响应是迟缓的；去耦电容插在中间，把「突发的取电」与「远端的供给」解耦——这就是缓冲池一词的原文含义。

### 1. 问题：发射瞬间，芯片是抽电流的怪兽

WiFi 发射不是匀速用电，而是脉冲式抽电。ESP32-S3 Datasheet v2.2 的功耗表给了量级：

| 场景                          | 电流（datasheet v2.2）  |
| ----------------------------- | ----------------------- |
| TX 802.11b 1 Mbps 21 dBm 峰值 | 340 mA（平均约 281 mA） |
| TX 802.11n MCS7 平均          | 283~291 mA              |
| RX 活跃                       | 88~91 mA                |
| modem-sleep                   | 约 20~31 mA             |

数字侧几十 mA，发射瞬间跳到几百 mA，而且这个阶跃发生在纳秒到微秒级（WiFi 活跃/睡眠切换的软件侧视角，见[[ch16-wifi-events|BOX-3（十六）]]的省电模式）。电源从稳压器到芯片要走几毫米到几厘米铜线，而任何一段导线都有电感（PCB 走线的量级约每毫米 1 nH——典型工程值）。电感上的压降正比于电流变化率：U = L × ΔI/Δt。粗估量级：走线与焊盘合计约 10 nH，电流在 10 ns 内从几十 mA 抬到 300 mA，电感上就有 0.2~0.3 V 的瞬时压降——在 3.0 V 的供电下限预算里，这是一笔大钱。后果轻则 RF 功率失真，重则电压跌破下限、芯片复位。

软件类比：突发流量直接打远端数据库，连接池瞬间见底；解法不是把数据库搬过来，而是在本地加缓存——毛刺电流从旁边的电容取，稳压器只需供给「平均流量」。顺带一提，软件层能「看见」电源毛刺的少数地方之一，是 esp-idf 的 brownout 检测复位（电压跌到阈值以下时芯片主动复位）：如果你见过 brownout 报错，那就是本节的现象层。

这不是理论风险：8.3.3 的官方清单里，10 µF 与 1 µF「协同工作」防的就是这个场景；电源的性格（LDO 与 DCDC 的响应差异、为什么电源不好 WiFi 就丢包）在第十二章展开成完整一章。

### 2. 解法：把缓冲池搬到芯片旁边，而且要两级

为什么教科书答案总是「0.1 µF 加 10 µF 两颗」而不是一颗「更好的」？因为真实电容不是理想电容：它是电容 C、等效串联电阻 ESR、等效串联电感 ESL 的串联组合。频率低时容量说话；到**自谐振频率**（SRF）时阻抗最低；超过 SRF 后 ESL 主导——电容表现得像电感，对更高的频率反而呈现大阻抗，等于下班。概念级一句话：**大电容高频会失效**——大电容像大仓库，装得多但物流慢（ESL 大、SRF 低，常在 MHz 级）；小电容像前置仓，装得少但出手快（SRF 可到百 MHz）。电容厂商 datasheet 里那根 V 形阻抗-频率曲线，谷底就是 SRF。

所以 0.1 µF 加 10 µF 并联的真相，是两级缓存覆盖全频段：小电容顶住最高频的毛刺，大电容补足稍慢但更大的电流缺口——不是仪式，是分工。

「就近」是多近？毫米级。去耦电容到芯片电源脚的距离每多一毫米，走线电感就多一分（8.3.1 的量级），高频缓冲效果就打折扣——所以原理图上的「电容贴脚放」，落地到 PCB 上就是「焊盘贴脚焊」。layout 层的细节第十三章展开。

### 3. ESP32-S3 的官方去耦清单

乐鑫《ESP32-S3 硬件设计指南》的「原理图检查」（Schematic Checklist）章节把去耦写成了清单，逐条摘录（数值出处即该指南）：

| 电源引脚               | 官方建议                                           | 出处                         |
| ---------------------- | -------------------------------------------------- | ---------------------------- |
| VDD3P3_CPU、VDD3P3_RTC | 数字电源脚旁各放 0.1 µF                            | ESP32-S3 硬件设计指南        |
| VDD_SPI                | 就近加 0.1 µF 与 1 µF，勿用过大电容                | 同上                         |
| VDD3P3 主电源轨        | 10 µF 防发射尖峰拉垮电源轨，另加 LC 滤波压高频谐波 | 同上                         |
| 主电源入口             | ESD 保护二极管加至少 10 µF                         | 同上                         |
| 模组电源（WROOM-1）    | 就近放 22 µF 与 0.1 µF                             | 模组 datasheet v1.8 参考设计 |

两条原文细节值得单独摘出：一是 VDD_SPI 上明确写着「不要加过大的电容」（Please do not add excessively large capacitors）——大电容不是免费的，上电瞬间它本身就是要被充电的大负载；二是电源轨的 10 µF 与 1 µF「协同工作」，官方点名就是为了「防止发射电流尖峰把电源轨拉垮」（prevent the power-rail collapse during TX current spikes）——设计指南的原话就是 8.3.1 的故事。LC 滤波中的电感要求额定电流 500 mA 以上，因为它串在主供电路径上。

如果你用的是模组（第七章结论：软件工程师永远用模组），芯片级清单的大部分已经焊在模组内部；你只需照模组参考设计在外部放 22 µF 与 0.1 µF（ESP32-S3-WROOM-1/1U Datasheet v1.8 第 3.1.1 节「外围参考设计」）。同一节还标注：模组内置的匹配网络元件不可修改或移除——RF 段的事 8.5 节再展开。

## 8.4 滤波器入门：频率域的筛子

滤波器（filter）在 RF 里没有任何玄学：它就是**频率域的筛子**。去耦电容其实是「最朴素的低通」——直流过、高频毛刺入地；把它正式化、配上电感搭档，就是三种经典筛子：

| 类型 | 让谁过、挡谁   | 软件类比                       | 在 WiFi 板上的角色           |
| ---- | -------------- | ------------------------------ | ---------------------------- |
| 低通 | 低频过，高频挡 | 吸收毛刺的缓冲池（去耦即低通） | 电源轨：直流过、高频噪声入地 |
| 高通 | 高频过，直流挡 | 只传 diff 不传全量（增量同步） | 隔直耦合电容                 |
| 带通 | 只放行一段频带 | 白名单防火墙只开一段端口       | 天线前端：只让 2.4 GHz 出去  |

造筛子的原料还是 8.1 的两句口诀：电容高频短路、电感高频开路。串一个电感「拦住」高频、再并一个电容到地把漏网高频「放地」，就是低通骨架；电容电感位置互换就是高通；低通与高通级联、只留中间一段，就是带通。本系列不推传递函数——你只需要在原理图上认出「串 L 并 C」与「串 C 并 L」两种积木。

筛子好不好，看两个指标：过渡带陡不陡（挡与放之间隔得多窄）与通带损耗多大（该过的被吃掉多少）——第十章讲射频前端 FEM 时对照真实的滤波器曲线看。另有第四种筛子「带阻」（notch）：与带通相反，只挡某一段、其余放行，常用于压制某个特定干扰频点。

### 为什么天线前要「只让 2.4 GHz 出去」

因为发射链路不是理想线性器件：PA 与混频的非线性会制造基波的谐波与杂散——2.4 GHz 的二次谐波在 4.8 GHz、三次在 7.2 GHz。而各国无线电法规（FCC、CE、SRRC）对**带外辐射**有硬性限值：你的设备只被允许在授权频段内说话。天线前的带通/低通把谐波挡在天线口之前——这是设备能否过认证的硬指标，第十七章展开。

一个官方佐证：《ESP32-S3 硬件设计指南》给匹配网络定的验收标准里，除了 2.4 GHz 处的匹配好坏，还明确要求 4.8 GHz 与 7.2 GHz 处 S21 低于 -35 dB（这两个谐波频率上衰减三千倍以上）——谐波抑制被写进了出厂检查单。S21 术语第九、十章讲，这里按「这两个频率上的衰减量」理解即可。软件类比：出口处的白名单防火墙——只放行 2.4 GHz ISM 频段（2400~2483.5 MHz，第二章）这一段「端口」，其余一律 drop，否则「监管」找上门。

### 2. 电源段怎么读：从 USB 到 3V3

1. 翻到电源页（或电源区域），从 USB 的 5V 网络出发，沿箭头走：保护器件（ESD 管、保险）、稳压器（DCDC 或 LDO）、输出 3V3 网络。
2. 在 3V3 网络上数电容：入口处 µF 级大电容、每个芯片 VDD 脚附近 0.1 µF 级小电容——对照 8.3 的官方清单看它是不是「全套」。
3. 找 GND 符号给整页「接地」：所有 GND 同名同电位。
4. 遇到不认识的符号回 8.2 的速查表；遇到位号去 BOM 查具体型号与封装。
5. PDF 原理图通常按页分区（电源页/主控页/接口页），目录或页脚的网络标号索引就是「符号表」——跟着它跳页。

> [!warning] 待核对
> BOX-3 主板原理图的具体元件值（稳压器型号、各处容值）与天线形式（模组 PCB 天线还是 IPEX 外接），本章未逐页核对 PDF，按 8.5.4 的练习自查后回填。

### 3. RF 段怎么读：从 ANT 到天线

1. 找模组的 ANT 引脚——引脚名直接标在模组符号上。
2. 沿 ANT 网络走：通常先经过两三个 C/L 组成的 π 形（CLC）网络——匹配加滤波，再到天线或 IPEX 连接器。
3. 数这段路径上的元件总数，一般不超过五个：RF 段的原则是越短越好，每多一个元件就多一分损耗（第九章讲损耗与反射）。

WROOM-1 模组 datasheet 同时说明：模组内置的匹配网络（C0、C1、C2、L1）已按 50 Ω 系统调好，使用模组时不可修改（v1.8 第 3.1.1 节附注）。你在板子上看到的 ANT 附近元件，多是「模组到天线」之间的适配，不是让你重新设计匹配的。

### 4. 本章练习：五件事，一张 PDF 就够

1. 在 MB 原理图上把 3V3 网络的电容数一遍，按容值分两堆（µF 级与 0.1 µF 级），对照 8.3 清单。
2. 找到 ANT 网络与它上面的全部 L/C，手画「模组到天线」的链路草图。
3. 在 BOM 里按前缀 R/C/L/D 过滤，统计四类元件数量比——你会直观看到电容占了半壁江山。
4. 找 40 MHz 主晶振和它两端的负载电容（设计指南只支持 40 MHz、精度 ±10 ppm 以内；负载电容公式与温漂是第十一章的开场）。
5. 把 3V3 与 ANT 两个网络上找到的位号抄下来与 BOM 对号——这是你第一份亲手整理的元件清单。

## 8.6 常见误区表

入门阶段最常听到的七句话，每句都有一半是错的：

| 流行说法                             | 错在哪                                                 | 正确姿势                                         |
| ------------------------------------ | ------------------------------------------------------ | ------------------------------------------------ |
| 电容越大越好，滤波越干净             | 大电容的寄生电感让它高频反而失效；上电浪涌电流也更大   | 大小并联分级承担：0.1 µF 管高频、10 µF 管低频    |
| 去耦电容是仪式，抄个 0.1 µF 意思一下 | 它有明确的物理任务：对付发射瞬间数百 mA 的电流阶跃     | 按官方清单放全套：脚边小电容加轨上大电容         |
| 电感在数字电路里没用                 | 电源 LC 滤波与磁珠是数字板标配，WiFi 板官方建议里就有  | 认识它的两副面孔：nH 级做匹配、µH 级与磁珠滤电源 |
| 二极管就是整流用的                   | WiFi 板上常见的是它的 RF 亲戚：ESD 保护管              | 电源入口和天线处的 ESD 管别当装饰删掉            |
| 匹配网络里那几个元件可以顺手改       | 模组内置匹配按 50 Ω 系统调好，WROOM-1 手册明令请勿修改 | 天线侧改动留给第九章的匹配分析                   |
| 看不懂符号没关系，反正有 BOM         | 符号自带语义：有极性电容接反、二极管装反都会出事故     | 先背 8.2 的口诀再看图，效率反而高                |
| 0.1 µF 是万能值，什么电路都放一颗    | 不同引脚需求不同，官方清单里 VDD_SPI 就配了 1 µF       | 照清单按引脚配，不搞一刀切                       |

一句话总括这张表的规律：四个元件的「用法」都是频率的函数——离开了频段谈容值、感值、阻值，都是刻舟求剑。

## 8.7 小结

- **四个元件，三份 RF 工作**：去耦（电容 = 每级芯片旁的缓冲池，对付发射瞬间的电流阶跃）、滤波（频率域的筛子，只让该过的频段过）、匹配（第九章主场，本章认脸）。
- **一条主线**：频率改变元件性格。「隔直通交、通直阻交」两句口诀，是从去耦到滤波到匹配全部推理的起点；寄生参数是频率世界的隐形税。
- **一张地图**：原理图 = 图标字体（符号）+ 符号名（网络标号）+ 主键（位号）；BOM 按 R/C/L/D 前缀分组即可按角色索引。
- **一个软件观察入口**：brownout 复位日志是电源毛刺在软件层最可见的投影；电源性格的完整故事在第十二章。
- **事实出处四件套**：ESP32-S3 Datasheet v2.2（功耗表：TX 峰值 340 mA 等）；《ESP32-S3 硬件设计指南》原理图检查（去耦清单、LC 滤波、0201 封装建议、4.8/7.2 GHz 谐波验收）；WROOM-1/1U Datasheet v1.8（22 µF+0.1 µF 参考设计、不可修改的内置匹配）；esp-box 仓库 hardware/（六张 BOX-3 原理图，本机实测存在）。
- **待核对两处**：BOX-3 主板原理图的具体元件值与天线形式（8.5）；「每毫米 1 nH」的走线电感量级是典型工程值，精确值取决于走线几何与叠层。

下一章把「阻抗」补全：50 Ω 从哪来、反射为什么会发生（类比协议不兼容导致的重传）、VSWR 与回损怎么读——天线附近那一小撮元件的完整故事，见[[ch09-impedance-matching|第九章：阻抗与匹配]]。
