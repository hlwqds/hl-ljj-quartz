# WiFi 射频硬件入门（十八）：综合实践——天线升级决策链与知识地图

> [!info] WiFi 射频硬件入门系列 0. [[wifi-rf-hw|系列索引]]
> 上一章：[[ch17-certification-regulations|第十七章：认证与法规一瞥]]
> **第十八章：综合实践与知识地图**（当前章）
> 下一章：系列完结：真机实验核销与进阶路线（正文十八章至此收官）

十七章走完，「WiFi 满格但上不了网」这条线索已经能从软件栈一路追问到天线口与法规条文。收官章做两件事：**用一条完整的决策链把全系列串起来**——以「ESP32 从 PCB 板载天线升级到 IPEX 外置天线」为实战案例，把散在各章的测量方法、dB 账与法规边界拧成一台能复用的机器；然后交出**全系列知识地图**与进阶路线，把这个系列还给更大的拼图。

核心类比先立起来，本章一切内容都在它上面：**天线升级决策 = 性能优化决策**。你调一个慢服务时的职业习惯——先 profile 找瓶颈、再算容量账、再动手改、再回归压测——整套搬到射频上一步不差；反过来，跳过测量直接换件，和不看火焰图直接改代码是同一种玄学。**不测量就优化是玄学**，这句话在两个世界同样成立。

| 性能优化决策                 | 天线升级决策                 |
| ---------------------------- | ---------------------------- |
| 先 profile：火焰图找热点     | 先测量：基线与方向图找瓶颈   |
| 再算账：预算与容量推演       | 再算账：链路预算的 dB 加减   |
| 再动手：改代码换配置         | 再动手：换天线挪位置         |
| 再验证：回归压测对比         | 再验证：同场地 A/B 复测      |
| 瓶颈在依赖服务，优化自己无用 | 瓶颈在 AP 端，改自己天线无用 |
| 改完要过配额与合规           | 发射要过 EIRP 法规上限       |

## 18.1 收官盘点：四问下钻走完一遍的你

四问下钻（Q1 现象、Q2 协议、Q3 芯片、Q4 电路，见[[wifi-rf-hw|系列索引]]）在这个系列的终点，从软件系列的「源码行号」换成了「datasheet 参数与元件符号」。走完一遍，你手里实际多了三样东西：

| 能力           | 到手的样子                               | 来源章                 |
| -------------- | ---------------------------------------- | ---------------------- |
| 看懂 datasheet | 功率与灵敏度表连着速率读，VSWR 换算成 dB | 三、六、九、十、十七章 |
| 零仪器测量     | 五件套实验与方向图手绘，单变量与中位纪律 | 六、十五章与本章       |
| 对话硬件工程师 | 50 欧姆、净空、失谐、EIRP 听得懂追得问   | 全系列                 |

三样能力各有一个自检动作：翻开 ESP32-S3-WROOM-1 的射频章节，能对着「+20.5 dBm @ 11b 1 Mbps」说出它为什么不是「发射功率 20.5 dBm」一个数（见第十章）；拿手机 App 站在客厅，能按第十五章的纪律采一组可比的 RSSI 数据；听到硬件同事说「这根线损太大、匹配也悬」，你接得住「线损多少、VSWR 多少、加起来净损几 dB」的追问。立项时承诺的不是「会设计」——是**看得懂、测得出、问得准**。这一章把三样能力放进同一条流水线里用一次。

## 18.2 决策链五步：测量、算账、合规、动手、验证

把开头的类比展开成流程，就是本章的主体。五步各有一个必须先回答的问题，答不上来就不要走下一步：

```text
        ┌──────────── 不达标：回炉（换件重选，或怀疑测量） ───────────┐
        v                                                          │
测量 -> 算账 -> 合规 -> 动手 -> 验证 -> 达标：结案，数据归档
```

| 步      | 问的问题           | 用的账本与工具              | 回收章               |
| ------- | ------------------ | --------------------------- | -------------------- |
| 一 测量 | 瓶颈真的在天线吗   | RSSI 基线、方向图、干扰矩阵 | 十五章               |
| 二 算账 | 净赚几 dB          | 链路预算：增益减线损减失配  | 三、五、六、九、十章 |
| 三 合规 | 这几 dB 发得出去吗 | EIRP 对法规限值审计         | 三、十七章           |
| 四 动手 | 买什么、怎么装     | IPEX 座、线缆、净空规矩     | 六、十三章           |
| 五 验证 | 真的变好了吗       | 同场地 A/B 复测             | 十五章               |

下面每步一小节，全部围绕同一个案例：**BOX-3 的 ESP32-S3-WROOM-1（板载 PCB 天线）要不要升级成 IPEX 外置天线**。

### 第一步 测量：先找瓶颈，别先买件

> [!warning] 待真机验证
> 本步的基线测量（距离 RSSI 曲线、方向图十二点、后台速率与 AP 侧 RSSI）沿用第十五章的实验协议，BOX-3 到货后实测回填；本节判定表的结论以实测数据为准。

性能优化的第一课是「瓶颈可能在别处」，射频同款——**信号差的原因有一半不在你的板上**。第十五章的五件套正好是排查工具箱，先做判定再谈升级：

| 第一步的观察               | 结论                   | 动作                       |
| -------------------------- | ---------------------- | -------------------------- |
| 同位置另一台设备同样差     | 瓶颈在环境或 AP 端     | 先换信道查干扰，改自己没用 |
| 只有这台差，方向图有深凹   | 板端天线姿态与遮挡     | 先挪位转姿态，再谈换件     |
| RSSI 好但延迟与丢包差      | SNR 问题：干扰或频偏   | 见第十四章与第十一章       |
| 一到大流量就掉线           | 电源毛刺拉低电压       | 见第十二章                 |
| 后台看这台客户端 RSSI 也差 | 双向都弱，板端嫌疑最大 | 进第二步算账               |

判定逻辑翻译成软件话术：**把另一台设备放到同一位置，就是拿一个已知健康的实例做对照实验**。两台都差，问题在共享环境（信道占用、干扰、AP 过载）——这时代优化自己服务没用；只有这台差，问题在这台的硬件链路上，天线才进入嫌疑人名单。「瓶颈在 AP 端你改自己没用」，这句是本步的全部要义。

基线测量记三样（协议全在第十五章）：距离 RSSI 曲线（1/2/4/8 米，每点五读数取中位）、方向图十二点、路由器后台的协商速率与 AP 侧 RSSI。这些数据一鱼两吃：既是本步的判据，也是第五步 A/B 复测的对照组——**没有升级前的基线，就没有升级后的结论**。

### 第二步 算账：净收益 = 增益差 − 线损 − 失配增量

第六章给过公式：净收益 = 天线增益 −（线损 + 失配损耗）。代入本案例的候选件（5 dBi 棒状外置天线、10 cm 延长线）：

| 账目                              | dB      | 口径                 |
| --------------------------------- | ------- | -------------------- |
| 天线增益差（5 dBi 对 2 dBi）      | +3      | 见第六章，量级待核对 |
| 外置链路插入损耗（座与 10 cm 线） | 约 -0.5 | 见第六章，待核对     |
| 失配增量：正品 VSWR 2:1 档        | 0       | 见第九章             |
| 失配增量：杂牌 3:1 档             | -1.25   | 见第九章             |
| 纸面净收益（正品口径）            | +2.5    | 本表合计             |

纸面结论：约两三个 dB——用第三章的距离规律换算，同速率可用距离约乘 1.3（自由空间口径），听起来不算激动人心。但账本还差一行**只有第一步的测量才能填**：如果 PCB 天线正被外壳、金属摆件或你的手掌压着（失谐加遮挡，见第六、九章），把它请出去修复的是测量已经看到的那几个 dB，这部分收益与纸面 +2.5 dB 是叠加的。**收益的大小由第一步的测量决定，不由商品页的 dBi 数字决定。**

### 第三步 合规：EIRP 审计——真会踩的坑

纸面账算完先别下单，还有一道性能优化里对应的「配额与 SLA」检查：发射功率不是你想发多少就发多少，EIRP（发射功率加天线增益，见第三章）有法规上限，超限的部分会被合规配置原额扣回——像极了扩容请求超了资源配额被限流器打回。

| 法域       | 2.4G 上限口径                            | 换 5 dBi 天线之后                |
| ---------- | ---------------------------------------- | -------------------------------- |
| 中国与欧盟 | EIRP 20 dBm（100 mW）                    | 超限，须功率回退，发射增益被没收 |
| 美国       | 传导 30 dBm、6 dBi 起，每超 3 dB 扣 1 dB | 有真发射收益，至 36 dBm 有效上限 |
| 模组认证   | WROOM-1U 按 2.33 dBi 天线认证            | 换天线可能触发 EMC 重测          |

（限值出处：信部无〔2002〕353 号、47 CFR 15.247、ETSI EN 300 328，均经第三章核实；认证流程与口径是[[ch17-certification-regulations|第十七章]]的主题。）

第三行常被个人玩家忽略：模组的认证是**连着那根天线**做的——WROOM-1U datasheet 写明认证所用天线增益不超过 2.33 dBi，换更高增益的天线「可能需要额外测试（如 EMC）」（见第六章）。量产产品换天线是认证变更；爱好者的板子虽无人来查，但你现在知道这条边界的存在，知道为什么路由器的国行与美版功率不同（见第三章的 16 dB 之差）。

### 第四步 动手：买什么、怎么装

判定通过、账算平、合规过审，才轮到下单。选型清单逐项回收前章：

| 部件    | 选型要点                                 | 依据                 |
| ------- | ---------------------------------------- | -------------------- |
| IPEX 座 | 兼容 U.FL（Hirose）、MHF（I-PEX）、AMC   | 见第六章             |
| 线缆    | 能短不长；1.13 mm 起步，0.81 mm 更细更损 | 见第六章，损耗待核对 |
| 天线    | 要 VSWR 曲线与方向图的品牌件             | 见第六、九章         |
| 焊装    | IPEX 焊盘全层挖空，天线净空 15 mm        | 见第十三章           |
| 机械    | IPEX 是机械弱点，防拔插与振动            | 见第六章             |

两个动手前的提醒。其一，**你的板子得先有座**：BOX-3 用的 WROOM-1 是板载天线版，与带 IPEX 座的 WROOM-1U 差在那 6.3 mm 的天线区（见第六章）——要么选 1U 变体的板，要么自己焊座，而焊座正是第九章警告过的「改变 50 欧走线几何」的动作，失配风险自担。其二，**线缆是耗材不是装饰**：第六章的线损账标的是 1.13 mm 细缆约 1 dB/m（待核对），更细的 0.81 mm 损耗更高（待核对），把天线引到金属外壳外的经典操作若拉到 1 m，5 dBi 就只剩 3 dB 出头（见第六章）——增益必须大于代价才有意义。

### 第五步 验证：同场地 A/B 复测（待真机验证）

> [!warning] 待真机验证
> 本步为完整 A/B 复测协议，需外置天线到货后执行；以下判读标准为设计稿，实测回填。

性能优化没有回归压测就不能宣布胜利，天线升级没有 A/B 复测就只是花钱买了心理安慰。协议三件套，纪律照第十五章：单变量（只换天线，位置姿态冻结）、多次采样取中位、记环境、先写预期再看结果。

| 指标      | 方法                         | 判读                             |
| --------- | ---------------------------- | -------------------------------- |
| RSSI 变化 | 同测点同姿态，换件前后各一轮 | 与第二步纸面账相差 2 dB 内算对上 |
| 方向图    | 十二点重画一轮               | 俯仰波束变窄，姿态更敏感         |
| 吞吐延迟  | ping 批次对照                | RSSI 与体验可能脱钩，看延迟丢包  |

判读要点三条：实测增益与纸面账差值在正负 2 dB 内算互相印证，差太多先回查失配与线损（第九章的嫌疑人名单）；高增益天线的方向图更窄，复测时若板子姿态稍有不同结果就大幅波动，那是波瓣变窄的物理而不是玄学；RSSI 改善不等于体验改善，「满格上不了网」的教训（第五章）在复测里最后一次出场——最终指标永远是延迟与吞吐。

## 18.3 dB 账完整算例：PCB 板载对比 IPEX 外置 5 dBi

把第二、三步合成一张全链路账单。先声明口径：传导功率用 WROOM-1 模组实测表（11b 1 Mbps 为 +20.5 dBm、HT20 MCS7 为 +17.5 dBm，模组表 16，见第十章）；天线增益为行业量级（板载 0 至 2 dBi、棒状 2 至 5 dBi，见第六章，待核对）；线损与失配为第六、九章口径。**这是算例表，不是任何一块板子的实测档案**；真实数字以第一步测量与本章复测为准。

发射方向（上行，AP 收）：

| 环节                    | PCB 板载             | IPEX 外置 5 dBi      | 口径                |
| ----------------------- | -------------------- | -------------------- | ------------------- |
| 传导功率（11b 1 Mbps）  | +20.5 dBm            | +20.5 dBm            | 模组表 16，见第十章 |
| 传导功率（HT20 MCS7）   | +17.5 dBm            | +17.5 dBm            | 模组表 16，见第十章 |
| 外置链路插入损耗        | 无此项               | 约 -0.5 dB           | 见第六章            |
| 失配损耗（VSWR 2:1）    | -0.5 dB              | -0.5 dB              | 见第九章            |
| 天线增益                | +2 dBi               | +5 dBi               | 见第六章，待核对    |
| EIRP（11b 1 Mbps 口径） | +22.0 dBm，约 160 mW | +24.5 dBm，约 280 mW | 本表推算            |
| 中国 EIRP 上限          | 20 dBm               | 20 dBm               | 见第三章            |
| 回退后 EIRP（合规口径） | 20 dBm               | 20 dBm               | 本表推算            |

这张表读出三条结论，每条都反直觉，恰好是本系列的收官彩蛋：

1. **发射方向的纸面收益会被 EIRP 帽子原额没收**。两种方案都超中国上限（板载超 2 dB、外置超 4.5 dB），合规做法都是回退传导功率（板载回退到约 18 dBm、外置回退到约 15.5 dBm），回退后两边 EIRP 同为 20 dBm——**升级天线一分发射收益都没赚到**。软件类比：配额打满时给单实例扩容，限流器先把你扣回总额，总吞吐不变。高速率口径同理更隐蔽：MCS7 的 17.5 dBm 加 5 dBi 减 1 dB 是 21.5 dBm，仍超限约 1.5 dB——越接近满功率的档位越容易踩线。
2. **接收方向不受法规限制，+2.5 dB 是净赚**。接收增益走互易定理（见第六章），不占 EIRP 预算——法规管你喊多响，不管你耳朵多灵。
3. **真正的升级空间在第一步量出的「位置账」**。把天线从外壳、金属、手掌边挪出去，修复的失谐与遮挡是纸面账之外的收益，几个 dB 起步——这才是「把天线请出壳外」的工程价值所在。

接收方向（下行，自己收）：

| 环节                   | PCB 板载 | IPEX 外置 5 dBi | 口径     |
| ---------------------- | -------- | --------------- | -------- |
| AP 侧 EIRP（同一环境） | 相同     | 相同            | 见第三章 |
| 传播损耗（同一测点）   | 相同     | 相同            | 见第三章 |
| 接收天线增益           | +2 dBi   | +5 dBi          | 见第六章 |
| 馈线插入损耗           | 无此项   | 约 -0.5 dB      | 见第六章 |
| 进模组电平变化         | 基准     | 约 +2.5 dB      | 本表推算 |

下行链路余量多 2.5 dB，按每 6 dB 距离翻倍（见第三章），同速率可用距离约乘 1.3；再叠加方向图对准与挪位收益，实测改善以第五步的 A/B 数据说话（待真机验证）。最后一个提醒来自第六章：高增益是压扁波瓣换的，俯仰面变窄意味着设备躺倒、挂墙后主瓣偏离 AP 时**反而变差**——增益从来不站在「方向中立」的立场上。

## 18.4 假货与玄学审计：「迷你高增益天线」的物理审视

决策链的四、五步之间横着一个市场现实：电商搜「ESP32 天线」，前排是 9.9 元包邮的「10 dBi 迷你全向天线」。用第六章的能量守恒做一次物理审计，这类商品当场现形。

**不可能三角：增益、体积、方向覆盖，三者不可兼得。** 天线是无源器件，增益不是放大而是把波瓣压扁（见第六章）；压得越扁，增益越高、覆盖角越窄。审计用一把尺子就够：整个天空的立体角约 41253 平方度（4π 球面度换算，天线教材通识）；10 dBi 意味着最强方向能量密度是理想全向天线的 10 倍，波束必须收进约十分之一的立体角——**若还自称全向（方位角 360 度），俯仰面波束只剩约 11 度，薄得像一张煎饼**（概念级估算）。一根几厘米的迷你胶棒在物理上既做不出这张煎饼，也做不出增益又高、覆盖又全、体积又小的三合一；电小天线还有教材通识的尺寸-带宽-效率下限约束（概念级），小体积与高增益天生相克。

| 你想要              | 物理代价             | 同时放弃               |
| ------------------- | -------------------- | ---------------------- |
| 高增益（10 dBi 级） | 波束收窄到十几度     | 全向覆盖（波束变窄）   |
| 迷你体积            | 电小天线效率带宽受限 | 高增益的可能           |
| 全向覆盖            | 波瓣只能是甜甜圈     | 高增益（增益靠压扁换） |

落到选购，一张鉴别清单：

| 检查项   | 正品的样子                   | 红旗                |
| -------- | ---------------------------- | ------------------- |
| 尺寸     | 与 3.1 cm 的四分之一波长相称 | 三厘米胶棒标 10 dBi |
| 匹配数据 | 频带内 VSWR 曲线低于 2       | 只有一个增益数字    |
| 方向图   | 给两切面图或注明全向         | 又全向又高增益      |
| 认证口径 | 标注法规与认证信息           | 无厂无址无曲线      |

杂牌高增益的真相，第九章早有断言：**增益是虚的，反射是真的**——标称增益抄自别家结构，匹配从没做过，插上先吃 1.25 dB 失配再谈其它。预算相同的两个世界：一根有 datasheet 的 5 dBi 品牌棒状天线，好过三根「10 dBi」迷你天线加包邮。

## 18.6 进阶路线：装备、书与本仓库的下一步

### 1. 装备：每一件扩大一层视野

第十五章立过规矩：仪器扩大视野，不替代纪律。进阶装备按预算爬梯，每件都标清楚「能看什么」与「看不到什么」：

| 装备       | 价位量级         | 能看什么             | 边界                                        |
| ---------- | ---------------- | -------------------- | ------------------------------------------- |
| 万用表     | 约 50 元         | 电源轨跌落与入口电流 | 射频看不见（第十二章）                      |
| RTL-SDR    | 约 200 元        | 频段能量瀑布图       | 裸机到 1.766 GHz，2.4G 需下变频（第十五章） |
| NanoVNA    | 数百元级，待核对 | 天线回波损耗曲线     | 定量精度有限，待核对                        |
| 入门示波器 | 千元级           | 电源纹波与使能脚时序 | 带宽远低于 2.4 GHz，载波看不见              |

两件新面孔补一句。NanoVNA 接的是第九章的班：VNA 是调匹配的仪器、屏幕上是那口「井」（频带内 S11 深沉到 -10 dB 以下），NanoVNA 把这口井带进几百元价位——规格与精度待核对，但「看自己天线的谐振井」第一次成为地摊预算内的动作。示波器则要先泼冷水：入门百 MHz 级带宽的用武之地是电源域与数字域（第十二章的电压跌落、FEM 使能脚的微秒级时序），2.4 GHz 载波需要 GHz 级带宽的专业仪器——示波器看得见「发射瞬间电压塌了」，看不见「发射的电磁波长什么样」。
