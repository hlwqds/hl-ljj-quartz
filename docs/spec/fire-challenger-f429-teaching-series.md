## 1. Goals（本迭代）

- 五阶段实验全部**真机做通**：每个实验有「做通标准」（可观察输出 / openocd 寄存器实证 /
  波形），不是"代码写完"。
- 对照表贯穿全程：Xtensa/IDF ↔ Cortex-M/Vanilla，每个新概念先给系统侧类比。
- 每实验沉淀三件套：可复现命令（make 目标/技能）+ 实测输出存档 + 根因/坑进
  docs/decisions.md 的 KD 日志。
- 阶段 4 的六个对照实验直接反哺 FreeRTOS 系列素材（PendSV ↔ Xtensa 窗口溢出是
  ch17 的镜像章节）。
- 成文节奏：实验先行、文章批量后置；成文时走既有 prettier/quartz build/wikilink 检查。

## 2. Non-goals（及影响）

- 不教 HAL/CubeMX——寄存器优先；HAL 只在对照处点名「 Cube 生成的是这几行」。
  影响：工程代码全手写，与官方教程风格不同属有意为之。
- 不做 mbed/Arduino/PlatformIO 等二次封装。
- 阶段 5 只走一条路（默认以太网路）；显示/CAN/USB 为备选，不并行铺开。
- 无仪器不编造：逻辑分析仪到货前的波形实验用 RPi 位采样替代或明确后置；
  延续「全文无伪造终端输出」红线。
- 不赶工：节奏以实验通过为准，周数只是粗估。

## 4.5 写作规范增补：小白模式（2026-08-30 用户指令）

- **术语首现必释**：每个专业名词第一次出现处必须有「是什么 / 为什么存在 / 类比锚点」；
  嵌入式·硬件·内核术语全量展开；系统/网络术语轻量回勾（一句话+标注「你的主场」）。
- **文首新词预览表**：每章开头加「本章会遇到的词」表（词 / 一句话版 / 详见正文小节）。
- **命令拆参到 flag 级**：每条操作命令给参数逐个解释的表格 + 「你会看到什么」 +
  「失败了先查什么」。
- **双层文本**：只增不删——小白读解释，熟手跳过；原有深度与待实测/待核对标记一律保留。
- 类比是脚手架不是事实：重要类比标注边界（「到这里类比就失效了」）。
- **装备清单（2026-08-30 追加）**：每章文首（状态声明后、新词表**前**）加「本章装备清单」
  表，四档：已有（✅）/ 需购买（价格锚点）/ 建议购买 / 可选进阶，每行含用途一句话；
  无新增装备的章也列「沿用基础盘」一行——读者打开任何一章都能立刻知道要买什么。
