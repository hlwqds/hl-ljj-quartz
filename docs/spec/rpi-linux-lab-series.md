# Spec: 树莓派 4B 实验室（仪器 / 对端 / Linux 反向解剖）

- 状态：**已确认**（2026-08-30 用户确认；阶段 R0 可随时启动）
- 姊妹 spec：`docs/spec/fire-challenger-f429-teaching-series.md`（F429 主线，本 spec 与其互引）
- 读者画像：系统/网络侧资深（用户态/网络是主场，内核驱动与设备树是新地）；F429 裸机
  阶段 1 结束后开本系列主线效果最佳
- 硬件基座：RPi4B + 直连笔记本网线（NM shared 10.42.0.1）；SSH 端口 8082、公钥免密；
  无 RTC（每次上电先校时）；Buster（2020）待升级
- 定位：RPi 不是「被学的板子」，是**仪器 + 陪练对端 + 反向解剖对象**三重身份

## 1. Goals（本迭代）

- Linux 反向解剖课（R1–R5）真机做通：把天天用的 Linux 从 GPIO 往下拆到寄存器，
  每实验有做通标准（可观察证据），与 F429 裸机同题材互为对照。
- 服务性实验（仪器/对端）按需执行：已挂靠 F429/WiFi RF/BOX-3 各 spec，本 spec 只登记
  责任与做通标准，不重复排期。
- 对照表贯穿：NVIC 直配 ↔ request_irq、裸机点灯 ↔ 用户态三态、F429 无设备树 ↔ DT——
  每层 Linux「官僚体系」都回答「它在解决裸机的什么问题」。
- 实验先行、成文后置；翻车进 KD，实测输出存档（同 lwip-labs CONVENTIONS）。

## 2. Non-goals（及影响）

- 不学 RPi 应用开发（Python/OpenCV/智能家居方向）——本实验室只把它当 Linux 标本与仪器。
- 不做内核主线贡献级开发（内存管理/调度器）——只到「字符设备+IRQ+DT+总线驱动」层。
- 不追求实时性（PREEMPT_RT 只作为概念对照提一句，不实测）。
- 仪器能力不与专业设备攀比：piscope 1µs 采样是穷人档，LA 到货后波形实验以 LA 为准。
- 不编造输出：需要未做实验支撑的论断一律标「待实测」。

### 阶段 R1：用户态点灯三态（Linux 反向课第一课）

| #    | 实验                        | 做通标准                                              | 教学点                                               |
| ---- | --------------------------- | ----------------------------------------------------- | ---------------------------------------------------- |

## 4.5 写作规范增补：小白模式（2026-08-30 用户指令）

- **术语首现必释**：每个专业名词第一次出现处必须有「是什么 / 为什么存在 / 类比锚点」；
  嵌入式·硬件·内核·驱动术语全量展开；系统/网络术语轻量回勾（一句话+标注「你的主场」）。
- **文首新词预览表**：每章开头加「本章会遇到的词」表（词 / 一句话版 / 详见正文小节）。
- **命令拆参到 flag 级**：每条操作命令给参数逐个解释的表格 + 「你会看到什么」 +
  「失败了先查什么」。
- **双层文本**：只增不删——小白读解释，熟手跳过；原有深度与待实测/待核对标记一律保留。
- 类比是脚手架不是事实：重要类比标注边界（「到这里类比就失效了」）。
- **装备清单（2026-08-30 追加）**：每章文首（状态声明后、新词表**前**）加「本章装备清单」
  表，四档：已有（✅）/ 需购买（价格锚点）/ 建议购买 / 可选进阶，每行含用途一句话；
  无新增装备的章也列「沿用基础盘」一行——读者打开任何一章都能立刻知道要买什么。

## 5. 验证计划

- 每实验以做通标准逐条核销：dmesg/trace 文本、引脚电平、/proc 值三类证据至少其一。
- 内核源码级论断（如 file_operations 语义）给出源码文件路径； raspberrypi/linux
  克隆到 `~/rpi/linux`（R0 后执行）。
- 成文批次走既有三项：prettier → `npm run check` → `npx quartz build` + 死链扫描。
- 翻车（如升级失败、内核模块 panic）必进 KD 日志。
- **图优先（2026-09-01 追加，用户指令）**：重要机制/结构/流程**必配 ASCII 图**（代码块
  内绘制），图的口径优先于文字——用户明确反馈"画图才能教会"。适用：内核/驱动架构、
  调用链、设备树结构、信号流。
- **Tag 唯一性 + 专业措辞（2026-09-01 追加，用户指令）**：系列 tag=rpi-lab + 受控
  主题词；跨章引用禁用口语化说法（救砖/傻瓜/穷人→故障恢复/防呆/低成本），详见
  F429 spec 同日条款。
