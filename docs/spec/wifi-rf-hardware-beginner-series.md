## 1. Goals（本迭代）

- 交付 18 章初稿：每个硬件概念必须有软件类比；数学只在"不懂就看不懂
  datasheet"时出现（dB 换算、Friis/链路预算的概念式）。
- 硬件事实可溯源：频段/功率限值/芯片参数引用官方 datasheet、ESP-FAQ、
  FCC/SRRC 文件并注明出处；查不到标「待核对」。
- 观察实验分层：手机 App/路由器后台/ESP32 真机可做的写全步骤；需仪器的
  只做概念演示，不编造仪器截图与读数。
- 与既有三系列的交叉引用准确（lwIP 十八 = 软件栈层、BOX-3 十六 = 连接
  管理层、本系列 = PHY/电路层，三者边界在文中显式说明）。

## 2. Non-goals（及影响）

- 天线设计与仿真（史密斯圆图只到"它是匹配的可视化"概念级）——影响：
  读者不会算匹配网络，只识别元件与参数。
- 射频电路计算/芯片设计入门——影响：不教 layout 实操，只教看懂模组
  datasheet 与设计约束。
- 5G/6GHz 实测（无装备）——6GHz 只讲标准演进；实验全部 2.4GHz。
- 认证测试的测试项细节——只讲认证是什么、为何存在、对选型的影响。
- 仪器教程——频谱仪/矢网只讲"看什么"，不教操作。
