# 黄琳 HTML 简历设计说明

## 目标

为 Linux 内核 / 高性能网络研发岗位制作一份两页 A4 HTML 简历。HTML 是视觉和内容的主版本，PDF 直接由浏览器打印生成。

## 设计方向

采用极简 ATS 风格：

- 白色背景，不使用深色侧栏、卡片墙、渐变和装饰图标。
- 仅使用深蓝标题、青色小范围强调和浅灰分隔线。
- 单栏阅读顺序，兼顾 ATS 文本提取和招聘人员快速扫读。
- 照片保留在第一页右上角，尺寸克制，不参与正文布局。
- 使用浏览器原生可打印字体栈，中文优先使用 Noto Sans CJK SC。

## 页面结构

### 第一页

1. 姓名、目标岗位、年龄、所在地、工作年限、电话、邮箱和技术主页。
2. 两行以内的职业摘要。
3. 三列核心能力概览。
4. 上海格微安科技有限公司经历：
   - Suricata 协议检测与 AF_XDP/DPDK ACL。
   - eCapture 加密流量证书与 URL 观测。
   - Kafka/ClickHouse 日志链路优化。

### 第二页

1. 北京外企德科（派驻华为 OS 内核实验室）经历：
   - AF_UNIX 协议实现。
   - 微内核 eBPF 子系统适配。
   - 内核疑难问题定位。
   - XXIP 协议栈集成。
2. 南京易米云通早期经历。
3. amux 与个人技术知识库。
4. 技能补充和教育经历。

## 排版规范

- 页面：A4，固定两页，每页独立 `.page` 容器。
- 打印边距：页面内部使用约 15 mm 留白，浏览器打印边距设为 0。
- 正文字号：约 10 pt；标题按 12–24 pt 分级。
- 行距：1.45 左右，避免密集文字墙。
- 工作经历：公司、职位和日期形成固定三层层级。
- 项目：粗体项目名、灰色技术栈、2–3 条简短要点。
- 指标直接嵌入要点并加粗，不创建独立指标卡。
- 页面断点固定，不依赖浏览器自动分页。

- 检查照片、中文字体、链接、长英文标识和项目标题是否溢出。
- 检查打印模式下背景、颜色和分隔线。
- PDF 必须为两页 A4，并可正常提取关键文本。
