# WiFi 空口调度实验套件 · 构建规格 v1（AIRTIME SPEC）

本文件是 `practice/wifi-airtime-labs/` 套件的实现契约，配套系列为
[[wifi-airtime|WiFi 空口调度实战]]，章节与工程的互链关系见各工程 README。

## 1. 定位

把《WiFi 空口调度实战》讲到的机制做成**可运行的最小实现**：宿主端（PC 或
树莓派）C 程序，不碰固件、不依赖 ESP-IDF 或任何 SDK，一行编译命令即可复现；
章节正文引用的实验数字，出处一律是本套件对应工程的 `run.log` 真实输出。

## 2. 技术栈与语言公约

- **C11、零第三方依赖**，仅标准 C 库头文件；编译器 `zig cc` / `gcc` 皆可
  （`~/zig/zig cc -O2` 与系统 gcc 等价；Windows 下 zig cc 产出的 `.pdb`
  等调试残留不入库）。
- 单位公约：内核 nl80211 survey 时间字段语义为 **µs**，`iw` 打印时除以 1000
  显示 **ms**——解析器必须识别行尾单位并统一归一到 µs 再算比例（比例值两种
  单位一致，绝对值必须归一）。
- 判定阈值集中在源码顶部 `#define`（busy 饱和 70%、重传偏高 30%），README
  与章节引用时注明出处行。

## 3. 目录约定

- 目录：`practice/wifi-airtime-labs/chNN-slug/`（NN 两位，与所属系列章节号
  对齐）。
- 通用必备：源码（单文件为主）、`README.md`（中文，含拓扑与复现命令）、
  `run.log`（真实运行输出）。按工程形态附加：
  - **仿真类**（ch01）：固定随机种子，同机重跑输出逐字节一致；
  - **文本解析类**（ch02）：`fixtures/`（按 iw 输出布局构造的样例）+
    `collect.sh`（真机采集脚本，头部标注待真机状态）；
  - **回环测量类**（ch07）：跨平台垫层头文件原样拷贝并注明来源工程。

## 4. 诚实性规则

- **仿真与回环实测是真实输出**：`run.log` 必须是程序真实运行的重定向，严禁
  编造；fixtures 是**构造样例**（布局忠实于 iw 真实输出，数值为设计值，供
  解析器自检），真机数据一律由 `collect.sh` 现场采集，不入库。
- **真机采集类标「待真机」**：脚本头部与 README 显式标注；采集脚本入库前
  必须在宿主用 iw 桩脚本（PATH 注入假 `iw` 回放 fixtures）干跑通过。
- 真机测量的宿主环境（系统烧写、权限、排错）衔接 [[rpi-lab|树莓派实验室]]。
- 回环数字不得当作空口画像引用——各工程 README 的「诚实边界」小节划定结论
  的适用范围。

## 5. 端口号段 13200–13299（专用，禁止越界）

仅网络类工程（ch07）使用：默认收发 13201，双进程示例 13202。后续网络类新
工程从 13210 起按每工程一个十位块递增分配。
