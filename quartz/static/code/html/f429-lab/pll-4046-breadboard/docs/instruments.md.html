## 先说结论：每种量找对仪器

| 你想知道什么           | 用哪件                                        | 一句话判据                                   |
| ---------------------- | --------------------------------------------- | -------------------------------------------- |
| VCOIN 锁定没有         | **万用表** 直流电压档                         | 读数**稳定不跳** = 锁定；漂移/摆动 = 失锁    |
| 频率是多少             | **树莓派频率计**（`measure_freq.py`，pigpio） | 在 4040 的 Q 输出上数边沿，×2ⁿ 还原 VCO 频率 |
| 锁定时相位对齐没有     | **piscope** 双通道                            | REF 与分频输出的边沿**相对位置不动** = 锁定  |
| MHz 级波形、PC2 窄脉冲 | **fx2lpo LA**（未购，可选）                   | 24MSa/s，N=64 的 2.1MHz 也够看               |

先立个总纲（网络侧类比）：PLL 锁定像 TCP 拥塞控制收敛——收敛的是**关系**（频率相等、相差恒定），
不是某个**数值**。所以全文反复出现一句话：别问「VCOIN 应该是几伏」，要问「VCOIN 稳不稳」。

## 1. 面包板 ↔ 树莓派接线

| 树莓派排针（物理脚） | 接到面包板           | 用途                                          |
| -------------------- | -------------------- | --------------------------------------------- |
| 3V3（脚 1）          | 电源正轨             | 全案唯一电源：预算 <50mA，实际 <20mA          |
| GND（脚 9）          | 电源负轨             | 供电即共地——这是 piscope/频率计读数有效的前提 |
| GPIO17（脚 11）      | 探针 A（默认测频脚） | `measure_freq.py` 默认脚；piscope 通道 1      |
| GPIO27（脚 13）      | 探针 B               | piscope 通道 2（与通道 1 对照看相位）         |

探针 A/B 按实验阶段换接法：

- **开环扫频（步骤 1）**：探针 A 接 **4040 的某个 Q 输出**（如 Q4 = VCO÷16），读数 ×16 还原 VCO 频率
  ——为什么不在 VCO 输出上直接测，见 §3 的奈奎斯特账；
- **闭环看锁定（步骤 2 起）**：探针 A 接 **REF**（32.768kHz 晶振输出）、探针 B 接**反馈 Q 输出**——
  锁定时两者同为 32768Hz，边沿对齐。名词对照教程的叫法：**探针 A 的 REF = SIGIN = TP2 = 晶振 OUT；
  探针 B 的反馈 Q 输出 = COMPIN = TP3**（经跳线 J1 接到 4046 脚 3 的那个 Q 脚，N=16 时即 4040 脚 5）
  ——各是同一张网，夹测点或夹信号源头读数相同。

**3.3V 红线（铁律）**：Pi 的 GPIO 只忍 3.3V。本实验全案 3.3V 供电，信号可直连；
**若改 5V 供电，任何信号进 Pi 前必须分压**（如 10kΩ 上 + 20kΩ 下 ≈ 3.3V），否则烧 Pi。
rpi-lab 系列的「跨板先共地、3.3V 红线」规约在此完整适用。

> ⚠️ **管脚免责**：4046 家族第 15 脚功能随厂商不同（CD4046B 是稳压输出 ZENER，NXP 74HC4046 是
> PC3OUT），4040 各 Q 输出的物理引脚号也需查表——**一律不接 Pi、以实物 datasheet 为准**；
> 查不准的引脚号标「待核对」，绝不猜。

## 2. 万用表：稳态测量 + 免费的「慢速示波器」

1. **VCOIN 锁定判据（本实验万用表的头号任务）**：直流电压档，表笔接 VCOIN 节点（4046 第 9 脚）
   对地。锁定 = 读数**末位稳定不跳**，几十秒不漂；失锁 = 读数缓慢漂移或周期性摆动
   （环路在搜索/振荡）。**读数具体是几伏不作判据**（原因见 §7 预期值总表）。
2. **供电检查**：直流档量面包板正轨对地 ≈3.3V；再量 4046 的 VCC 脚（第 16 脚）对地，确认杜邦线压降可忽略。
   上电前用通断档查 INH（4046 第 5 脚）、MR（4040 第 11 脚）到地是否导通——这两个脚悬空就是
   「仪器读数诡异」的头号来源（INH 悬空禁 VCO，MR 悬空随机清零计数器）。
3. **慢信号平均值技巧（VDD/2）**：万用表直流档显示的是数百 ms 的积分平均——一个占空比 50% 的
   慢方波读数就是 VDD/2 ≈ 1.65V。用法：失锁拍频期 VCOIN 在轨间摆动，表会读出中间值附近且不稳；
   PC2OUT 在失锁时输出宽脉冲，平均值朝修正方向偏移——VCO 慢于参考时高电平占多
   （平均抬升）、快于参考时低电平占多（平均下压）。锁定后 PC2OUT 只剩极窄脉冲，
   万用表几乎读不出脉冲本身——看脉冲要靠 LA。
4. **静态电流（本实验唯一要断线的测量）**：①红表笔从 VΩ 孔拔出、改插 **mA 孔**，
   黑笔留 COM，档位拨直流 200mA；②拔 Pi 侧 3V3 杜邦线断电，再把该线的母头端
   从 Pi 排针 3V3 针上拔下；③把表串进回路：红表笔尖插进杜邦母头孔、黑表笔尖
   碰 Pi 的 3V3 针（电流路径：Pi 3V3 → 黑笔 → 表 → 红笔 → 杜邦线 → 红轨）；
   ④恢复供电读数：数 mA 级、<20mA 合格，读数骤增或超 50mA 立即断电。
   切记电流档内阻近零，**严禁**两表笔并联跨在电源与地之间直接量（等于短路）。

## 3. 树莓派频率计：tools/measure_freq.py

pigpio 守护进程在后台数 GPIO 上升沿，脚本用「闸门时间内的边沿数 ÷ 闸门时长」得到频率，
每轮打印本次值与累计均值，Ctrl-C 退出。原理与依赖安装写在脚本头部 docstring 里。

```bash
# 树莓派上（安装细节与 pigpiod 定位见 rpi-lab ch08 §1）：
sudo apt install pigpio python3-pigpio
sudo killall pigpiod 2>/dev/null; sudo pigpiod -s 1   # 1µs 档：可靠边沿上限约 500kHz（§3）；默认 5µs 档按同一准则只有约 100kHz，kHz 级以上即开始漏计

# 测 Q4（锁定时应读 32768.0 Hz 附近，ppm 偏差见 §6）：
python3 tools/measure_freq.py --gpio 17 --gate 10

# 开环扫频：探针挂 Q4，读数 ×16 = VCO 频率；想连续盯住变化就缩短闸门：
python3 tools/measure_freq.py --gpio 17 --gate 2 --interval 1
```

**为什么在 Q 输出上测、不直接测 VCO 输出（奈奎斯特账）**：pigpio 1µs 采样 = 每通道 1MSa/s，
可靠检测的边沿事件上限约 500kHz。N=16 的 VCO 输出 524288Hz 刚越过这条线——采样法会把周期
1.9µs 的方波混叠，计数趋向「采样率 − 信号频率」≈ 476kHz（推导值，待实测核销），欠读约 9%。
而 4040 的 Q4 锁定后是 32768Hz（每周期 30 个采样），怎么测都稳。**精确频率永远在 Q 输出上测，
读数 ×2ⁿ 还原**；VCO 输出脚留给 LA 或只做数量级粗验。

## 4. piscope：双通道看「边沿对齐」

piscope 的安装、pigpiod 远程连接（8888 端口默认只听 localhost 的坑）全部以
[[ch08-instrument-roles-guide|RPi 仪器手册（rpi-lab ch08）]] §1 为准，此处只列本实验的操作序：

1. `sudo pigpiod -s 1` 起 1µs 档；`pigs hwver` 吐 BCM 版本号 = 守护进程活着；
2. 探针 A（GPIO17）接 REF、探针 B（GPIO27）接反馈 Q 输出（N=16 时即 Q4）；
3. 笔记本上的 piscope GUI 连 `raspberrypi.local`，看到两路 32768Hz 方波；
4. **锁定判据**：把时间光标卡在 REF 的一个上升沿上，看 Q 输出上升沿与它的间距——
   **多次抓屏间距不变** = 相位锁定；每次抓屏都在滑 = 两频率不等（失锁拍频）。

```text
锁定（边沿相对位置冻结）            失锁（边沿相对滑动，每次抓屏都在变）
REF  ┌──┐  ┌──┐  ┌──┐            REF  ┌──┐  ┌──┐  ┌──┐
       └──┘   └──┘   └──┘              └──┘   └──┘   └──┘
Q4   ┌──┐  ┌──┐  ┌──┐            Q4    ┌──┐  ┌──┐  ┌──┐   ← 缓慢左/右滑
   └──┘   └──┘   └──┘                └──┘   └──┘   └──┘
     ↑ 相位差恒定                       ↑ 相位差漂移（拍频）
```

类比：失锁时两路信号像两台没对时的 NTP 服务器，偏差一直漂；锁定后像 PTP 主从，
偏差恒定不动——**恒定的小偏差不是问题，漂才是**。

## 5. fx2lpo LA + PulseView（可选，设备未购）

到货后替代 piscope 做 MHz 级与窄脉冲观察（本节为操作预案，待实测核销）：

1. 笔记本装 sigrok/PulseView，插 fx2lpo，设备选 fx2lpo、采样率 24MHz；
2. 通道映射：CH0→REF、CH1→VCOOUT、CH2→反馈 Q 输出、CH3→PC2OUT（各通道地线接面包板地轨）；
3. 测频：时间光标卡一个周期的两个上升沿，1/T 即频率（N=64 的 2.097MHz 也有 11 个采样/周期）；
4. 看 PC2OUT 窄脉冲：时基调到最细，盯参考沿处——锁定时是极窄的修正脉冲
   （piscope/pigpio 的 1µs 档看不清它，这正是要 LA 的原因）。

## 6. 频率读数换算 ppm：和 ch01 的晶振精度对账

公式：

```text
偏差(ppm) = (f实测 − f标称) / f标称 × 10⁶
```

**算例一（读数异常时）**：实测 524.1kHz（=524100Hz），标称 524288Hz：

```text
(524100 − 524288) / 524288 × 10⁶ = −188 / 524288 × 10⁶ ≈ −358.6 ppm
```

−358.6ppm 比表晶典型公差（±20ppm 量级）大一个数量级——**先别怪晶振**，按顺序排查：
环路失锁（VCOIN 稳不稳）→ 计数欠读（是不是直接测了 524kHz 的 VCO 输出，见 §3）→
才轮到参考晶振偏差。

**算例二（健康形态）**：实测 524.31kHz（=524310Hz）：

```text
(524310 − 524288) / 524288 × 10⁶ = +22 / 524288 × 10⁶ ≈ +42.0 ppm
```

+42.0ppm 与 [[ch01-systick-heartbeat|SysTick 章]] 用 65 秒精测出的板上 25MHz HSE +40.9ppm
同量级——锁定后 PLL 输出的偏差**就是**参考晶振的偏差（锁定跟随参考），这是同一颗晶振世界观的
两次独立测量对上账。

**量化误差预算**：计数法有 ±1 边沿量化误差 = 1/边沿总数。32768Hz、闸门 2s（65536 个边沿）
→ 每轮 ±15.3ppm，判 ppm 级要 `--gate 10`（±3.1ppm）；n 轮累计均值再除 √n。这正是 ch01
「65 秒精测」的长闸门对表思想——闸门越长，刻度越细。

## 7. 预期值总表（先成文，待实测核销）

| 观测点             | 预期值                                                                      | 说明                                                                               |
| ------------------ | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| REF（SIGIN）       | 32768 Hz 方波                                                               | 有源晶振输出，约占空比 50%                                                         |
| VCO 输出，N=16     | 524288 Hz                                                                   | 超 pigpio 500kHz 边沿上限：piscope 看不清波形、计数欠读（§3），在 Q4 上测          |
| VCO 输出，N=32     | 1048576 Hz                                                                  | **超出 piscope 能力**，需 LA（或 Q 输出 ×2ⁿ）                                      |
| VCO 输出，N=64     | 2097152 Hz                                                                  | 同上，LA 才能直接看                                                                |
| VCOIN（锁定时）    | **稳定直流**，典型落在约 1.1~2.1V 邻域的某个值（3.3V 插值）——不是固定目标值 | 见下方解释                                                                         |
| PC2OUT（锁定时）   | 近似三态 + 参考沿处窄脉冲                                                   | 万用表读不出脉冲，LA 才能看清；失锁时变宽脉冲、平均值朝修正方向偏移（慢=升/快=降） |
| REF vs 反馈 Q 输出 | 边沿对齐且间距不变                                                          | piscope 双通道的锁定判据（§4）                                                     |

**为什么 VCOIN 不是固定目标值**：锁定的判据是「频率对」（VCO 输出 = N×REF），不是「电压对」。
VCOIN 稳在哪一伏，由 VCO 的 f-V 转换曲线决定——自由振荡频率（C1/R1/R2 定的）、温度、
芯片个体差异都参与。类比：TCP 收敛后的 cwnd 不是定值，是路径 BDP 的函数——换个网络收敛点
就换，但「收敛」这件事本身没变。换一颗 4046 或改一个 C1，锁定电压就搬家；只要它**稳**，环路就是健康的。

## 8. 常见观测坑

| 坑                | 现象                                | 规避                                                                                                                                     |
| ----------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 未共地            | piscope 波形全 0 或乱跳；频率计读 0 | 从 Pi 取电即天然共地；一旦换独立电源或加第三台仪器（DAP、LA），先把所有 GND 接一起                                                       |
| 5V 直连 Pi        | GPIO 损坏（不可逆）                 | 全案 3.3V；改 5V 供电则信号必经分压（§1 红线）                                                                                           |
| 采样率不足        | 波形畸变、计数偏低                  | pigpiod 切 1µs 档；>500kHz 一律在 Q 输出上测 ×2ⁿ 或上 LA（§3）                                                                           |
| 探头电容/负载     | 一挂上 VCOIN 环路就变味：锁定点漂移 | VCOIN 是高阻节点（100kΩ 串阻 + 100nF），只许万用表（10MΩ）碰；LA 输入 ~100kΩ//10pF，一挂就改环路滤波。VCOOUT 与 Q 输出是低阻驱动，随便接 |
| pigpiod 端口/独占 | 连不上、GPIO 被占                   | 8888 默认只听 localhost（远程配置见 rpi-lab ch08）；上次没杀干净的 pigpiod 先 `killall`                                                  |
