# ex14 perf-gym-tcp —— menuconfig 旋钮
#
# ⚠⚠ 场景切换走构建期（SPEC §5 ex14 硬要求）：
#   不要在这里手改场景后直接 build——sdkconfig.defaults 只在 sdkconfig 不存在时生效，
#   残留旧值会静默吃掉新配置（Batch 1 教训）。标准切法：
#     cp sdkconfig.defaults.scN sdkconfig.defaults
#     rm -f sdkconfig            # ← 必须删！
#     idf.py build               # 重新生成全量 sdkconfig
#   预设文件与场景对照见 README「构建命令」一节。

menu "Example Perf Gym TCP Configuration"

config GYM_SCENARIO
    int "错误注入场景编号（0=健康基线，构建期切换）"
    range 0 4
    default 0
    help
        本固件把四类真实调参/编码错误做成可切换场景，跑同一套基准负载：

        0 = 健康基线（对照口径；也是所有 fixed 变体的"代码侧"形态）
        1 = 窗口过小：SND_BUF/WND 被压到 2×MSS → 外环吞吐坍缩
        2 = 大窗小环黑洞：WND=28800 但 openeth RX 环保持默认 4
            → hostfwd 入向吞吐黑洞（窗口×RX 环深不等式，ch24 头号发现）
        3 = 发送泵漏挂 tcp_sent 回调（代码级错误，复刻 ch6 真 bug）→ 吞吐涓流
        4 = PCB 计数闸 MEMP_TCP_PCB=2（CONFIG_LWIP_MAX_ACTIVE_TCP=2）
            → 新连接静默无响应 + tcp.memerr 爬升

        注意数值旋钮本身不在本菜单里：SND_BUF/WND 是 lwIP 组件级符号
        （CONFIG_LWIP_TCP_SND_BUF_DEFAULT / CONFIG_LWIP_TCP_WND_DEFAULT），
        RX 环深是 esp_eth 的 CONFIG_ETH_OPENETH_DMA_RX_BUFFER_NUM，
        PCB 上限是 CONFIG_LWIP_MAX_ACTIVE_TCP。每场景的坏/修两档预设
        以 sdkconfig.defaults.scN / sdkconfig.defaults.scN.fixed 成对交付，
        场景号必须和对应预设配套使用。

config GYM_ROUNDS
    int "每腿轮数（LB/TX/RX 三腿交错执行）"
    range 1 5
    default 2
    help
        一轮内按 LB(镜像回声,对端 tools/gym_echo.py) -> TX(raw 泵外发) -> RX(hostfwd 灌流) 顺序执行，
        再进下一轮——同开机交错轮次是 ch6 方法学，用于对冲 QEMU 宿主负载抖动
        （Batch 4 实测 ±50%）。

config GYM_MB
    int "单轮数据量（MB，十进制 MB=1000000B）"
    range 1 32
    default 2
    help
        TX/RX/LB 每腿每轮传输的目标字节数。涓流场景靠截断早停规则限幅，
        不会真等满额传输。

config GYM_PEER_WAIT_SEC
    int "等待宿主工具就绪的秒数（TX 重试与 RX 接受共用预算）"
    range 5 120
    default 25
    help
        TX 泵拨 10.0.2.2:8311 找 tools/gym_sink.py、RX 口等 tools/gym_flood.py
        接入，超时按 PEER_DOWN 记账并跳过该腿剩余轮次（不是错误，是"对端缺席"）。

config GYM_TX_DEADLINE_SEC
    int "raw 泵单轮硬预算秒数"
    range 10 120
    default 30
    help
        到点未发完即中断连接。含涓流早停规则：启动满 12s 后若滑窗速率仍低于
        20KB/s（= tcp_poll 补发节拍的特征值），提前判 TRICKLE_STOP 收档。
        这两个数字本身就是诊断证据的一部分，改小会让涓流特征失去展示窗口。

endmenu
