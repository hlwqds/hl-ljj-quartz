    config ZC_CASE
        int "Zero-copy case (0=catalog 1=rx-parse 2=tx-segment 3=layer-tax 4=stream-checksum 5=honest-boundary)"
        range 0 5
        default 0
        help
            0 说明模式（打印五案例目录 + 8330 入向命令口）；
            1 案例 A RX 就地解析：recv 回调直接在 pbuf payload 上解析协议头 vs 先 memcpy 再解析；
            2 案例 B TX 分段提交：头/体分离 write+MORE vs 用户侧拼大缓冲整体 write；
            3 案例 C 接收路径层级拷贝差：同一回声负载走 raw/netconn/socket 三层；
            4 案例 D 流式校验零落地：边收边算 Fletcher32 vs 收完落地整包再算；
            5 案例 E 诚实边界：IDF 硬编码 LWIP_NETIF_TX_SINGLE_PBUF=1 使 COPY 强制，
              apiflags 证据 + 行为学验证（write 后改源缓冲，收端 digest 定案）。
