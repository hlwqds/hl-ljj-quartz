menu "ESP LV Adapter"

config ESP_LVGL_ADAPTER_ENABLE_FS
    bool "Enable esp_lv_fs integration"
    default n

config ESP_LVGL_ADAPTER_ENABLE_DECODER
    bool "Enable esp_lv_decoder integration"
    default n

config ESP_LVGL_ADAPTER_PARTIAL_AUX_IMG_CACHE
    bool "Set LVGL image cache to max (partial tear-avoid modes)"
    default n
    help
        When enabled, set LVGL image cache to maximum for partial tear-avoid modes
        (v8: LV_IMG_CACHE_DEF_SIZE; v9: LV_CACHE_DEF_SIZE, LV_IMAGE_HEADER_CACHE_DEF_CNT).
        When disabled, LVGL cache is not overridden.

config ESP_LVGL_ADAPTER_ENABLE_FREETYPE
    bool "Enable FreeType font support"
    default n
    help
        Enable FreeType library for rendering TrueType/OpenType vector fonts.
        Fonts are auto-cleaned up in esp_lv_adapter_deinit().

        Requirements:
        - Enable CONFIG_LV_USE_FREETYPE in LVGL configuration

        Stack Configuration:
        - LVGL v8: FreeType font initialization runs in the caller task.
        - LVGL v9: FreeType glyph rendering runs on LVGL draw threads.

        Limitations:
        - LVGL v8: Cannot use LVGL virtual filesystem (lv_fs) for fonts
        - LVGL v9: Can use virtual filesystem paths like "F:font.ttf"

config ESP_LVGL_ADAPTER_FREETYPE_SMALL_RENDER_POOL
    bool "Reduce FreeType render pool stack usage"
    depends on ESP_LVGL_ADAPTER_ENABLE_FREETYPE
    default n
    help
        Reduce FreeType's render pool from 16KB to 4KB. On LVGL v9, this also
        removes LVGL's conservative 32KB FreeType draw-stack build-time check.

config ESP_LVGL_ADAPTER_FREETYPE_MINIMAL_BUILD
    bool "Reduce FreeType flash usage with a minimal module set"
    depends on ESP_LVGL_ADAPTER_ENABLE_FREETYPE
    default n
    help
        Build the freetype component with a reduced module set and config
        tailored for LVGL runtime fonts. This keeps the default dependency
        model but removes legacy font drivers and compressed stream helpers
        from the final linked image when they are not needed by LVGL.

        Intended to preserve common TTF/OTF usage while reducing flash usage.
        Applies to both LVGL v8 and v9 FreeType integration paths.
        When enabled, these formats/features are removed:
        - Type1/CID/PFR/Type42/BDF/PCF/FNT font drivers
        - gzip/lzw/bzip2 compressed font stream helpers
        - SDF/SVG/monochrome raster backends

        Keep this disabled if your project depends on those formats/features.

config ESP_LVGL_ADAPTER_LVGL_THREAD_STACK_IN_PSRAM
    bool "Allocate LVGL FreeRTOS thread stacks in PSRAM"
    depends on SPIRAM
    depends on FREERTOS_TASK_CREATE_ALLOW_EXT_MEM
    default n
    help
        Experimental. Allocate LVGL-created FreeRTOS thread stacks, including
        LVGL v9 draw threads, in PSRAM when the LVGL FreeRTOS backend is used.

config ESP_LVGL_ADAPTER_ENABLE_FPS_STATS
    bool "Enable FPS statistics"
    default n
    help
        Enable FPS (Frames Per Second) statistics for display performance monitoring.
        When enabled, you can use esp_lv_adapter_fps_* APIs to get real-time FPS.
        Performance overhead is negligible (< 2 microseconds per frame).

config ESP_LVGL_ADAPTER_ENABLE_BUTTON
    bool "Enable button input support"
    default n
    help
        Enable navigation buttons input device support.
        Requires espressif/button component.

        When enabled:
        - Button navigation APIs are available
        - Supports 3-button navigation (prev, next, enter)
        - Compatible with both button component v3 and v4+

        When disabled:
        - Button-related code will not be compiled
        - Saves ~5-10KB of flash space
        - espressif/button dependency can be removed from your project

config ESP_LVGL_ADAPTER_ENABLE_KNOB
    bool "Enable knob/encoder input support"
    default n
    help
        Enable rotary encoder (knob) input device support.
        Requires espressif/knob component.

        When enabled:
        - Encoder APIs are available
        - Supports rotary encoder with optional button
        - Ideal for menu navigation without touch screen

        When disabled:
        - Knob-related code will not be compiled
        - Saves ~8-12KB of flash space
        - espressif/knob dependency can be removed from your project

endmenu
