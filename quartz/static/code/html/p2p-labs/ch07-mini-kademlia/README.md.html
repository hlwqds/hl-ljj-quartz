# ch07-mini-kademlia —— k-bucket · 迭代查找 · 女巫攻击与防御

把 [[ch07-kademlia|第七章：Kademlia——现实世界的 DHT 通用语]] 与 [[ch10-p2p-security|
第十章：P2P 安全与未来]] 的攻击部分做成进程内模拟器：引擎 **kad.c**（XOR 度量、160 个
指数 k-bucket、α=3 迭代查找、k 副本、FIND_VALUE 短路语义），两个实验入口——
**demo.c**（地址簿体检 + 40 键存取 + 杀 50% 节点存活率）与 **demo_sybil.c**（女巫
三幕剧：占领目标邻域 → 说谎应答 + 写路径劫持 → S/Kademlia 式 ID 门槛防御与代价对账）。

## 实验看点

- **指数地址簿**：48 节点网络里单个节点只有 ~16 个联系人、5 个非空桶——
  "桶 i 容量翻倍"的体检数字；
- **churn 抗性**：杀 50% 节点后 40/40 键全部可达（k=4 副本 + 路径冗余）；
- **日蚀的完整含义**：不只是查不到——是**写进去**。刷新再发布把副本迁往
  「当前 K 近」，而 K 近已是马甲（实测 4/4 落入攻击者）；
- **防御 = 给身份定价**：8 位 ID 门槛下马甲进不了桶，查找恢复；攻击者入场费
  从 0 涨到 ~2⁸ 次/个（PoW 抗女巫的微缩版）。

## 编译运行

```bash
zig cc -o demo demo.c kad.c sha1.c          # Linux/macOS 同一行（无平台依赖）
zig cc -o demo_sybil demo_sybil.c kad.c sha1.c
./demo 48 40 50          # 节点数 键数 杀掉百分比
./demo_sybil             # 三幕剧（固定种子，输出可复现）
```

完整真实输出见 `run.log`（含两段排错实录：clz 跨宽度暗坑、攻击键与邻域对不上）。
