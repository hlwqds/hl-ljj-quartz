# ch03-framing —— COBS + CRC32 + 帧层流式解析

[[ch03-framing|第三章：帧协议]] 的完整实现与验收：**cobs.c**（块指针式编解码，254
边界处理）、**crc32.c**（IEEE 802.3 反射式按位实现，官方向量 + zlib 对拍）、
**framing.c**（八字节头 + CRC + COBS + 0x00 分隔的打包器，与逐字节流式解析器——
空闲填充合法、连发可切、截断可续）。传输层无关：这层字节流来自 SPI 交换缓冲还是
UART，对它没有区别。

## 测试矩阵（12 项全 PASS，见 run.log）

- COBS 已知向量（`[00]→[01 01]` 等）与 253/254/255 非零段边界回环；
- 随机数据（含密集零）×3000 回环 + 输出无零性质；
- CRC32 官方向量（`"123456789"` → `0xCBF43926`，与 zlib.crc32 一致）；
- 帧回环：空闲填充中切帧、双帧连发、截断续喂；
- 故障注入：翻位帧被拒（CRC/头部检查其一）、截断帧等待不误收。

## 编译运行

```bash
zig cc -o test test.c cobs.c crc32.c framing.c    # Linux/macOS 同一行
./test
```
